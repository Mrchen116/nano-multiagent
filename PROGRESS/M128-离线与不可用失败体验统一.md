# M128 Progress - 离线与不可用失败体验统一

## Summary
- 对齐了 Web IM 在 unbound、offline、unavailable 三种失败状态下的可见反馈。
- 将 composer 前置阻断与发送失败态统一收敛到 `Chat unavailable` 产品卡片语义。
- 同步更新 README、operator runbook、frontend README，移除“只有发送时才知道无可用节点”的冲突说法。

## Implementation Notes
- `resolveSendAvailability` 现在显式返回 `state`，用于区分 `unbound` / `offline` / `available`。
- `MessagePane` 统一渲染 failure banner；不可发送时展示 amber 卡片，发送失败时展示 rose 卡片，但标题、问题定义与下一步动作保持同一产品心智。
- unavailable 发送失败继续保留草稿，用户可以在节点恢复后直接重试。
