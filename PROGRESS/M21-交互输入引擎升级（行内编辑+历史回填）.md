### R21.1 行内编辑基础能力（左右光标 + 插入删除）
- Context:
  - 原 REPL 仅依赖 `input()`，无法在 CLI 代码层显式保证 `←/→` 光标移动与行内插入/删除行为。
  - 需要在不破坏现有命令模式与测试注入 `input_fn` 的前提下，引入可控输入引擎。
- Decision:
  - 新增 `_read_interactive_line` 行编辑函数，支持左右移动、插入、退格、回车提交。
  - 增加 `_build_repl_input_reader` 统一选择输入源：优先测试注入 reader，其次 `input_fn`，最后 TTY 场景启用 raw mode 行编辑。
  - REPL 主循环改为通过 reader 读取输入，并记录每个 session 的输入历史（为 R21.2 做准备）。
- Rationale:
  - 将“按键行为”下沉为可单测函数，避免把交互逻辑隐含在终端库黑盒行为中。
  - 输入源分层保持兼容：现有单测继续可控，真实 TTY 获得新编辑能力。

### R21.2 会话级输入历史导航（↑/↓ 回填 + 草稿恢复）
- Context:
  - R21.1 已支持行内编辑，但 `↑/↓` 仍未生效，无法回填当前 session 历史输入。
  - 需要保证历史回填后可继续编辑并提交，同时保持 session 维度隔离。
- Decision:
  - 在 `_read_interactive_line` 中引入历史游标：`↑` 回到更早输入，`↓` 回到更新输入，末尾恢复进入历史前草稿。
  - 当用户在回填内容上继续输入/删除时，脱离历史游标并在当前行继续编辑。
  - `_run_repl` 使用 session 级 `input_history_by_session`，仅在消息发送路径记录输入历史。
- Rationale:
  - 将历史导航状态放在输入引擎内部，避免 REPL 主循环散落键位状态管理。
  - 仅记录消息输入可保持 `/help` 等命令不污染历史回填体验。
