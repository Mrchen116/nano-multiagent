### R22.1 会话预算指标接口与客户端接线
- Context:
  - REPL 预算展示依赖稳定的会话预算来源；当前 API 仅有 `/tools` 与 `:compact`，缺少预算查询接口。
  - 需保持 CLI HTTP-only 边界，不引入 `agent.runtime` 直连 import。
- Decision:
  - 新增 `GET /v1/sessions/{session_id}/context-budget`，返回 `used_tokens/max_tokens/remaining_tokens/usage_ratio`。
  - 在 session 路由层复用 `SessionService.manager.list_turn_messages` 估算上下文 token，并从 runtime 设置读取 `context_window`（不可得时回退默认值）。
  - CLI `ServerClient` 新增 `get_context_budget`，统一使用已有 `_request` 错误处理链路。
- Rationale:
  - 预算口径与会话消息一致，可直接服务 REPL 展示；把能力暴露在 HTTP API 层可保持 CLI 与 runtime 解耦。
