## R1 — 聊天面板固定布局

- Context: App.tsx 用 `min-h-screen` 使根容器高度无上限，消息增多时页面整体下长，输入框被推出视口。
- Decision: 将 `min-h-screen` 改为 `h-screen overflow-hidden`；chat-workspace-page.tsx 外层 section 加 `h-full` 确保高度链不断裂；MessagePane 已有 `flex h-full flex-col overflow-hidden`，无需再改。
- Rationale: `h-screen` 将根容器锁死为视口高度，`overflow-hidden` 防止溢出，flex 链传导保证消息列表 `flex-1 overflow-y-auto` 真正内部滚动。
- Evidence:
  - Tests: App.test.tsx `uses fixed viewport height` PASS; `npm run build` 全绿
  - Entry: 根容器 className 含 `h-screen`，不含 `min-h-screen`
