## R1 — 聊天面板固定布局

- Context: App.tsx 用 `min-h-screen` 使根容器高度无上限，消息增多时页面整体下长，输入框被推出视口。
- Decision: 将 `min-h-screen` 改为 `h-screen overflow-hidden`；chat-workspace-page.tsx 外层 section 加 `h-full` 确保高度链不断裂；MessagePane 已有 `flex h-full flex-col overflow-hidden`，无需再改。
- Rationale: `h-screen` 将根容器锁死为视口高度，`overflow-hidden` 防止溢出，flex 链传导保证消息列表 `flex-1 overflow-y-auto` 真正内部滚动。
- Evidence:
  - Tests: App.test.tsx `uses fixed viewport height` PASS; `npm run build` 全绿
  - Entry: 根容器 className 含 `h-screen`，不含 `min-h-screen`

## R2 — 全局消息到达 Toast 通知

- Context: 用户在 settings 等其他页面时无法感知新消息到达；需要 in-app 通知，不需浏览器 Notification 权限。
- Decision: 新建 `InAppToast` 组件（fixed top-left，4 秒自动消失）+ `useGlobalMessageToast` hook（订阅所有已知会话 SSE 流，最多 10 条）。App.tsx 根组件挂载 hook 并条件渲染 toast。
- Rationale: 复用现有 `streamConversationEvents` API 避免引入新后端接口；最多 10 条限制防止连接过多；用 `key={toast.id}` 让 React 每次新 toast 重置 auto-dismiss 计时器。
- Evidence:
  - Tests: `in-app-toast.test.tsx` 4 tests PASS; `npm run build` 全绿（136 modules）
  - Entry: App.tsx 根组件有 `{toast && <InAppToast ... />}` 渲染
