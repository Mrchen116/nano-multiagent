# M237 - 修复创建群聊弹窗遮挡左边栏滚动

## 背景

创建群聊面板（groupChatPanel）渲染在左侧列的 flex 容器中，位于 ConversationList 上方。
参与者候选列表无高度约束，agent 数量多时会将 ConversationList 推出视口，导致用户无法滚动到底部 agent。

## Roadpoints

### R1 - 为候选列表区域添加限高滚动

- Context: 候选列表 `<div className="grid gap-3">` 无 max-h / overflow 限制，直接撑高页面
- Decision: 在 `grid gap-3` 外层包裹 div，加 `max-h-60 overflow-y-auto` 限高滚动
- Rationale: 最小侵入，只加一个包裹 div，不影响内部 grid 布局和现有逻辑
- Evidence:
  - Tests: `cd src/IM/frontend && npm run build 2>&1 | tail -5` 全绿
  - Entry: 渲染面板后候选列表节点 className 含 `overflow-y-auto`
- Rollback: 回退到本 milestone 的 C1 commit
