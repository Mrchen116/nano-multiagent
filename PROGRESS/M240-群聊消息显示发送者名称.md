# M240 - 群聊消息显示发送者名称

### R1 MessageBubble 仅在群聊显示发送者名称
- Context:
  - 群聊消息当前无条件显示 `sender_name ?? sender_type`，导致直聊也出现发送者行，且无法消费 relay payload 已有的 `sender_user_id` / `sender_display_name`。
  - 本 milestone 只允许修改前端聊天组件与类型定义，不触碰后端 relay 结构。
- Decision:
  - 为 `ChatMessage` 增补 `sender_display_name` 与 `sender_user_id` 字段。
  - 在 `MessagePane` 内统一计算 `isGroupChat`，仅在群聊向 `MessageBubble` 传入 sender label 渲染开关。
  - 群聊 sender label 采用 `sender_display_name -> sender_name -> sender_user_id -> sender_type` 的回退链。
- Rationale:
  - 让群聊能直接消费现有 payload 字段，同时不改变直聊既有视觉密度与信息结构。
