# M112 真实进程级 IM↔Gateway↔Agent 联调与操作手册

## 目标
用真实进程而不是 TestClient harness，打通 IM 服务 + Gateway + agent kernel 的人工可操作链路；补齐联调缺口，并产出最终 operator runbook。

## Exit Criteria
1. 真实启动 IM.app + personal_assistant.main + 本地 agent kernel 后，能完成一次 Web IM 消息往返。
2. 验证 docs/NodeGateway-SPEC.md §16 中与真实启动最相关条目：channel 启动(1)、四步决策(2)、回发原目标(4)、heartbeat(6)、IM 在线/离线降级(5)。
3. 验证 docs/IM-SPEC.md §12 中第 1/3/5/9/10 项真实链路。
4. 产出最终 operator 启动步骤，且这些步骤已经被本 milestone 真实执行过。
