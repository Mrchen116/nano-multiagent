## 基线判断
- 当前 `README.md` 与 `docs/operator-runbook.md` 已有默认路径，但仍偏“运行手册”表述，缺少：
  - 一眼能看到的启动顺序。
  - IM / Gateway 各自 ready 信号。
  - 绑定后、失败后“接下来做什么”的产品化文案。
- 当前前端已具备关键产品反馈能力：
  - 未绑定时显示 `Chat unavailable` + `Next: Open bind flow`
  - 离线时显示 `Chat unavailable` + `Next: Bring Gateway online`
  - 发送失败时保留草稿并提示重试
- 当前 Gateway 已具备关键终端反馈能力：
  - 未绑定时输出 `ACTION ...` / `NEXT ...`
  - bootstrap 失败时输出 `ERROR ...` / `NEXT ...`
  - smoke runtime 可输出 `READY / RUNNING / SHUTDOWN`
