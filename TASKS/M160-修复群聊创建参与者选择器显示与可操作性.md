## 目标
修复 Web IM 点击 `Create group chat` 后只显示标题/说明而没有参与者选择控件与创建入口的问题，恢复真实可见、可选择、可创建的群聊参与者面板，并补齐关键状态回归测试。

## 明确问题
1. `chat-workspace-page.tsx` 目前只有群聊面板标题与说明，没有任何候选参与者列表、选中状态或提交按钮。
2. 前端现有 API 只暴露直聊候选 agent，缺少群聊参与者候选与群聊创建动作封装。
3. 自动化测试只断言点击后出现 `Select participants` 标题，没有覆盖 loading / empty / selection / create affordance。

## Scope
- 为 Web IM 群聊面板补齐真实参与者候选列表、选中状态与创建按钮。
- 为前端 chat API 增加最小必要的群聊候选加载与群聊创建封装。
- 为 mock API 同步补齐群聊数据路径，保证测试/开发态一致。
- 新增聚焦前端测试，覆盖可见候选、选中反馈、loading、empty 与 create affordance。
- 更新 `TASKS/M160-*.md` 与 `PROGRESS/M160-*.md`，记录 Roadpoints、验证命令、提交点与回滚说明。
