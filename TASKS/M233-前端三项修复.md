# TASKS/M233 — 前端三项修复：聊天固定布局 + 全局消息通知弹窗 + 创建群聊按钮穿模

## Milestone 概述

修复三个前端问题（src/IM/frontend/src/ 内）：
1. 聊天面板固定高度布局，消息列表内部滚动，输入框固定底部
2. 全局消息到达 toast 通知（in-app，无需浏览器授权）
3. 创建群聊按钮不再溢出容器边界（穿模）

**test_command**: `cd src/IM/frontend && npm run build 2>&1 | tail -5`

## R1 — 聊天面板固定布局（输入框不随消息增多下推）

### Acceptance
1. `message-pane.tsx` 外层 section 使用 `flex flex-col` 且高度受 `h-full` 约束，不随内容增长
2. 消息列表区域使用 `flex-1 overflow-y-auto` 实现内部滚动
3. 表单（输入区）紧贴底部，不会被推出视口
4. `App.tsx` 的主容器从 `min-h-screen` 改为 `h-screen`，main 区从 `flex-1` 改为 `min-h-0 flex-1`，保证高度链不断裂
5. `chat-workspace-page.tsx` 的外层 section 带 `h-full` 确保 MessagePane 拿到确定高度

## R2 — 全局消息到达 Toast 通知

### Acceptance
1. `App.tsx` 根组件监听所有对话的新消息事件
2. 当用户不在该对话页面时，左上角显示 toast（含发送者名称 + 消息摘要 + 点击跳转链接）
3. Toast 自动消失（3-5 秒后）
4. 连续多条消息只叠加最新条（不无限堆叠）
5. 纯 in-app 通知，无需浏览器 Notification API 授权

### Tests Plan
- unit: 适用 — 测试 `InAppToast` 组件渲染与消失逻辑
- contract: 不适用
- integration: 适用 — 测试 toast 在切换路由后弹出
- e2e: 不适用（需真实 SSE 流）

**选择**: 新建 `src/features/chat/components/in-app-toast.test.tsx`，覆盖：
- toast 显示指定 sender + preview
- toast N 秒后消失（fake timer）
- 点击 toast 触发导航回调

- `npm run build` 全绿
- C1/C2/C3 齐全
