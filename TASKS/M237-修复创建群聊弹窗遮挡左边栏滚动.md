# M237 - 修复创建群聊弹窗遮挡左边栏滚动

## 目标

创建群聊对话框打开后，左侧会话列表无法滚动，导致列表底部的 agent 选不到。
正确做法：参与者候选列表应在弹窗内部可滚动（overflow-y: auto + 固定最大高度），
不依赖左边栏滚动。

## Roadpoints

### R1 - 为候选列表区域添加限高滚动

**状态**: TODO

**问题根因**

`chat-workspace-page.tsx` 中的 `groupChatPanel`（行 895-933）的参与者候选
列表容器是一个无高度约束的 `<div className="grid gap-3">`。agent 数量多时，
该 div 会撑高整个左侧列，将 `ConversationList` 推到视口以外，导致无法滚动到列表底部选择目标 agent。

**修复方案**

给 `groupParticipantOptions` 候选列表的包裹 div 加上：
- `max-h-48`（或 `max-h-60`）
- `overflow-y-auto`
- 保留 `grid gap-3` 内部布局

**Acceptance**

1. 候选列表容器有显式 max-height 样式
2. 候选列表容器有 overflow-y-auto（或等价 scroll）样式
3. groupChatPanel 内的 `grid gap-3` wrapper 保持不变（内部排列不变）
4. `npm run build` 全绿
5. 不给 body/html 加 overflow:hidden

**Tests Plan**

- unit: 不适用（纯 Tailwind CSS 结构，无业务逻辑）
- contract: 用 DOM 断言验证候选列表容器的 className 中包含限高与滚动类
- integration: 渲染 ChatWorkspacePage 并打开群聊面板，断言候选列表 DOM 节点带目标 class
- e2e: 不适用（超出当前 test_command 范围）

**Expected Tests**

测试名：`group chat panel - candidate list has max-height and overflow scroll`
形态：vitest / @testing-library，渲染组件 + click "Create group chat" + 断言候选列表节点的 className
