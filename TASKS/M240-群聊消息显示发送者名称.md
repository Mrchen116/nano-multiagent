# M240 - 群聊消息显示发送者名称

## Goal
群聊中每条消息气泡上方显示发送者名称（`sender_display_name -> sender_name -> sender_user_id -> sender_type` 回退）；直聊不显示。

## Prevention Rules
- 群聊判断：`ConversationDetail.kind_label === "Group chat"`
- 只在 `isGroupChat` 时在气泡上方显示 sender 名称（`sender_display_name -> sender_name -> sender_user_id -> sender_type`）
- 直聊不显示发送者名
- agents-list-mobile.test.tsx 的 5 个测试是预存在失败，不要去动

## Roadpoints

---

### R1 - MessageBubble 接受 isGroupChat prop，仅在群聊时显示发送者名称

**Acceptance**
1. 群聊（`kind_label === "Group chat"`）中，每条消息气泡上方显示 sender 名称，回退顺序为 `sender_display_name -> sender_name -> sender_user_id -> sender_type`
2. 直聊（`kind_label !== "Group chat"`）中，气泡上不显示发送者名称
3. 自己发的消息（`is_mine === true`）在群聊中也显示发送者名称（显示 "You" 或 sender_name）
4. `npm run build` 通过
5. `npx vitest run` 新增测试全绿，已有测试不退化

**Tests Plan**
- unit: 测试 `MessageBubble` 在 group/direct 两种 context 下的渲染行为
- contract: 验证 `isGroupChat=true` 时 sender 名称存在于 DOM，`isGroupChat=false` 时不存在
- integration: 通过 `renderMessagePane` 传入群聊 detail 和直聊 detail，验证消息列表中的展示差异
- e2e: 不需要（本 Milestone 纯前端组件，build 即入口验证）

**Expected Tests** (in `message-pane.test.tsx`)
- `"shows sender name above each bubble in group chat"`
- `"does not show sender name in direct chat"`
