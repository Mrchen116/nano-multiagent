# M75 - 多产品架构重构二期：配置目录与路径解析收口

**Goal**: 统一 local_coding 与 personal_assistant 的全局/工作区配置目录、sessions.sqlite3 放置规则、用户扩展 roots 与兼容 skill roots 解析，全部通过统一的 config resolver 解决，不再散落到各模块。

**Test Command**: `pytest -q`

**Baseline**: 5 pre-existing failures (contract/integration tests from before M74), 480 passed — these 5 are NOT M75 scope.

---

## Roadpoints

### R75.1 扩展 ProductProfile 路径字段 + 新增 ConfigResolver
**Status**: TODO

**Acceptance**:
1. `ProductProfile` 新增 `global_config_home`, `workspace_config_dirname`, `session_db_filename`, `compat_skill_roots` 字段
2. `platform/config/resolver.py` 提供 `ConfigResolver` 类，构造接收 `ProductProfile + optional workspace_root`
3. `global_config_root()` 返回 `~/<global_config_home>`
4. `session_db_path()` 返回 `global_config_root() / session_db_filename`（总在 global dir）
5. `user_tool_roots()`, `user_hook_roots()`, `user_skill_roots()` 返回正确优先级顺序

**Tests Plan**:
- unit: 对 `ConfigResolver` 的各方法做独立单元测试
- contract: `ProductProfile` 字段结构校验
- integration: 不需要（resolver 是纯路径计算，无 I/O）
- e2e: 不需要（路径计算只作为下游模块参数）

**Expected Tests**:
- `tests/unit/test_config_resolver.py`
  - `test_global_config_root_expands_home`
  - `test_session_db_path_always_in_global_dir`
  - `test_user_tool_roots_workspace_first`
  - `test_user_hook_roots_workspace_first`
  - `test_user_skill_roots_workspace_global_compat`
  - `test_resolver_without_workspace_root`

**DoD**: `pytest -q` 与基线相同（不增加失败） + C1/C2/C3 提交
