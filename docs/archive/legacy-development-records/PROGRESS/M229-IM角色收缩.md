### R3 IM settings 改为优先读 Gateway live config
- Context: M229 exit criteria 明确要求“IM 查询 agent 配置时改为请求 Gateway”。仓内原实现 `src/IM/api/routes/agents.py` 仍直接返回 `agent_profiles` 镜像。
- Decision: 增加 IM↔Gateway websocket 请求/响应通道：IM 下发 `agent.config.get`，Gateway 通过本地 `LocalConfig` 返回 `agent.config`；`GET /im/v1/agents/{agent_id}/config` 改为 async 路由，优先请求 bound Gateway 的 live config，拿不到时再退回 IM 镜像。
- Rationale: 这样保持 IM `agent_profiles` 是镜像/缓存，而 settings 真正看到的是 Gateway 当前本地配置，和 config.sync / 本地真源模型一致。
