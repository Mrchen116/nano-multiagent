# M241 - 全局滚动修复：h-screen 固定后各页面/面板内部滚动补全

## 背景
M233 把 App 根容器改为 `h-screen overflow-hidden` 后，settings 子页和部分面板失去滚动能力。
根本原因：`SettingsPageShell` 缺少 `h-full`，内部右侧面板未设 `overflow-y-auto`。

## Roadpoints

### R1 - SettingsPageShell 与各 settings 子页滚动修复

**状态**: DONE

**Acceptance**
1. `/settings/agents` 页面内容过长时可独立滚动，页面外层无滚动条
2. `/settings/agents/:id`（agent-detail-page）内容过长时可滚动
3. `/settings/nodes`、`/settings/policies`、`/settings/account` 均可内部滚动
4. 左侧 Settings 导航栏在移动端水平滚动不回退
5. `npm run build` 成功；vitest 105 passed（5 pre-existing failures 不变）
