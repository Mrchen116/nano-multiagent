# Gateway relay-protocol delta

## ADDED Requirements

### Requirement: 入站普通文件不会被按图片处理

入站消息按附件类型投影。普通文件保留名称、类型和来源，明确内容尚未读取；不自动赋予文件读取权限，不以图片损坏中断文字要求。single_thread 与 global 均保持此基本语义。

#### Scenario: 普通文件或图文文件混合
- **WHEN** 用户发送文字及普通文件，或文字、有效图片与普通文件的混合消息
- **THEN** 文字与有效图片正常进入上下文，普通文件保留描述并明确未读取，不报告图片损坏

### Requirement: 历史附件失败不阻断新请求且群上下文接收后消费

单会话 Agent 的群缓冲只有在内核接受输入后才消费；准备/接收失败不能提前移除，处理中后来到达的消息不被误消费。

#### Scenario: 历史图片不可用
- **WHEN** 群缓冲中图片无法下载、超大或损坏，而新请求触发 Agent
- **THEN** 保留历史文字、有效附件和新请求，不可用图片明确标记未读取及原因，不让该图片阻断新请求
- **AND** 失败说明进入上下文不代表图片内容已被读取

#### Scenario: 当前失败或接收失败
- **WHEN** 当前图片使本轮停止，或本轮输入未被内核接受
- **THEN** 群缓冲仍保留给后续正常请求

#### Scenario: 接收期间新增上下文
- **WHEN** 一批缓冲被接受时又有其他背景消息到达
- **THEN** 仅本次被接受的缓冲被消费，后来消息保留；正常后续请求不重复已接受的背景

当前消息的异常图片继续遵循既有“异常图片本轮停下、明确告知用户、可重发”契约。
