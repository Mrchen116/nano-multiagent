# gateway global-agent Specification (delta for bugfix-605)

## MODIFIED Requirements

### Requirement: 全局模式向目标群或私聊发言前复核应处理的新消息

#### Scenario: 没有新消息时正常发言
- **GIVEN** 全局 Agent 准备向内置 Web IM 群或已有私聊发送消息
- **WHEN** 目标会话没有它尚未读取、按其配置需要处理的新消息
- **THEN** 可以正常发言，不需要用户批准或额外触发

#### Scenario: 目标群的新更正被考虑
- **GIVEN** 全局 Agent 正准备向内置 Web IM 群回答一项安排
- **WHEN** Gateway 在发言前收到该群按 Agent 配置需要处理的新更正
- **THEN** 旧草稿不先公开，Agent 读取新信息后重新判断再交付
- **AND** 新信息不影响原结论时可保留原文；是否允许静默仍遵循原有规则

#### Scenario: 复核期间又收到适用的新消息
- **GIVEN** 全局 Agent 已因目标群更正开始复核
- **WHEN** Gateway 在其正式发言前再次收到该群按配置需要处理的新更正
- **THEN** 后续发言继续考虑新更正，不把第一次复核当作永久通行证

#### Scenario: 其他群及仅作背景的更新不阻塞发送
- **GIVEN** 全局 Agent 准备向 A 群发送消息
- **WHEN** 只有 B 群的新消息，或 A 群按其配置仅作背景的普通更新
- **THEN** 这些消息不阻塞本次向 A 群发言，也不因复核改变它们原有的处理与唤醒规则

#### Scenario: 草稿和复核归属员工工作视图
- **WHEN** 用户查看全局 Agent 的工作视图
- **THEN** 可以展开查看真实未发送草稿、所涉目标会话与复核过程
- **AND** 未发送草稿不作为目标会话的正式发言出现，也不触发其他 Agent 接话

#### Scenario: 私聊补充在旧答发送前到达
- **GIVEN** 全局 Agent 正准备向 Web 或飞书私聊回答
- **WHEN** 该目标出现它尚未读取且按配置需要处理的新补充
- **THEN** 旧稿不先公开，Agent 读取补充后重新判断再交付
- **AND** 飞书真实会话和 Web 镜像定位到同一目标时，两侧接收的新输入均参与复核
- **AND** 正在执行的工具不被硬中断，其他聊天与仅作背景的输入不阻塞该私聊

#### Scenario: 私聊复核后再次有补充
- **WHEN** Agent 读取新输入后重新发言前，该私聊又出现需处理的新输入
- **THEN** 新发言继续复核，不复活已拦截的旧发送调用

#### Scenario: 外部群聊与真实投递回执保持
- **WHEN** 全局 Agent 向外部群聊发送，或私聊发言已经进入投递
- **THEN** 外部群聊保持原有规则，已投递消息不因后到输入被撤回
- **AND** 外部回复经原 Channel 投递，不能仅保存 Web IM 镜像就确认已发送
