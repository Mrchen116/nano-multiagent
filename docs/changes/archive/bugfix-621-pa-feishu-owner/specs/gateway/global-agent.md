# gateway/global-agent delta

## ADDED Requirements

### Requirement: PA 跨渠道主人交办一致性

主人 Web 私聊和已绑定主人飞书私聊均作为主人直接交办来源，原始授权由服务端持久身份事实确认。主会话继续使用同一个 Inbox、工具和调度，按来信渠道回复；其他会话中的主人消息作为背景事实，不自动获得私聊授权。

#### Scenario: 主人飞书交办可引用原始授权
- WHEN 主人在已绑定飞书单聊发起需要主人授权的操作
- THEN PA 可引用该条原始消息执行授权范围内的操作，不要求主人转到 Web 重复交办

#### Scenario: 单一接入
- WHEN 一条飞书消息镜像进入持久来源事件并经历重试或重启
- THEN PA 主会话只接入一次，保留原渠道、发送者和时间
