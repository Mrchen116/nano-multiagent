# ADDED Requirements

### Requirement: 会话预览按可读文本截断 mention

会话列表 MUST 在解析参与者提及后截取消息预览，不能因原始标签或 ID 占用字符而显示残缺标签。当前参与者人名与正文一致，列表宽度不足时可按正常规则省略可读文字。

#### Scenario: 连续 mention 跨越原始字符截断点
- **WHEN** 消息开头连续提及两位参与者，原始标签总长度超过预览限制
- **THEN** 预览按顺序显示人名，不出现原始 mention 标签。

#### Scenario: 已有会话重新加载
- **WHEN** 用户重新加载历史上预览被截断的会话
- **THEN** 从完整消息恢复可读预览，无需重新发消息，正文不变。
