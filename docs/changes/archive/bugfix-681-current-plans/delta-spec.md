# IM Agent 配置：当前计划（已归并）

### Requirement: Web 配置页仅展示仍有效的自动执行计划

- WHEN 用户查看 Agent 配置中的当前计划
- THEN 页面仅展示已取得列表中 enabled=true 的条目，不展示 inactive 历史；计划时间已过不能单独作为隐藏条件。
- AND 无有效条目时显示“暂无待执行的定时任务”；离线历史快照继续标示原有来源提示，不宣称实时状态。
- AND 显示本地化调度规则和带时区的下一次时间，默认收起执行指令，自定义 cron 表达式放在详情；计划类型与下次执行时间分层展示，取消操作位于展开详情内。
- AND 用户可通过“取消计划”使用原删除操作；仅允许当前可信状态下执行。
- AND 隐藏记录不删除底层历史，也不宣称后续工作执行成功。
