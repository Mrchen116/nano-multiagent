# Agent 配置读取体验增量

## ADDED Requirements

### Requirement: 已保存配置的首次展示不等待节点能力检查

#### Scenario: 打开在线 Agent 配置
- **WHEN** 用户打开配置页
- **THEN** 真实已保存配置可先展示并允许满足当前准入的草稿编辑；首屏读取不启动或等待临时能力检查。
- **AND** 保存仍要求当前能力确认成功、无读取错误与在途确认，并通过既有版本、身份和 operation 校验；首屏数据不授予提交资格。

#### Scenario: 首次能力确认失败
- **GIVEN** 本次已从服务端取得同一身份、在线节点和配置版本的已保存配置
- **WHEN** 后台能力确认超时或失败
- **THEN** 可以继续编辑草稿，并明确提示确认失败、保存仍被阻止；不把能力缺失当成配置空值或填入新默认值。
- **AND** HTTP 401/403/404、节点断线、连接恢复或状态变化撤销该草稿准入；不以历史缓存重新解锁。

### Requirement: 已确认配置在普通后台刷新时保持可编辑

#### Scenario: 普通刷新保留草稿
- **GIVEN** 已确认当前用户、Agent、节点连接和配置版本，且没有未确认操作
- **WHEN** 配置在后台刷新或用户从其他窗口返回
- **THEN** 既有已确认字段可查看和编辑，草稿不被覆盖；刷新状态可辨认。
- **AND** 保存前重新确认当前准入、版本和依赖；不能确认时保留草稿且不声称保存成功。

#### Scenario: 连接或准入失效
- **WHEN** 节点断线、用户身份或权限变化、版本冲突或操作仍待确认
- **THEN** 不使用过期数据授权提交；展示可辨认状态并保留允许保留的草稿。
