# IM Web Chat UX Specification (delta for bugfix-731)

## ADDED Requirements

### Requirement: Web 应用内新消息提醒按会话类型标识来源

Web IM SHALL 在会话外的新消息弹窗中用会话名标识来源，群聊额外展示该消息发送者的可读名称，并保留消息摘要与进入来源会话的操作。

#### Scenario: 私聊提醒沿用会话名
- **WHEN** 用户在其他页面收到真人或 Agent 私聊的新消息提醒
- **THEN** 弹窗显示该私聊的会话名，包括已保存的自定义名称，并展示消息摘要。

#### Scenario: 群聊提醒同时标识群和发送者
- **WHEN** 用户在其他页面收到群聊中真人或 Agent 的新消息提醒
- **THEN** 弹窗同时显示群名、发送者的可读名称和消息摘要；只有两个成员的群仍按群聊展示。
- **AND** 点击查看进入该消息所属的群聊。

#### Scenario: 尚未加载聊天列表或名称暂不可得
- **WHEN** 用户停留在设置等页面时收到新消息提醒
- **THEN** 不要求先打开聊天列表才能显示来源名称；名称暂不可得时显示可读通用称谓，不将内部 ID 作为名称兜底。
