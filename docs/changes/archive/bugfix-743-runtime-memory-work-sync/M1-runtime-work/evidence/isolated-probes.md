# 隔离对照：历史驻留、Work 回包与慢读

环境：本机 macOS arm64，Node 24.22.1、锁定 DSH 0.2.1-alpha.1；独立 DSH_HOME、合成数据，无生产连接。基线相关实现 `142e05598`（机制探针与已部署 `68e65a880` 一致）；候选为实现提交 `082d62fe`。后续 `088d104d` 只变更 Node/Work 对冷中断、pending 和生命周期的处理，以下探针的读取与写出代码未变。

| 探针 | 基线 | 候选 |
|---|---:|---:|
| 空样本：initialize 后显式 GC 的 heapUsed | 63,437,704 B | 63,284,352 B |
| 320 条标题输入 + 320 条工具展示（约 9,600 万合成字符）：同一口径 heapUsed | 112,979,496 B | 63,247,608 B |
| cursor 98、head 99：返回的 own 事件 | 100 条，从 seq 0 | 1 条，seq 99 |
| 上述响应 JSON 大小（含各自协议元数据） | 106,829 B | 1,164 B |
| 模拟五个大帧遇到 blocked Writable：stream buffer | 500,320 个 JS 字符，额外排队 4 块 | 100,064 个 JS 字符，额外排队 0 块 |

启动对照使用等结构、等大小的随机合成正文，测量是单次 GC 后驻留，既不是峰值也不是生产内存估计。写入对照的字符数来自关闭 `decodeStrings` 的慢 Writable；生产管道使用字节。候选端待写队列仍持有未序列化对象，最多为配置的有限数量；根与子两类 Work 生产者各只允许一页在写入屏障内。原生冷 Session 的公开读取仍可能解码一份完整日志；这不是 Work 页的传输量。

候选真实 DSH 的 300 项合成目录使用两个请求完成：256 + 44 项，请求参数 20 / 44 B，响应 JSON 20,917 / 3,622 B；未给目录中 unsupported 身份开通子页读。真实 Node/DSH 的分页断连用例在工具调用页提交后终止独立子进程，重启从同一 cut 拉取，保留 1,100,000 字符的工具展示正文以及唯一配对的工具开始/结束和真实轮结束。独立冷中断探针在模型运行中终止进程，DSH 冷读回补原生 interrupted 结束；修复后 Work 按原逻辑轮显示 interrupted，未续跑子任务。

这些数据不能证明生产崩溃的最后触发帧，不能外推所有 V8 分配或生产延迟。合成输入、缓存/管道探针和验证目录均不包含用户历史。
