## Findings 与关闭

- P2-1。OpenAI Completions 和 Responses 的代理 502 归一化格式被漏识别。独立审查者用锁定 pi-ai 实测三种错误形态。复审确认现在三种格式均要求明确的上游建连类型，普通 502 仍走原预算。真实 DSH 两种 OpenAI 协议用例通过。已关闭。
- P2-2。Node 24.22.1 明确报告 TLS 建立前 `ECONNRESET` 的场景被漏识别。独立审查者用本地 TCP 对端接收 ClientHello 后发送 FIN 复现。复审确认精确匹配仅覆盖该握手前信号，真实 DSH 用例通过。已关闭。

## 验证限制

- 实体合盖、Mini 代理链路和生产部署未在本次验证中操作。
- 本地已有 `global-child-tools.test.ts` 个别用例出现能力检查期限超时。在干净基线使用相同 Node 和单 worker 复测，亦得到 `Capability inspection deadline exceeded`。本变更未调整能力检查或测试时限。
- 本次验证进程、模型端口和数据目录由测试夹具在结束时回收。开发 worktree 留作 PR 审查。
