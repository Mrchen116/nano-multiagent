## 问题与关闭

- P1 已关闭。正常或异常收尾原先可能提前结束检查进程和 watchdog，使父检查器随即退出时遗留插件子进程。复审确认 POSIX 检查组保留协议取消的宽限时间，随后向整组发出 SIGKILL。检查 RPC 失败也交由拥有整组的父检查器处理。
- 无未关闭的审查发现。复审复用了实际进程的红绿对照与 macOS Node 24.22.1 检查器回归结果。
