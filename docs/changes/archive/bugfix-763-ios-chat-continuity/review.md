## 最终交付决定

- 用户确认 15% 作为调查线。依据同机实测，本次接受 iPhone 17 Pro 模拟器 300 条混合消息暖滚动中约 18.8 MB 的 App 峰值内存增量（106.3 → 125.1 MB，+17.73%）。保留全部样本和早段合计占用升高的证据。
- 本轮验证了卡片自动呈现、快滑折返的复用收益、实际尾部和历史阅读位置。模拟器没有返回原生 hitch 系列，两种 Allocations 附加均未给出可归因调用栈。真机掉帧率、内存压力和系统回收概率未验证。
- 目标基线已同步到 `8920a728a`。基线增量是 Web Agent Work 和轨迹就绪恢复、相关中心服务及文档。iOS 源码、iOS 测试、共享卡片渲染代码与隔离语料保持原取证版本，模拟器路径使用独立 fixture，原生证据在新集成树有效。最终 CI 验证完整集成树。
