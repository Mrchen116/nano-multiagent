# 切换聊天的实际设计

本文在实现后形成。基线为 `d5fb8a55c`，改动限于 Web IM。

工作区用当前路由识别已选聊天，并以列表中的展示信息先绘制标题和头像。详情访问复核和首屏历史并行；复核成功后由 MessagePane 接续，原有账号和会话草稿存储负责恢复输入。工作区根据本次会话数据是否已进入时间线控制空态，连续等待 300 毫秒后显示局部提示，详情或初始消息读取失败时提供对应重试。没有选中聊天时继续使用原有入口。

消息查询在每次进入时刷新。新会话仍可使用已获访问确认的缓存内容。阅读位置按账号和聊天保存在工作区内存中，包含首个可见消息 ID、相对视口偏移和离开时的末条消息信息。切回时结合本次详情的末条时间和时间线判断是否有更新。没有更新时按原有分页接口找回锚点，有更新时沿用面板跟随底部的逻辑。显式消息链接优先。Web 页面重新加载后按常规进入聊天。

回滚可还原本分支的前端改动，无存储迁移。回归关注加载中途切换、访问被拒、快速往返、跨分页恢复、草稿和新消息。用户试用反馈和独立审查见 [验证记录](review.md)。
