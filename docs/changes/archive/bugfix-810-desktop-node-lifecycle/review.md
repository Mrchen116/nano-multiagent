## 独立审查与处置

独立 reviewer 指出两处 P1，owner 完成以下修复和定向复验。

| 发现 | 修复与证据 |
|---|---|
| Windows 每连接计划任务可独立于 Desktop Run 登录项启动节点；写入 YAML 失败可能发生在任务变更之后。 | 设置页和托盘按当前连接汇总两条启动路径。保存配置前读取运行状态，先完成 YAML 验证和写入，再应用该连接的系统任务；任务注册失败恢复原配置，宿主恢复原 Desktop 登录项。macOS 定向测试强制注册失败并读回原配置。Windows 候选用例显式核对当前连接的原生任务。 |
| 配置保存可能重写并发托盘操作刚保存的 autostart 值。 | 配置保存、托盘和设置页操作共用宿主生命周期锁，写入和失败恢复都在同一临界区。重新登录时读取相同的当前连接有效状态。 |

跨服务操作只作用于当前连接及 Desktop 登录项。不同 Windows 节点任务各自服从所属连接的配置；检查当前连接时也读取其任务注册状态。
