# bugfix-816 窄屏聊天返回按钮与头像重叠

## 原始报告

「窄屏版上面有头像这个点不对，和返回箭头重叠了」。用户附图显示 PA 私聊标题左侧的头像、在线标记和返回箭头叠在一起，消息头像位置正常。

## 现象与复现

在 375px 宽的网页版打开 PA 私聊。加载完成后，返回按钮仍在左上角，标题栏的会话头像占用了同一位置。

## 根因

聊天工作区为加载期间和加载完成后的会话保留同一个返回按钮。提交 6e20c753d6 的窄屏留白规则只匹配会话面板的直接子标题栏。提交 ead0b38311 为消息区加入 chat-pane-main 后，加载完成的标题栏不再匹配该规则。加载中和加载完成的标题栏都沿用了桌面头像。

## 审查范围

核对窄屏两种加载状态的标题、返回入口和点击区域，检查宽屏及消息头像，并保留私聊 Agent 活动详情的入口。

## 修复

窄屏就绪和加载中的标题栏均省略会话头像，外置返回按钮为标题预留 68px。原本可打开 Agent 活动面板的私聊在窄屏改为点击标题。宽屏继续使用头像，正文继续显示消息头像。

## 验证

- 改动前，窄屏标题栏无头像的回归断言失败。改动后，消息面板和工作区两组共 187 项测试通过。
- Chromium 真实 daily 环境，320、375 和 767px 宽度下在 PA 私聊与群聊逐一检查，返回按钮均为 44×44px，距离标题 10px，点击返回聊天列表。点击 PA 标题可打开原活动面板。768px 下两个会话均显示桌面头像。
- 375px 下延迟会话详情响应，加载期间不显示头像，标题左侧仍有 10px 间距。响应后保持同一个返回按钮 DOM 节点。验证结束已关闭隔离栈。
