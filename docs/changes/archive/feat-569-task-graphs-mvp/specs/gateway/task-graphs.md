# gateway task-graphs Specification (delta for feat-569)

## ADDED Requirements

### Requirement: Agent 可按讨论结果维护持久任务图

#### Scenario: 创建、查询和增量修改
- **WHEN** 用户要求已配置任务工具的 Agent 保存或调整讨论好的计划或探索结构
- **THEN** Agent 能建立、读取并修改对应任务图，返回同一图的稳定入口。
- **AND** 保存行为本身不启动或调度执行工作。
- **AND** 节点以图内稳定短编号（如 `n1`、`n2`）读取和更新；改名、排序或状态变化不改变编号，不要求 Agent 反复传递节点 UUID。
- **AND** 图本身也使用短且稳定的引用（如 `tg_a1b2c3d4`）；不同图不会因短 ID 重名而覆盖彼此，工具与 Web 链接使用同一个图 ID。


#### Scenario: 配置任务图特性
- **WHEN** 用户在 Agent 配置中开启或关闭默认开启的“任务图”特性并保存
- **THEN** 该 Agent 下一轮回复按最新配置采用任务图能力，当前正在回复的一轮不切换，已有聊天历史和任务图记录保留。
- **AND** 开启开关通过既有界面联动选中 `task_graph` 工具；有效能力同时要求特性开启和工具白名单包含该工具。关闭后即使白名单保留该工具，也不向后续模型提供或允许调用，预览采用同一有效配置。
- **AND** 关闭某个 Agent 的特性不撤销用户对本人账号既有任务图的 Web 访问权，也不改变其他 Agent 或输入渠道的权限。

### Requirement: 图操作使用真实会话与账号归属

#### Scenario: 身份不匹配或未注册
- **WHEN** 请求中的会话不属于对应注册 PA Agent（包括无法核实为 PA 身份的内核 child），或图不属于该Agent的账号
- **THEN** 操作被拒绝且说明原因，不接受模型指定账号归属、传入身份或借Work可见性扩大权限。

#### Scenario: 无聊天创建及同账号Agent协作
- **WHEN** 用户要求Agent保存目标但没有指定聊天，或另一个同账号Agent读取并更新它
- **THEN** 使用同一持久图和稳定ID，不要求来源聊天成员关系、同群或负责人分派。
- **AND** 默认查询该账号所有目标的分页摘要，不要求按聊天筛选。

#### Scenario: 输入渠道与工具能力解耦
- **WHEN** 持有任务工具的 Agent 会话处理来自 Web IM 或外部聊天的用户指令
- **THEN** 使用相同的创建、查询和更新契约，不按输入渠道另建任务工具权限。
- **AND** 显式工具配置未授予该工具时不绕过配置；工具操作本身不创建或唤醒会话。

#### Scenario: 目标聊天映射尚不可用
- **WHEN** 创建或更新时显式提供的聊天来源引用尚无既有 IM 会话映射
- **THEN** 明确返回来源暂不可用，不猜测另一聊天、不创建本地影子图；省略来源的写入和已知graph_id查询仍按该图账号归属判定。

#### Scenario: 记录更新发生的聊天
- **WHEN** Agent保存或修改节点
- **THEN** 记录该次更新对应的聊天；普通绑定会话使用实际上下文，全局会话只有明确提供来源才记录，不猜测最近聊天。
- **AND** 只改变本次受影响节点的回聊位置，没有聊天则留空；幂等重试不改写第一次成功记录的来源。

#### Scenario: 返回可查看的同一张图
- **WHEN** Agent 向用户说明任务图及更新结果
- **THEN** 返回稳定图引用，可用的外部回复链接指向既有 Web IM 公开入口；打开后仍登录并检查账号归属。

### Requirement: 工具确认、失败与结果未知按真实情况返回

#### Scenario: 过时修改或无效图
- **WHEN** Agent 提交与新版本冲突或破坏图结构的修改
- **THEN** 得到可操作的错误，旧请求不会覆盖新图或落下部分修改。

#### Scenario: 写入结果未知后重试
- **WHEN** 一次写入未取得确认，Agent 以同一请求身份核实或重试
- **THEN** 不重复创建图或节点；无法核实时不声称已保存。

### Requirement: 图查询与记录不改变既有执行语义

#### Scenario: 查询或标记完成
- **WHEN** Agent 查询图或按用户要求更新一个节点的完成、暂缓、放弃或选定记录
- **THEN** 不消费聊天Inbox，不以此自动执行依赖任务、开子Agent或宣布目标验收通过。
