# IM task-graphs Specification (delta for feat-572)

## REMOVED Requirements

### Requirement: 账号及其名下 Agent 共享持久目标

## ADDED Requirements

### Requirement: 有效成员和具备能力的有效 Agent 共享公司任务

#### Scenario: 跨账号、跨机器与无来源任务
- **WHEN** active 成员或有效接入且启用任务工具的真实 Agent 浏览、搜索或读取任务
- **THEN** 可以读取全公司的同一批图、总目标与子节点，包括私聊创建及无来源的任务；不按 owner、来源群或负责人过滤，分页摘要与全文遵守同一资格。
- **AND** 读取按需发生，不把全量任务自动注入上下文，不自动开工或取得聊天、附件、其他 Agent 配置及本机资源权限。

#### Scenario: 资格失效或借用身份
- **WHEN** Web IM 调用者待批准/停用，或调用 Agent 的管理者未获准公司资格、Agent 未注册、机器失效、工具未启用
- **THEN** 拒绝相应访问，不能通过模型自报身份、旧连接、已知链接或飞书 ownerOpenId 绕过调用主体检查；外部发言人不另行关联 IM 账号。

### Requirement: 公司任务可共同维护且删除须明确授权

#### Scenario: 全员经 Agent 维护
- **WHEN** active 成员交办创建、修改或明确删除任务
- **THEN** 有任务能力的有效 Agent 可以维护公司任务，不增加任务管理员审批；写入保留真实 Agent、可核实发起人及实际来源，不能伪造。
- **AND** 来源聊天及受保护附件继续按对象权限投影，不能借变更信息泄漏其原文。

#### Scenario: 明确删除与冲突重试
- **WHEN** 用户明确指定删除范围或确认 Agent 说明的删除范围
- **THEN** 仅删除相应图或子树，其他任务不变；旧链接明确不可用；没有明确要求/确认不删除。
- **AND** 写操作保持原子 revision 检查，过时请求不覆盖更新，同一写入重试不重复执行或改写原来源，删除回执也可核实。

### Requirement: 群任务视图记录本群创建及编辑的节点

#### Scenario: 从任意群聊天进入本群任务
- **WHEN** 成员在某个群聊天点击“任务”
- **THEN** 展示当前群新建或编辑过的任务节点，打开同一张公司任务图，并能返回原群；切换到另一群时采用新群上下文，不固定示例群。
- **AND** 全局 Tasks 沿用原列表/图/详情入口，仅扩大公司可见范围；本群活动不变成全局页的固定群筛选，回聊继续保留草稿和引用、不自动发送。

#### Scenario: 跨群分解与协作
- **WHEN** A 群创建总目标及分解，B 群更新其中子任务
- **THEN** A/B 各自保留相应图与节点的活动入口，打开同一持久图，不复制任务或用最后编辑群覆盖前群关联。
- **AND** 群过滤只对有权查看该群者开放；所有公司成员仍可从公司任务入口查看任务本身。

#### Scenario: 独立生命周期与最后更新聊天
- **WHEN** 成员退群或群被解散
- **THEN** 公司任务及 ID 保留，任务访问仍按公司资格；失效的聊天关联不再提供跳转。
- **WHEN** 节点从另一个聊天或无来源处被更新
- **THEN** 每节点的快捷回聊指向实际最后更新的有权访问聊天，无来源则留空；不覆盖其他节点的回聊位置，也不删除此前有效群活动关联。

#### Scenario: 保留原图浏览与讨论入口
- **WHEN** 成员打开任务深链或把节点交给另一 Agent 讨论
- **THEN** 既有层级图、面包屑、节点引用复制和回聊追加引用行为保持；保留聊天草稿，不自动发送；手机也可操作。
