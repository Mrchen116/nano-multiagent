## 已确认方向与范围

一条旅程：总览比较进度 → 打开任务读目标与结果 → 编辑 → 在具名面板选状态/负责人 → 明确保存 → 返回刷新后的详情；遇冲突转到独立比较页，处理后保存。逐层浏览、根/子任务创建和群任务入口复用同一状态、身份与内容层级。

## 体验契约

| 场景 | 必须保持的呈现/交互 | 原生适配 |
|---|---|---|
| 总览与子层 | 五组清晰边界和标题计数；卡片标题优先、头像/身份次级、会话/路径及直属完成数；整卡详情与子层入口分开 | 五组纵向、浅底/分隔组织，空组紧凑；保留累计加载与已加载计数，结构画布沿用 |
| 详情 | 会话/父路径 → 标题 → 状态/负责人 → 描述 → 结果 → 子任务；创建者/更新者等次级信息收起；编辑主操作，删除在更多菜单 | 白色正文、24pt 水平间距、动态标题字号、轻分隔、克制 teal 强调；保留领取、结果复制、引用回聊、来源链接 |
| 创建/编辑 | 持续可见字段名，标题突出；描述/结果随内容长高，空字段不预留多行；状态/负责人紧凑行，变更说明按需展开，返工时明确要求 | ScrollView 与原生多行 TextField，键盘可收起，Save 明确提交；未保存取消询问，滑动关闭在脏草稿时禁用 |
| 状态 | 六状态、图标和名称、已选勾选，完整可点行、关闭入口 | 原生独立 sheet，点选只改草稿；完成/关闭语义不变 |
| 负责人 | 会话成员搜索、真人/Agent 可辨身份、头像、未分配、选中标记、关闭入口；陈旧成员不可选 | 复用品牌颜色/真人头像；Agent 显式机器人标识；不存在匹配时空态；全局负责人筛选复用面板但无未分配选项 |
| 保存冲突 | 草稿保留；独立比较页有字段名、“我的修改/最新内容”及逐字段选择；明确确认并保存；不展示整条无标签记录 | revision 409 后读取最新；自动读取仅准备比较，不能自动提交。再遇 409 回到新比较，错误保留草稿 |
| 长内容/大字体 | 正文可读可复制、主要按钮可达、320pt 宽度及大字体不横向溢出，VoiceOver 具名 | 系统动态字体和滚动，选择行最小 44pt，文本可多行，无固定整页高度 |

must-match 为信息顺序、持久标签、内容密度、选择面板身份与选中反馈、明确保存和冲突保留。原生导航栏、sheet detent、系统确认框、具体字号可合理适配；不是把整个 App 改成新设计系统。五组仍有明确区域，但不再使用多层重边框。

## 状态与数据设计

TaskEditorView 持有初始/最近已比较节点 baseline、可编辑 draft 和最新 graph。比较标题、描述、结果、状态、负责人五个字段（负责人按 type:id 比较，不按昵称）。新增 TaskEditField / TaskConflict 值类型负责字段比较与取值，不依赖 SwiftUI。

409 后获取 fresh：对于远端独有改变（draft 等于 baseline），采用 fresh；对于本地独有改变保留 draft；两侧同值无需处理；同字段两侧都改且值不同，列为冲突。比较页展示冲突字段的完整内容，必须逐个明确选择，不预选覆盖服务器；非冲突本地修改保留并在比较页标明保留项。若没有同字段冲突，提示最新更新已合并但仍需明确确认保存。确认后以 fresh revision 为准提交，更新 baseline；再次 409 以该 baseline 重做比较，已选结果仍在 draft。草稿 changeNote 始终保留，done→doing 以 fresh 状态检查原因。删除/拒绝访问不得自动重建节点，保留本地草稿供复制并显示不可保存原因。

API、服务端事务、request_key 与通知不改：完全相同不确定请求重试复用 key，body/revision 改变生成新 key；任何选择都不隐式写入。新建冲突（父层 revision 变化）保留输入，刷新父图后明确重试；父节点删除/无编辑权时不得继续保存。已有 update_task patch 可以继续发送协调后的全部字段，因为 graph revision 保证比较之后没有静默覆盖。

## R9 补充原型范围与实查（2026-10-13）

扩展同一原型，不改变已确认的编辑与面板方向：总览五组（含空组）和计数由示例数据计算；任务保存改变真实示例节点，再按新状态归组。卡片详情与子层分别可点，代表性三层可进入并返回；根/子创建展示所属会话、父任务和结构选择，创建后在原层出现。全局负责人筛选显示根/子节点及父路径；群任务由简化聊天背景进入，同一节点链接回详情。聊天仅静态上下文，不声称重建聊天 UI；仅一个示例群，会话列表为代表性选择状态。创建结构控件示例显示首次拆分上下文，实物仍只在父 mode=none 时显示，子任务自身结构沿用现有创建能力。
