# UI/UX Skill 根因修订与验证

日期：2026-10-13。依据同目录 [根因复盘](retro-pipeline-rootcause.md)，用户要求按根因修改相关 skill，不堆原则和补丁。本记录描述技能修订与验证，不代表产品版本重新验收。

## 改动

修改四个技能目录中的七个文件，以替换原有判断方法与模板提示为主，技能文件总行数不增加：

- change-design-author：共同标准以受影响流程为单位，先决定内容关系、阅读和操作顺序，再映射控件；跨端适配建立在各端已有体验方案之上。实际触发关键选择/反馈状态，静止画面只证明该状态。
- change-design-reviewer：先独立看画面与走路径，再核作者清单；识别被“平台适配”掩盖的设计缺口。
- change-reviewer：从观察事实推导用户能否理解、判断、完成任务；先判断整体可交付性，再合并问题定级，避免把整体设计失配拆成若干不阻塞点击的 minor。相应验收/回归模板同步。
- change-orchestrator：复验按具体结论继承证据，代码未变不能补强旧体验判断；删除要求两轮修复后才能建议 revise-design 的冲突条件。简化 orchestrator 已引用同一文件，无需复制规则。

没有新增角色、审批或固定门禁。change-retro 不变：本次证据没有显示复盘方法需要再增加规则。
