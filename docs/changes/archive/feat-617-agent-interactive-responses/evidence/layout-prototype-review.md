# 消息布局原型走查

2026-10-19，作者在 Chrome 实际渲染 `prototype-layout.html`，1537px 桌面、768px 中间宽度、390px 手机容器。旧/新差异由宿主宽度与外壳表现，原型的内容只是模拟，不宣称新增生成能力。

- 桌面：短句收缩，交互区域横向铺开，摘要、图表、输入框同一左边界；灰色外气泡移除后，内部指标/图表层级可辨。
- 768：保留桌面侧栏后的窄聊天面板仍能展示三列演示输入、指标，底部输入可见。
- 390：侧栏隐藏；控件纵向排列，指标紧凑呈现。实际把本金从 10000 改为 20000，期末结果从 26533 变为 53066，输入框保持可达。
- 修正原型 grid child min-height 后，聊天内部滚动而非整页内容把 composer 推出。
- 截图只保存在 `/tmp/feat617-layout-evidence/prototype-{desktop,768,390}.png`，不入 Git。实际产品验收仍须用未改生成源的真实复利消息、普通短长消息、代码和表格核对；原型仅证明设计方向。
