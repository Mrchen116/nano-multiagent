## 当前产品对照

先登录已运行的 feat-616 隔离 Web IM `/chat/c_04143c1727c6`，查看 1440×1000 实际画面。观察到顶栏、260px 会话侧栏、浅灰 Agent 消息、浅绿本人消息、主列表滚动和底部输入框。PA 专用提醒位于消息列表底部独立区域。原型保留这些导航与阅读线索，将新增交互放在对应 Agent 回复内；没有改动或重启该测试服务。

## 实际操作与观察

- 桌面：先读建议再调整出发时间为 11:00，勾选博物馆；当前选择即时变化。点击继续后仅增加一条本人消息，包含按钮含义与准确选项；原卡片显示已提交并禁用编辑。
- 手机：字段改为上下排列，按钮整行；主列表可滚到按钮、失败提示和后续消息，输入框始终可见。无卡片内纵向滚动层、无横向溢出。整张卡片需要随聊天滚动，摘要和提交区相邻，提交前无需回看顶部。
- 修改草稿后在普通输入框发送“先别发送，把语气改得随意一点”，本人消息同时包含修改后的草稿。演示回复明确先不发送。实际后端/模型行为留给 M1 验收。
- 提交失败：显示“未能提交，当前选择已保留”，按钮变为重试；重试后显示已提交，不伪造发送完成。
- 已替代：按钮禁用并提示已有更新；普通输入仍可用。
- 无法渲染：显示与当前场景匹配的摘要和文字继续入口；没有显示原始 DSL。
- 768px：保留会话侧栏，字段上下排列；继续按钮通过主列表滚动可达，输入框不遮挡列表末尾。

走查修正：选择摘要与点击合并为一条本人消息；草稿演示保留“先别发送”的指令；不同场景的文字降级使用各自内容；重置后滑块标签同步。favicon 的静态 404 已通过内嵌空图标消除。此次不是安全审计，也未验证移动端软键盘、跨设备草稿 API 或真实业务发送。

## 验收资源可用性

本轮确认浏览器可用、隔离 Web IM 可登录。读取 `config/e2e/gateway.yaml` 的模型入口后，对本机代理 `127.0.0.1:4000/v1/messages` 发起 `deepseek:deepseek-v4-flash` 最小请求：HTTP 200、正文 `OK`、`stop_reason=end_turn`。这证明真实模型验收入口可用，不证明 OpenUI DSL 生成质量。M1 起点仍须用固定版本实际生成并渲染三类任务。
