# IM conversations-messages Specification (delta for feat-630)

## ADDED Requirements

### Requirement: 同一次普通 Web 发送在结果未知时幂等恢复

#### Scenario: 消息保存后返回中断
- **WHEN** 用户通过原有输入框发送文字或附件，中心保存后返回中断，随后刷新或重试
- **THEN** 恢复同一次发送的已有消息，不因重试创建第二条交办；确认成功前保留待发内容，不增加内部阶段展示。

#### Scenario: 恢复期间编辑新内容或切换聊天
- **WHEN** 原发送尚在核对，用户编辑后续内容或切换聊天
- **THEN** 原消息的迟到成功不清除后续草稿或其他聊天的内容，重试不把新正文替换进原发送；账号和聊天访问隔离保持。

#### Scenario: 明确再次发送相同正文
- **WHEN** 用户已完成一次发送，又明确发送相同正文
- **THEN** 作为两次真实交办保留，不因内容相同被错误合并。

#### Scenario: 核对本人的发送结果
- **WHEN** 当前真人通过 `GET /im/v1/conversations/:conversation_id/message-attempts/:key` 核对同次发送
- **THEN** 仅在仍有聊天资格且原发送者为本人时返回原消息；未找到返回 404，调用方只能以原身份和原快照重试
- **AND** 其他人的消息、机器凭据或已失去资格的聊天不可通过此入口读取。

#### Scenario: 同一发送身份携带不同快照
- **WHEN** 原发送身份再次用于不同发送者、正文、附件或交互背景
- **THEN** 返回 409，不静默替换旧内容或返回其他人的消息。
