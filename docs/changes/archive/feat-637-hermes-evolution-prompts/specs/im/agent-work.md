# IM agent-work Specification (delta for feat-637)

## MODIFIED Requirements

### Requirement: 从真实发起位置进入子 Agent 的本次执行

#### Scenario: 主动委派和后台维护
- **GIVEN** 主执行真实发起普通子 Agent、fork、记忆整理、技能复盘或记忆与技能联合复盘
- **WHEN** 用户阅读该发起位置
- **THEN** 能辨认用途、普通／fork、主动／后台及真实状态，并直接进入对应本次执行，不依赖顶部名称列表。
- **AND** 后台用途来自真实发起事实，不从内部标签或 UUID 猜测。

#### Scenario: 并行、重复唤起与嵌套
- **WHEN** 用户从并行发起点或同一子会话的不同唤起记录进入，或继续进入下一层委派
- **THEN** 按真实执行身份区分各次范围及父级来源；驻留期间继续收信不被虚构为新的执行。
- **AND** 刷新后仍可从持久发起记录进入同一次执行。

#### Scenario: 联合复盘的用途和范围
- **WHEN** 用户从联合复盘的发起位置进入子执行，或刷新后重新进入
- **THEN** 入口与导航显示“记忆与技能复盘”，指向同一次真实后台 fork 及其执行范围，不拆成两个虚构执行。
- **AND** 用途名称不表示两类知识均已更新；执行状态来自真实运行记录，知识更新只按实际写入报告。
