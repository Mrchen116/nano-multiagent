# im/personal-agent 增量

## ADDED Requirements

### Requirement: 通用个人服务仍以聊天为入口
#### Scenario: 私人状态与控制
- **WHEN** 主人查询正在代办、需要决定、为其留意或记住的内容
- **THEN** 返回真实有来源的相关内容，无结果不生成空工作台；可在原聊天修改、稍后、忽略、停止或忘记，结果以实际回执说明。
#### Scenario: 模式与缺少连接
- **WHEN** 主人调整仅应答、主动准备或授权内代办，或领域连接缺失
- **THEN** 模式不构成新动作授权且不取消明确委托；没有连接仍提供可用准备成果，明确最小缺口，不声称外部动作已完成。
#### Scenario: 交互与附件
- **WHEN** 主人采用草稿、重复反馈或打开生成文件
- **THEN** 草稿只进入正确输入框、旧版本不执行和重复不重复副作用；文件可实际打开，版本与报告一致，失败不假装成功。
