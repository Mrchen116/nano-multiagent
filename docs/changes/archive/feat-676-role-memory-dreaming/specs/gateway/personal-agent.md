# Gateway personal-agent Specification (delta for feat-676)

## REMOVED Requirements

### Requirement: 来源控制仅改变未来访问

## ADDED Requirements

### Requirement: 来源控制停止后续访问与文档记忆采用，保留原始历史

#### Scenario: 排除聊天
- **WHEN** 主 PA 按主人向它提出的原始要求调用来源工具
- **THEN** 后端核实主人与原会话上下文，拒绝后续访问并撤销待处理输入，不清空原始上下文、成果、Git 或备份。
- **AND** document 记忆不得继续采用被排除来源的内容：当前入口和相关页失效，Dreaming 核对或修正并由宿主确认后才恢复有效部分；主执行只传递停止采用约束、不修改正文；已全部消费、无未读消息、关闭 Dreaming 或节点重启均不能绕过。
- **AND** 来源资格已经生效、知识仍待核对与真正完成清理分别报告；无法确定全部派生范围时不宣称已清除或可继续使用。

#### Scenario: 观察文本不控制来源
- **WHEN** 主人向他人说了与来源设置相关的话
- **THEN** 不能仅引用该观察消息替 PA 改变来源权限。

#### Scenario: 外部来源变化和重新允许
- **WHEN** 当前访问资格因成员或来源政策变化而撤销，或主人以后重新允许访问
- **THEN** 权威资格同步覆盖已消费来源，不以未读队列代替完整来源；同步未完成的相关知识仍待核对。
- **AND** 重新允许未来访问不等于自动解除明确的停止使用要求，不将未核对的旧知识整体恢复为有效。
