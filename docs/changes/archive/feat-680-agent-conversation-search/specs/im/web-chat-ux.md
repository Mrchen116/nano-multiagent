# Web 聊天搜索增量

## MODIFIED Requirements

### Requirement: 用户可从聊天列表搜索历史消息

#### Scenario: 查找并定位原消息
- **WHEN** 登录用户在聊天侧栏搜索关键词
- **THEN** 保留会话匹配，并分组展示其可访问的已同步消息，按时间从近到远，显示来源、发送人、时间及片段；点击结果定位原消息及上下文。
- **AND** 非当年消息显示年份；窄屏从原消息返回搜索视图时恢复搜索词、分类、已加载页和位置以继续查看结果。

#### Scenario: 独立搜索视图
- **WHEN** 用户进入搜索
- **THEN** 移动端展示独立搜索页面，桌面端侧栏切换为搜索视图；普通会话列表和固定 PA 入口不与结果同时展示。
- **AND** 清空关键词仍留在搜索视图，主动退出后恢复普通列表；PA 会话在搜索中与其他会话一样参与匹配。
- **AND** 有匹配时按会话与消息分组显示结果和关键词，无任何匹配时显示统一空状态；消息命中可定位原文。

#### Scenario: 权限、分页和状态
- **WHEN** 结果分页、权限变化或搜索失败
- **THEN** 续页只包含当前用户可访问的消息，加载、无结果及失败可区分；搜索不改变未读。
