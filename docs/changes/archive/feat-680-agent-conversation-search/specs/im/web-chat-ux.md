# Web 聊天搜索增量

## ADDED Requirements

### Requirement: 用户可从聊天列表搜索历史消息

#### Scenario: 查找并定位原消息
- **WHEN** 登录用户在聊天侧栏搜索关键词
- **THEN** 保留会话匹配，并分组展示其可访问的已同步消息，按时间从近到远，显示来源、发送人、时间及片段；点击结果定位原消息及上下文。
- **AND** 非当年消息显示年份；窄屏返回聊天列表时恢复搜索词和分类以继续查看结果。

#### Scenario: 权限、分页和状态
- **WHEN** 结果分页、权限变化或搜索失败
- **THEN** 续页只包含当前用户可访问的消息，加载、无结果及失败可区分；搜索不改变未读。
