# gateway agent-capabilities Specification (delta for feat-720)

## ADDED Requirements

### Requirement: 节点浏览器页面能力 SHALL 默认关闭、按显式选择提供，并在本机前置不满足时如实不可用

Agent 可获得“读取本机浏览器页面”和“操作本机浏览器页面”两项能力。两者默认不被任何 Agent 选中；未选中时 Agent 不打开浏览器窗口、不读取页面。能力只在本机具备运行前置时可用，前置不满足时用户得到可理解的缺口说明，而不是一个看起来可用却什么都不发生的动作。

#### Scenario: 新建与既有 Agent 默认都没有浏览器能力
- **GIVEN** 一个从未配置工具白名单的 Agent
- **WHEN** 用户查看它的工具设置并要求它操作浏览器
- **THEN** 两项浏览器能力都处于未选中状态
- **AND** Agent 说明当前没有该能力，期间没有浏览器窗口被打开

#### Scenario: 用户显式启用后生效
- **WHEN** 用户勾选两项浏览器能力并保存
- **THEN** 该 Agent 下一轮新回复可以使用它们
- **AND** 用户取消勾选后，后续回复不再提供

#### Scenario: 本机前置不满足
- **GIVEN** 本机缺少驱动、驱动服务未运行、系统权限未授予，或驱动版本与预期不符
- **WHEN** Agent 尝试执行浏览器任务
- **THEN** 用户看到具体缺少哪一项以及处理方向
- **AND** 没有浏览器窗口被打开，也没有任何动作被描述成已执行

### Requirement: Agent 浏览器操作 SHALL 只作用于自持的隔离实例，前台影响按收窄承诺表达

Agent 打开的浏览器使用独立 profile，不读取用户已打开的标签、窗口或登录态；实例在该 Agent 的浏览器会话结束时（Agent 销毁、真实新窗口后归还前台）或空闲回收时结束，结束一段对话不触发回收，不保留持久登录状态。产品对前台影响的承诺是：不抢焦点地操作页面；新窗口或首次接入可能短暂占前台。该承诺是上限而不是时长保证，不得改写成绝对表述。

实例的首次启动只发生在用户发起的对话轮次：只有该轮次仍在进行、且用户最近一次发言在约 5 分钟内时，主 Agent 或它在这一轮里同步委派的子 Agent 才可能新开实例。更早的委派（长轮次末端）与后台委派（那一轮已结束）只复用已有实例；定时、心跳、任务续跑轮次及其派生的子 Agent 同样不得新开实例。需要新实例时 Agent 说明需要用户先在对话里发起。页面脚本打开真实新窗口时，Agent 在完成本次回读后结束该实例，把前台归还用户；继续操作页面需要新的用户轮次。

Global/PA 的系统 Inbox 提醒不产生在场资格；只有本轮读取的新鲜、完整、直接真人 participant 消息才按原始发言时间参与判定。历史恢复、partial、observer、PA 代发及非真人材料不刷新资格。真实窗口归还后，同祖先同轮次内另派子 Agent 或补入真人消息不能重新开窗，须新一轮。

#### Scenario: 用户已有窗口与登录态不受影响
- **GIVEN** 用户自己的浏览器开着多个窗口并已登录站点
- **WHEN** Agent 执行浏览器任务
- **THEN** 出现的是独立窗口，用户原有窗口、标签与登录态不变
- **AND** Agent 读到的内容不包含用户已登录的页面

#### Scenario: 页面内动作不切换前台
- **GIVEN** 用户正在前台应用里输入，Agent 的实例已经启动
- **WHEN** Agent 在自持实例里导航、读取、点击、输入、滚动
- **THEN** 前台应用始终是用户原来那个应用

#### Scenario: 新窗口或首次接入可能短暂占前台
- **WHEN** 页面脚本打开新窗口，或本次任务在用户发起的轮次里首次启动独立实例
- **THEN** 浏览器可能短暂成为前台应用，用户输入可能被打断
- **AND** Agent 在结果中说明发生了新窗口或首次接入，用户可切回自己的应用

#### Scenario: 无人值守轮次不新开实例
- **GIVEN** 一次无人值守、任务续跑或后台委派轮次（含这些轮次派生的子 Agent），且当前没有该 Agent 的浏览器实例
- **WHEN** Agent 需要读取或操作页面
- **THEN** 它不启动新实例，也不弹出浏览器窗口
- **AND** 它说明需要一个用户发起的对话轮次才能启动浏览器

#### Scenario: 用户轮次里委派的子 Agent 可以新开实例
- **GIVEN** 用户在对话里发起一项需要浏览器的任务，主 Agent 把它委派给子 Agent
- **WHEN** 子 Agent 需要浏览器实例且当前没有
- **THEN** 允许启动该请求的独立实例（本轮仍由用户发起）
- **AND** 若该请求来自定时、心跳或任务续跑轮次，子 Agent 同样不得新开实例

#### Scenario: 真实新窗口后前台归还
- **GIVEN** 页面脚本打开了一个有独立地址的真实浏览窗口
- **WHEN** Agent 完成本次回读与证据保存
- **THEN** 它结束该浏览器实例，前台回到用户原来的应用
- **AND** 继续操作页面需要用户再发起一轮

### Requirement: 浏览器动作 SHALL 经既有审批，并在目标身份不确定时拒绝执行

会改变页面或发出请求的动作都经过既有自动审批与人工审批语义；只有只读页面读取可按既有安全工具规则自动放行。无人值守轮次不会因为无人值守回退配置而自动放行页面动作；没有人工审批出口的会话里，需要人工确认的动作被拒绝，Agent 说明并停止。页面或标签身份发生变化后，动作必须落在 Agent 确认过的页面上；无法唯一确定目标时拒绝执行并说明，不按位置猜测。

#### Scenario: 用户拒绝后没有副作用
- **WHEN** 用户拒绝一次浏览器动作的审批
- **THEN** 页面没有变化，Agent 明确说明动作被拒绝
- **AND** Agent 不重试同一动作，也不换元素或换工具达到同样效果

#### Scenario: 没有人工审批出口时不自动放行
- **GIVEN** 一次由定时任务、心跳或后台委派触发的轮次
- **WHEN** Agent 的页面动作需要人工确认
- **THEN** 该动作不执行，也不会因为无人值守的自动放行配置而执行
- **AND** Agent 说明这一步需要在用户发起的对话里确认

#### Scenario: 超出边界的请求被拒绝并说明
- **WHEN** 用户要求 Agent 登录账号、提交表单或下载文件
- **THEN** Agent 说明这些不在浏览器能力范围内，不执行
- **AND** 它不会先用别的动作绕到同一个结果

#### Scenario: 新标签成为当前标签后不点错页面
- **GIVEN** Agent 正在处理一个页面
- **WHEN** 页面在新标签打开内容并成为当前标签
- **THEN** 下一次点击或输入落在 Agent 正在处理的页面上
- **AND** 不会因为标签顺序变化而操作到另一个页面

#### Scenario: 目标无法唯一确定时拒绝
- **GIVEN** 同一窗口里有两个地址和标题都相同的标签
- **WHEN** Agent 要在该窗口执行动作
- **THEN** 它报告无法唯一确定目标并说明下一步
- **AND** 不任选其中一个标签执行

### Requirement: 浏览器界面噪声与真实窗口事件 SHALL 被区分，失败不得伪装成成功

浏览器自身的界面弹层不是页面事件，也不等于失败；只有确认为独立浏览窗口的事件才需要报告。驱动返回空或无法解析的结果时按失败处理，不得描述成动作已完成。

#### Scenario: 浏览器自带弹层不打断任务
- **WHEN** 浏览器弹出无标题、固定小尺寸、没有自己页面地址的界面弹层
- **THEN** Agent 继续任务，不报告失败
- **AND** 不为“处理该弹层”重复上一个动作

#### Scenario: 真实新窗口被报告
- **WHEN** 页面打开了有独立地址的真实浏览窗口
- **THEN** Agent 将其作为事件说明，并在回读后结束实例以归还前台
- **AND** 无法判断时结束本次动作并说明，不自动重试

#### Scenario: 空响应不是成功
- **WHEN** 驱动返回空或无法解析的响应
- **THEN** Agent 报告这次动作失败，并说明可以怎样继续
- **AND** 不把空结果描述成页面已更新或动作已完成

### Requirement: 浏览器页面结论 SHALL 以画面证据为准，读数不得冒充已验证

Agent 对“元素可见”“已滚动到某处”一类位置结论，必须以它拿到的画面为证据；只有读数、没有画面时须明示未验证。本能力生成在 Agent workspace 中的源 PNG 是临时证据：每个产品 Agent 最多 20 张，按 1 小时 TTL 在写入新图时及进程启动期有界补清，非到点自动删除；实例结束和 Agent 销毁不立即删除。

该清理仅覆盖本能力的源 PNG 缓存，不覆盖既有会话工具历史或官方 `read_image` 创建的独立运行时附件。页面文本、工具结果与 Agent 文字结论沿用底座现有会话与记忆取材规则；本 unit 不新增浏览器内容的记忆屏蔽、附件副本清理或长期保存保证，不改变原有操作、secret 与无关内容保护边界。

#### Scenario: 位置结论与画面一致
- **WHEN** Agent 声称页面已滚动到某个位置或某个元素在视口内
- **THEN** 它给出的画面证据支持该结论
- **AND** 读数与画面冲突时以画面为准并说明不一致

#### Scenario: 只有读数时明示未验证
- **WHEN** Agent 只有语义读数、没有拿到画面
- **THEN** 它说明该位置结论未经验证
- **AND** 不把读数描述成“已经看到”
