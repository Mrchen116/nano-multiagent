# IM agent-work Specification (delta for feat-727)

## ADDED Requirements

### Requirement: Web 工作记录的关联入口归属于对应轨迹卡片

#### Scenario: 连续子执行返回与 Agent 消息
- **GIVEN** 一轮主工作记录包含连续子执行返回或 Agent 消息，且已有真实来源执行
- **WHEN** 用户阅读这些消息并点击关联入口
- **THEN** 每条消息在自身卡片内部紧凑展示入口，点击后打开各自对应的执行；入口不单独形成另一张轨迹卡片。
- **AND** 不同来源分别进入各自执行，同一来源的重复消息保留同一来源归属。

#### Scenario: 折叠委派工具与后台结果
- **GIVEN** 工具或后台结果记录已有可查看的关联执行
- **WHEN** 用户尚未展开完整参数或结果
- **THEN** 仍可在所属卡片内部点击入口查看对应执行，原有调用与执行状态按真实记录展示。
