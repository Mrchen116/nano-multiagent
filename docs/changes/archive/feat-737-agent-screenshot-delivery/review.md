## 无成品示例复测

在隔离 Nano IM 中用 `codexOAuth:gpt-6.1-sol` 和三个新建 Global Agent 各跑一次全新任务。本 unit 已删除新增的截图对比范例。复测另在隔离环境删去 Skill 原有的成品示例及布局片段，保留组件签名、索引规则、通用指导和语法参考。对比与交接两个 Agent 的 DSH `skill` 工具结果都包含该版本正文与 `AttachmentImage` 签名，没有成品示例。用户输入给出任务目标和本地 PNG 测试图路径。仅交接任务明确指定图文卡片，三个任务均未指定组件或提供布局。

| 场景 | 实际结果 |
|---|---|
| 搜索页验收 | Agent 读取两张图，自行用并排卡片标注改动前后，附差异清单与截图能确认的范围。一条发图消息 `c9c84cf7ef304126b6bc08336f6d4365` 引用两张原图。Web 可点开原图，刷新后两图仍在卡片内。 |
| 普通巡检通知 | Agent 直接用一条文字和图片附件消息交付，保留两项待办的未完成状态。消息 `863ff6dd9fc2421a8bf35e6fb63395db` 在 Web 可点开原图。 |
| 晚班值守交接 | Agent 自行将现场图放在位置说明里，用表格列出三项待执行事项的时间、负责人和状态。卡片消息 `b236fe963c8f430a8a31dd795a3132f8` 只引用一张原图。Web 表格逐行显示负责人和待执行状态，图片可点开原图。 |

独立复核发现两处 PA 审核缺口。两项都有修复前失败证据及修复后的定向断言。

- 公开群历史可被有资格的非成员读取。审核现在收到这一可读范围，提交事务再次核对。私密群转公开且成员不变时，旧审核无法发送。
- 卡片附件位置可能重复，图片快照按 URL 去重。审核收到实际有序位置，按一基索引匹配冻结的附件，因此可以准确核对卡片在每个位置呈现的图片。
