独立产品旅程与 Web 窄屏检查由 `feat738_design_reviewer` 执行，受审树为 `e10bca38e`，使用隔离 IM、Node、锁定 DSH 和本地受控 SSE provider：

- Global A 产生原生主、子会话和已发布聊天，经确认停用后删除。两份日志物理消失，旧 Work 与轨迹入口返回 410，原聊天和默认保留的工作区文件可读。向旧聊天提交的新消息仍保存，受控 provider 在两秒观察窗内未收到 A 的对应执行。
