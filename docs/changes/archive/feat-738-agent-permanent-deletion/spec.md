# feat-738：永久删除 Agent

## 原始需求

> 我觉得得有删除功能

这条需求来自一次磁盘清理。一个已停用的 Global Agent 仍占有约 9.3 GiB 的子会话数据，用户无法从产品里清理。现行[启停契约](../../../specs/im/agents-nodes.md#requirement-真人管理者可以独立启用和停用-agent)支持停止执行并保留资料，适合稍后继续使用。

## 澄清记录

- 问：永久删除 Nano Agent 时，工作区文件要怎么处理？两种方案都会删除该 Agent 独占的执行数据（包括子会话），并保留 IM 聊天消息。
- 答：「提供单独勾选，允许一并删除专用工作区」
- 对同节点维护窗口的答复：「这不对啊，我们要求该agent被关停再删除。其他agent跟我们删除的有啥关系，没有重叠吧？必然不能影响到其他的agent啊。」

## 用户场景

一个普通或 Global Agent 已结束职责。所有者在 Agent 详情中停用它，确认受管执行已停止后发起永久删除。确认时能认出目标 Agent，知道执行会话和轨迹会清理，历史 IM 消息仍可回看。所有者可以保留工作区文件，也可以明确选择同时删除该 Agent 的专用工作区。

如果节点失联或清理失败，所有者能看到实际进度和原因，并在恢复后继续。清理完成后，Agent 退出可使用列表，原有私聊和群聊的消息仍按原权限可读，曾经由它发出的消息仍显示发送者。

同一节点上的其他 Agent 可以在删除期间持续执行和接收新工作。删除只要求目标 Agent 已确认停止。

## 验收标准

### Requirement: 所有者可以确认永久删除一个已停用的 Agent

#### Scenario: 所有者确认删除
- **GIVEN** 普通或 Global Agent 已确认停止，所有者打开它的管理详情
- **WHEN** 所有者发起永久删除
- **THEN** 确认界面明确标识目标 Agent、不可恢复性、要删除的运行数据、保留的聊天消息和工作区选项
- **AND** 只有明确确认才提交，取消时保留现有 Agent 和资料

#### Scenario: 尚未确认停止或没有权限
- **WHEN** Agent 仍可运行、停止尚未确认，或操作方是非所有者、Agent 自身
- **THEN** 删除不可提交；有权操作的所有者可从现有入口完成停用并查看停止结果

### Requirement: 删除回收 Agent 独占的执行数据，聊天历史保持可读

#### Scenario: 完成删除并回看历史
- **GIVEN** 目标有自己的运行会话、派生子会话和已发出的 IM 消息
- **WHEN** 产品确认永久删除完成
- **THEN** 目标的独占会话、子会话、轨迹及相关运行数据已清理，独占的自动触发安排不再触发
- **AND** 目标从 Agent 列表和新聊天的可选对象中消失，旧聊天不再向它投递新工作，节点重连或重启后也不会重新出现
- **AND** 原有消息、聊天附件和共享任务仍按原权限可读；历史中能辨认该发送者，指向已删除执行轨迹的入口显示记录已删除
- **AND** 其他 Agent 的执行数据、工作区及共享资源可继续使用

#### Scenario: 同节点其他 Agent 正在执行
- **GIVEN** 目标 Agent 已确认停止，同节点另一个 Agent 正在执行
- **WHEN** 所有者永久删除目标 Agent
- **THEN** 删除可以在另一个 Agent 执行期间完成，另一个 Agent 的在途工作、共享执行进程、新工作接收和正常历史读取都继续进行

### Requirement: 专用工作区须单独选择才删除

#### Scenario: 使用默认选项
- **WHEN** 所有者确认永久删除并保持工作区选项未勾选
- **THEN** Agent 独占的运行数据已清理，工作区文件仍可在原位置访问

#### Scenario: 勾选清理专用工作区
- **GIVEN** 系统可确认工作区专属于目标 Agent
- **WHEN** 所有者勾选该工作区并确认永久删除
- **THEN** 确认界面指出要删除的工作区，清理完成后该工作区文件也已移除
- **AND** 共享或无法确认专属的工作区不可选，文件保留

### Requirement: 删除状态以实际清理结果为准

#### Scenario: 清理未完成
- **WHEN** 删除期间节点不可达或清理未能完成
- **THEN** 所有者能区分等待节点、删除中和清理失败，看到原因及可用的继续或重试操作
- **AND** 清理未确认前不显示删除完成，目标保持停止；恢复后沿用已确认的范围，重复操作得到同一个删除结果

## 范围与非目标

- 范围为普通和 Global Agent 的产品管理入口、独占执行数据清理、可选的专用工作区清理以及 IM 历史展示。
- PA 的账户绑定与生命周期、独立的聊天删除、自动清理策略和单会话删除由各自需求处理。
