# IM Agents and Nodes Specification (delta for feat-738)

## ADDED Requirements

### Requirement: 所有者可以永久删除已确认停止的普通或 Global Agent

#### Scenario: 确认删除和专用工作区选项
- **WHEN** 真人所有者在管理详情删除一个已确认停止的普通或 Global Agent
- **THEN** 在提交前显示目标、永久删除的执行数据与保留的 IM 历史，允许取消
- **AND** 工作区默认保留。所有者可以单独选择删除已确认专属于目标的工作区，选择时显示目录；共享或不能确认专属的工作区保留

#### Scenario: 权限或停止条件不满足
- **WHEN** 操作者没有所有权、操作者是 Agent，或目标尚未确认停止
- **THEN** 不能提交删除

#### Scenario: 等待、失败和重试
- **WHEN** 已确认删除的操作等待节点、执行中或清理失败
- **THEN** 所有者看到实际状态及可采取的动作，目标保持停止，重试沿用原确认范围
- **AND** 只有节点和中心均确认清理完成，才显示已删除

#### Scenario: 删除完成后的旧聊天和新入口
- **WHEN** 删除完成后查看原聊天、共享任务或 Agent 列表
- **THEN** Agent 不再出现在可用列表或新聊天候选中，已有聊天不再向其投递工作，重连或重启不恢复它
- **AND** 原有 IM 消息、聊天附件、发送者身份与共享任务按原权限可读；有权用户打开已删除执行的旧链接时能看到记录已删除
