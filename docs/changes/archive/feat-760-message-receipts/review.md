## Findings 与关闭

- R1。Gateway 的 `message.receipts_changed` 曾携带实际 `message_id`。Dreaming 的截止点查询会将随后出现的关联事件视为消息版本变化，进而排除原消息。`13b7df8b5` 将它改成会话级刷新，端到端用例检查两个阶段都不关联消息版本。独立复核关闭。
- R2。某飞书 App 或消息不可用时，共享队列在首个失败项返回，其他 Bot 的回执因此积压。`a0f3b7584` 将失败项留到下轮并继续同一轮其他项。独立复核关闭。
- R3。Web 和 iOS 送达确认在网络错误后丢失，虽然用户流游标已前进。客户端改用后台队列，Web 对仍有效会话下的临时 401 继续重试。Web 测试覆盖网络失败、401、200，iOS XCTest 覆盖 503 后重试。独立复核关闭。
- R4。Web 回执更新导致时间线丢失已加载的旧页。普通刷新保留旧页和游标，失效恢复重新按服务端快照取历史。独立复核关闭。
- R5。Web 群回执在滚动容器内裁切。详情改为独立可滚动的浮层，集成测试覆盖 12 位成员。打开旧消息的详情也会读取发送者有权查看的实时回执。独立复核关闭。
