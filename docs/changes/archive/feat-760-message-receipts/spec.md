## 用户场景与验收

### Requirement: 发送者可辨认消息送达和已读

#### Scenario: 私聊
- **WHEN** 真人在 Nano 私聊发送普通消息给真人或 Global Agent
- **THEN** 发送者从消息旁的一组勾辨认待送达、已送达或已读，并可展开收件人的状态

#### Scenario: 混合群聊
- **WHEN** 真人向同时包含真人和 Agent 的群聊发送消息
- **THEN** 发送者看到一组汇总勾。发送时的其余群成员全部收到后显示灰色双勾，全部已读后显示青色双勾
- **AND** 展开详情即可看到头像、名字和对应状态
- **AND** iOS 的勾放在气泡右下角，点勾打开详情

### Requirement: Agent 执行与回执反馈独立推进

#### Scenario: Inbox 读取与飞书回执
- **WHEN** 普通 Global Agent 收到应响应的飞书消息，并通过 Inbox 读取完整消息
- **THEN** Bot 先对原消息添加收件表情，读取后换成已读表情
- **AND** 即使回执服务暂不可用，Agent 仍可完成读取和后续工作

范围包括 Web、原生 iOS 和上述飞书 Bot。Nano 回执以新发送的真人消息为入口。
