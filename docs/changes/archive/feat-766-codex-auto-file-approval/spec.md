生产会话 `347e4415-02a9-4cfe-b6c9-3ac2b7c5abec` 的原始样本中，173 次 `edit` 都位于 `/private/tmp`，调用到结果的中位数为 8.54 秒，其中审核中位数为 8.32 秒。该子会话恢复后的快照仍启用 Codex 审核，主会话已使用跳过审核配置。

### Requirement: Codex Auto 放行普通文件编辑

#### Scenario: 普通文件编辑与创建

- **GIVEN** Codex Auto 开启，工具自身约束允许，且没有需要模型解释的自定义审批规则
- **WHEN** Agent 通过 `edit` 或 `write` 操作当前工作区或系统临时目录内的普通文件
- **THEN** 直接执行，Work 中的调用耗时省去模型审核等待。

#### Scenario: 特殊路径与其他工具

- **WHEN** 文件目标在范围外、实际路径越界、属于受保护位置，或无法确定满足免审条件
- **THEN** 走原有审批流程。
- **AND** `bash`、读取、搜索和消息工具沿用各自的审批行为。工作区和系统临时目录是默认边界，用户无需为每个 worktree 配置额外授权。

### Requirement: 子会话恢复应用当前审批配置

#### Scenario: 既有子会话接续

- **WHEN** 所属 Agent 的新审批配置已生效，既有子会话恢复并开始下一轮
- **THEN** 使用当前 Auto 开关、跳过审核开关、审核规则及审批模型。
- **AND** 任务历史、委派范围和授权证据继续可用，已在执行或已发起审批的调用仍对应原策略。
- **AND** 从启用改为跳过及从跳过改回启用均生效，旧会话可接续。
