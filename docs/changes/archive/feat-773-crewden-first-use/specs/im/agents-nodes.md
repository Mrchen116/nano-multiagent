## ADDED Requirements

### Requirement: 创建助手时可选择统一且可辨认的角色头像

- Web 的 PA 首次设置、PA 创建弹窗与普通 Agent 创建页在名字旁提供已预选的头像，允许选择四种样式与六种颜色，不增加必填步骤。
- PA 使用圆润的有机轮廓与轻微微笑，普通 Agent 使用拱形、菱形、纸片和星芒等几何轮廓；两类均以简洁眼神表达性格，不叠加面罩或机械配饰。已有 Agent 未选择头像时按稳定 Agent ID 生成默认组合，改名不改变默认形象；组合不是全局唯一身份，姓名仍显示。
- 选择以可选 `avatar_variant`（0–23 的整数）随创建请求保存，中心服务拥有该身份信息；配置执行请求及其运行时指纹不包含该字段，待确认请求从原创建记录恢复已选形象。
- 绑定、联系人、会话参与者、历史与实时消息的身份投影携带所选头像，Web 列表、私聊、群聊、成员与提及选择器使用同一组合。PA 代主人发言仍保留主人的身份呈现。

## MODIFIED Requirements

### Requirement: 托管 IM 提供连续首次设置

新个人用户可从连接电脑、连接模型、定义首个助手一路进入真实聊天。安装页提供可复制给本地 Agent 的 prompt 和可直接运行的手动命令，都针对当前 IM，不包含用户密码或模型凭据。进度由真实节点、模型和助手状态恢复；已有用户不被强制重新引导。

#### Scenario: 短窗口完整完成设置

- **GIVEN** 首次设置步骤的表单内容超过当前窗口高度
- **WHEN** 用户在桌面或手机上继续填写设置
- **THEN** 可纵向滚动到完整表单、保存与继续操作，不因屏幕高度被截断。

#### Scenario: 安装并恢复
- WHEN 用户运行页面提供的安装方式并确认设备绑定
- THEN 页面显示本人电脑并继续模型步骤；重复安装/刷新不重建身份或丢失数据。
- AND 首次连接确认展示当前账号和电脑，并以连接成功引导继续设置；只有整机交接使用设备转移文案，不将首次连接描述为转移。绑定页与首次设置使用聚焦的设置页头，分别呈现账号确认与电脑端连接进度，实际提交完成前不展示连接成功。

#### Scenario: 有指导的助手创建
- WHEN 用户选择用途、名称与目标并完成创建
- THEN 获得独立助手及工作目录，进入真实聊天并可发送符合用途的起步任务；建议不冒充真实回复。
- AND 首次设置用个人助手、电脑和模型等用户可理解的称呼；创建前的连接摘要优先展示模型显示名，不以内部服务标识代替模型名称。

### Requirement: Agent 配置页可直接编辑工作区角色约定

#### Scenario: 管理者直接读写角色
- **WHEN** PA 主人或独立 Agent 的管理者在 Web 或原生 iOS 打开使用文档记忆的 Agent 配置页
- **THEN** 页面可读取工作区现行角色约定并提供编辑入口。本人主动保存就是对这份约定的确认。
- **AND** 保存成功表示节点已保存 `.nanoassistant/ROLE.md`。清空后页面显示未设置，主 Agent 恢复主动对齐。Web 使用页面底部的 Save Agent 统一提交角色及普通配置修改，不提供独立角色保存按钮；仅修改角色时不重提普通配置，放弃修改同时清除两类草稿。原生 iOS 保留既有保存交互。
- **AND** Web 先保存已修改角色，再保存已修改配置；角色失败保留两类草稿，配置失败保留配置草稿并显示错误，不把整个页面报为保存成功。重试只提交仍未保存的修改。

#### Scenario: 草稿超过角色约定长度上限
- **WHEN** 角色约定草稿超过 2,000 个 UTF-16 码元
- **THEN** Web 和原生 iOS 显示长度提示并禁用保存。直接提交超限内容时，服务端拒绝写入。

#### Scenario: 编辑期间角色变化或节点不可用
- **GIVEN** 用户有未保存的角色草稿
- **WHEN** 文件版本变化、读取失败、连接断开或保存结果未确认
- **THEN** 保留草稿，显示可确认的状态。获取当前版本后，由用户核对再主动保存，旧草稿不自动覆盖现行文件。

#### Scenario: 角色约定是管理者专用内容
- **WHEN** 非管理者浏览公开资料或请求角色设置
- **THEN** 不获得约定正文或编辑能力。节点当前无法读取时，页面不会将未取得的数据视为未设置。

Global 创建后的管理者私聊首屏引导，见[首次建立合作约定](personal-agent.md#首次建立合作约定)。
