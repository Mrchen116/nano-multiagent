## MODIFIED Requirements

### Requirement: 固定个人助手保持原 IM 体验
#### Scenario: 聊天列表中的固定个人助手
- **WHEN** 主人查看 Web 聊天列表
- **THEN** PA 保留独立的置顶聊天入口，使用普通聊天行呈现最新消息摘要、消息时间与未读数，不用告警式底框或固定角色说明覆盖已有消息。
- **AND** 摘要与普通聊天使用相同的 mention、卡片和系统通知呈现，收到更新与已读变化时同步刷新；尚无消息时可显示角色说明。固定入口与工作区欢迎页使用会话当前标题，手动命名不被助手配置保存覆盖。

#### Scenario: 工作电脑保持固定
- **WHEN** 主人打开 PA 配置页
- **THEN** 不提供跨电脑迁移入口；PA 专用换机接口不可用，不能借该接口改变现有绑定、工作区或聊天归属
- **AND** 已有 PA 的日常配置、聊天访问控制与当前运行位置继续沿用

#### Scenario: 创建、改名和配置
- **WHEN** 用户创建或配置自己的 PA
- **THEN** 固定主人关系与私聊入口保持，使用原 Agent 设置与导航；他人可联系 PA，但不能读取主人私人配置和 Work。
- **AND** 已创建PA的聊天配置入口直接进入现有Agent配置页；名字、模型、指令、技能与聊天访问范围在同一页维护，不另设PA设置浮窗。来源勾选明确立即生效；创建与未完成创建的恢复仍使用原设置流程。

#### Scenario: 创建与第一条消息分开
- **WHEN** 用户在首次设置或聊天入口创建 PA
- **THEN** 只填写助手名字，创建后进入空白主人私聊；不收集或自动发送首个任务。
- **WHEN** 主人第一次进入已确认没有历史的 PA 聊天，且输入框为空
- **THEN** 先展示可尝试的小任务，背景介绍与长期职责入口按[首次建立合作约定](#首次建立合作约定)按需展开；点击提示仅填入并聚焦普通输入框，由用户编辑后发送。
- **AND** 发出第一条消息后隐藏整个引导，已有历史的聊天不再显示；已有草稿或附件时不覆盖，查看他人的 PA 时不显示主人职责引导。

#### Scenario: 刷新后恢复未完成的创建
- **WHEN** 电脑尚未确认 PA 创建，用户刷新首次设置页面
- **THEN** 页面显示可重试的准备状态，恢复同一助手与原电脑，不打开尚未建立的聊天；只有确认创建完成才进入私人对话。

#### Scenario: 注册后创建并沿用同一个 PA
- **WHEN** 新用户注册并在首次设置中连接电脑、确认可用模型和创建助手
- **THEN** 创建的是该用户固定的 PA 与主人私聊，个人使用无需等待公司批准。
- **WHEN** 用户随后申请加入公司并获批
- **THEN** PA、绑定与主人私聊身份保持，既有消息、配置和工作上下文继续沿用；不再要求创建第二个 PA，也不把私人聊天与 Work 发布给公司。

### Requirement: PA 创建使用原主人来源与既有节点创建边界

#### Scenario: 创建可在现有产品中使用
- **WHEN** 可信主 PA 根据主人向它提出的原始创建要求完成创建
- **THEN** 新 Agent 出现在本人的现有列表，可长期聊天并经现有配置页维护；创建仍遵守本人绑定节点、在线校验及实际工作区和能力校验。
- **AND** 观察内容、他人消息或 PA 自己代发的消息不能成为新的主人创建依据。
- **AND** 首次提交配置操作前，即使经过排队或能力查询等待，主 PA 的绑定、原执行代次和主人来源仍须有效；已接受操作继续按原回执确认实际结果。

#### Scenario: 同次请求恢复与冲突
- **WHEN** 同一次创建遇到断线、重启或结果尚未确认
- **THEN** 按同一请求确认原操作，不重复创建，未确认时不宣称成功。
- **AND** 请求标识被用于不同目标或配置时拒绝混用；离线、权限、ID/路径或配置冲突均明确说明，不静默换机。

### 首次建立合作约定

PA 创建时可按 [Agent 身份头像](agents-nodes.md#requirement-创建助手时可选择统一且可辨认的角色头像)选择形象，创建后直接进入主人私聊。已确认无历史的首屏优先提供理清想法、安排一周、找到第一步等小任务；点击仅填入空输入框并聚焦，由主人修改并发送，已有草稿或附件时不可覆盖。背景介绍与长期职责引导放在可展开的可选入口；选择稍后只隐藏职责引导，仍可选择小任务或自由输入。背景按正常对话／记忆流程处理，不能把发送成功表示为永久记忆成功。

同一入口也覆盖绑定管理者与 Global 数字员工的私聊，内容转为工作背景、负责结果、交付标准及分工；Global 创建成功直接打开私聊，打开失败则落到已创建的设置页提示重试，不重复创建。普通联系人、群聊和单线程 Agent 不显示职责引导。

引导只在已确认没有历史消息的主人／管理者私聊中展示。用户发出第一条消息后移除整个引导，不继续展示职责讨论状态、保存状态、继续入口或 ROLE 正文；刷新和返回已有聊天也不再展示。职责入口仅通过现有 role API 判定是否已有职责，创建时已保存职责的 Global 不重复引导；不轮询角色状态，读取失败或离线时不展示职责引导，个人助手的小任务草稿入口仍可用，不表示助手已在线。职责讨论、确认与保存结果由正常对话承接，角色文档仍在原设置页维护。
