## 审查修正

1. 混合飞书与 Web 来源的同一忙碌轮次曾沿用首个聊天入口。387b0a73e 按最新触发来源决定最终回复目标，覆盖两种渠道切换方向。
2. 队列中的会话控制曾持有收紧前的旧意图。387b0a73e 将两种模式的持久化命令纳入清退，在实际执行与发布时重新检查取消状态，覆盖正在等待 session.ensure 和排在其后的命令。
3. 授权历史读到了原生界面给消息加的短 ID，导致合法的结构化工具结果解析失败。cb0f91c3b、407752e5c 将范围替换绑定到精确的原生事件序号，6585478d7 覆盖原生显示层再次替换已清退的消息。委派授权、模型交接及原始授权保留的 15 项定向回归通过。独立审查确认上述问题关闭，最终 delta 与可观察行为一致。
