# 跨机预览实现

Air 按本机身份与 worktree 的绝对路径生成实例 ID，Mini 在共享入口配置的测试子域名中原子领取一个空闲项，使用 SSH 将明确的 Git 版本送到 Mini 的专属开发目录。每个实例拥有独立源码、运行目录、IM 端口、数据库、管理员口令和 Gateway。默认 IM 和 Gateway 均在 Mini，浏览器在 Air，经公网访问。测试子域名的 DNS、TLS 和通往 Mini 的测试 Tunnel 由独立基础设施提供。

共享测试 Tunnel 的唯一源站为 loopback 上的 Traefik。使用 file provider 读取私有目录内每实例一份 Host 路由，原子写入或移除该文件，仅接受该域名的 HTTP/WS。应用登录使用随机口令；通过公网登录并核实预期测试节点后交付 URL。单实例操作串行，不锁其他实例。更新在原运行目录复用身份、数据和凭据；停止先移除路由，再停该实例进程。共享入口不随单实例重启。

## 本次审查安排

独立审查实例归属、测试账户和正式入口隔离，以及版本、更新和失败恢复。验收分别记录本地进程、真实两机及公网 TLS/WS 的实际证据。无产品行为契约变化。

## 初始化、更新与访问

首次启动在新目录运行 E2E 初始化，写入随机管理员口令、JWT、SQLite、绑定密钥及节点配置。复用 E2E 的 IM 进程启动逻辑；更新只重建代码、按原端口启动 IM，并用原配置重启 Gateway。更新失败保留数据和入口归属，可用可构建的版本再次更新。新实例首次初始化失败则撤销本次分配。原本地起栈的重置语义保持。验收在 A 写入记录后执行更新，读取同一记录与节点，覆盖失败重试的数据保留。

Mini Gateway 连接本机隔离 IM，IM_PUBLIC_URL 使用实例的完整 HTTPS 地址，浏览器登录、WS ticket 与 WSS 使用同一 Origin。操作者通过 SSH 读取实例私有口令；从 Air 真实浏览器建立登录会话，持有 B 的 WSS，在撤掉 A 后经 B 创建事件并在原连接接收。首批入口为 preview-a.nanoim.win 和 preview-b.nanoim.win；独立测试 Tunnel、Traefik 与子域名作为共享设施保留，down 只归还本实例。入口均被占用时 up 提示容量已满。
