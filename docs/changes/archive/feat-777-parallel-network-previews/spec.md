# 多 worktree 跨机试用

## 原始需求

> 本地速度太快了，根本没体验出来感受。
>
> 然后现在我们本地的这个测试环境，我们是可以支持同时多个Worktree多个feature去做实验的，对不对？那跨机的也应该支持
>
> 可以啊，那你落入到仓库中。

## 用户场景

开发者在 Air 的两个 worktree 同时试切换聊天与派工同步，两套候选在 Mini 独立运行。用户从自己的浏览器分别打开两个测试子域名，使用可重复的测试数据体验真实网络上的等待和恢复。用户已确认共享专用测试入口、每个 worktree 各有 URL，分别更新、分别停止。

### Requirement 独立访问
#### Scenario 同时试用
- WHEN 两个 feature 启动并分别打开其 URL
- THEN 各自显示对应版本、测试节点和数据；A 创建的记录在 B 不可见。

### Requirement 独立生命周期
#### Scenario 更新和停止
- WHEN 更新 A，再关闭 A
- THEN 更新后 A 的原链接和数据可继续使用；关闭后 A 失去入口，B 的现有实时连接仍可读写。正式入口持续使用原服务。
