## 独立审查与关闭

- 视觉与交互审查先发现群头缺成员数、群消息留白影响连续阅读。调整后重新实跑同账号 Web / iOS；复审确认成员数、密度、身份层次、长按菜单和键盘引用可达。
- 用户指出群名旁的通用图标多余。最终群头将群名与人数居中放在同一行，更多操作使用省略号。用三人群在模拟器重新跑通搜索、定位、长按、引用与发送；上表群聊实图取自这次复验。
- 代码审查发现冷开后丢失对话身份。已添加 SQLite 迁移与往返测试。同步上游后修正 worker 缺报用量的解码，区分有关系与可打开的记录，并以 owner ID 判定个人 Work 可见性。
- 设置旅程定位到轮询期间控件被禁用，已分开写入和后台读取状态，并隔离晚到响应。最终独立窄审通过。已逐条核对并归并 [iOS 契约](../../../specs/im/ios-client.md) 和 [Work 契约](../../../specs/im/agent-work.md)。

## 全 App 体验复查

以[Web 的体验原则](../../../product/web-im-principles.md)对照新账号第一次交办、老用户继续聊天、从对话进入任务和工作记录三条路径。两张用户反馈截图暴露的是普遍问题：界面经常先呈现系统能配置什么，用户要找的人、正在做的事和最自然的下一步反而靠后。

| 场景 | 发现与改动 | 验证范围 |
|---|---|---|
| 登录和注册 | 打开即面对账号表单、置灰的大按钮和连接设置，输错密码还会出现清除本机登录。入口现在用产品里的三个头像迎接来访者，注册和登录同屏可达；点登录能直接进入待填字段，打字时欢迎画面收起，连接设置归到右上角。注册提前说明密码长度，支持系统强密码面板；常见错误按界面语言显示，本机会话恢复失败时才出现清除操作。 | 新装模拟器的登录、注册 |
| 第一次使用个人助手 | 已配置电脑和模型时仍需要阅读设置表。现在先看到助手形象、名字和创建按钮；缺电脑时优先提供发到电脑的设置链接，有绑定链接可以直接继续。 | 新账号首屏、缺电脑的下一步；已连电脑时的创建及首次交办见上表 |
| 收件箱、新聊天、群详情 | 私聊原来选中联系人后还要确认，群详情默认暴露移除成员和保存名称。现在点人即进入私聊；建群另行选人，群页先看人、邀请和群任务，管理操作按需打开。邀请和公开群也区分读取中、错误与空结果。 | 同一账号切换私聊／建群、打开真实私聊，查看群、打开改名并取消 |
| 消息、搜索、整理知识 | 回复和引用保留在消息上下文。整理知识原来一进入就要求选择执行标识，选错设备直到提交才报错；现在先选来源，再按电脑约束可选对话，并展示对应助手。 | 搜索、引用、活动见上次原生实跑；本轮整理知识、只读协作、附件及互动卡片核对入口及状态分支 |
| 任务 | 两条任务也要读一排零计数，状态在标签和分组重复。短列表直接显示分组任务，长列表保留跳转和部分加载说明。新任务先写要做什么，已有进展和子任务结构按需填写。 | 用两条不同状态的群任务检查总览、进入创建、取消返回；编辑冲突、来源、树形结构与等待状态沿用既有契约核对 |
| 助手与 Work | 目录的运行模式与电脑名妨碍辨认联系人；详情与 Work 的红色停用按钮抢走发消息和读工作的注意力。目录现在以名字与头像识人，详情先发消息、再看工作，正常运行中的停用收进管理菜单；等待和重新启用仍有明确入口。Work 把最近的记录放在关联执行目录之前。 | 点真实助手、打开工作与派工；有交付和子执行的路径见上表 |
| 我的、电脑、团队 | 首屏曾混排个人助手、模型、设备绑定和公司策略。现在点头像改资料，助手有独立入口，已就绪可直接聊天。电脑连接归在「我的电脑」，团队管理按实际权限进入。电脑列表保留台数和助手数量，技术细节进入电脑详情查看。 | 原生打开「我的」与设置；设备升级、团队审批、模型服务的证据见[管理核对](M3-management/acceptance.md) |

在测试账号已有的同一条私聊中，原先横跨屏幕的 “Hi” 已收拢到文字与回执宽度，下面的长回复正常换行。点头像后直接看到“现在有空，可以聊聊”，点工作记录会打开该助手实际完成的那一轮。执行上下文、关联执行和控制记录收进“更多工作信息”。

前一轮发现普通助手创建时需要同时理解审批模式和模型选择，群任务通知摘要也会露出操作者内部 ID。下轮调整见下文。复杂交互卡片、第三方通道的完整收发、真机大字号和 VoiceOver 没有在这次模拟器走查中逐一复验。


### 原生多页面走查

用同一账号的 PA 私聊、两项真实群任务和三位团队助手对照四个入口。聊天首页突出个人助手及最后一条消息，助手目录按真实形象识人，任务首页优先展示当前筛选结果中待确认或推进中的一项，个人空间直接进入自己的助手和电脑。新建聊天、群成员、助手创建、任务详情、子任务、派工及电脑详情沿同一条操作路径调整。管理入口保留原有权限。

模拟器上从 PA 的「Hi」私聊打开近况并进入工作记录，可以直接读到已投递回复的摘录，点「查看原消息」返回原聊天。并走查了从群详情修改名称后取消、返回个人空间进入设置、从助手目录进入工作与派工，以及从注册到发现首位助手的入口。群任务摘要只在有结构化任务通知时使用可读摘要。历史缓存只有字符串时在下一次成功同步后更新。
