# IM Agents / Nodes Specification (delta for feat-781)

## MODIFIED Requirements

### Requirement: 托管 IM 提供连续首次设置

新个人用户可从连接电脑、连接模型、定义首个助手一路进入真实聊天。macOS / Linux 安装页提供可复制给本地 Agent 的 prompt 和可直接运行的手动命令，都针对当前 IM，不包含用户密码或模型凭据。进度由真实节点、模型和助手状态恢复；已有用户不被强制重新引导。

#### Scenario: 短窗口完整完成设置

- **GIVEN** 首次设置步骤的表单内容超过当前窗口高度
- **WHEN** 用户在桌面或手机上继续填写设置
- **THEN** 可纵向滚动到完整表单、保存与继续操作，不因屏幕高度被截断。

#### Scenario: 安装并恢复
- WHEN 用户运行页面提供的安装方式并确认设备绑定
- THEN 页面显示本人电脑并继续模型步骤；重复安装/刷新不重建身份或丢失数据。
- AND 首次连接确认展示当前账号和电脑，并以连接成功引导继续设置；只有整机交接使用设备转移文案，不将首次连接描述为转移。绑定页与首次设置使用聚焦的设置页头，分别呈现账号确认与电脑端连接进度，实际提交完成前不展示连接成功。

#### Scenario: 有指导的助手创建
- WHEN 用户选择用途、名称与目标并完成创建
- THEN 获得独立助手及工作目录，进入真实聊天并可发送符合用途的起步任务；建议不冒充真实回复。
- AND 首次设置用个人助手、电脑和模型等用户可理解的称呼；创建前的连接摘要优先展示模型显示名，不以内部服务标识代替模型名称。

#### Scenario: Windows 用户从 IM 下载并连接工作电脑
- **GIVEN** 用户使用 Windows 10 或 Windows 11 x64，电脑上没有 Node.js 或 WSL。
- **WHEN** 用户从当前 IM 下载 Windows 安装包，双击安装并确认要连接的电脑和账号。
- **THEN** 用户无需终端或系统开发环境即可在同一 IM 看见电脑在线，连接模型、创建助手并收到真实回复。
- **AND** 当前服务尚未提供对应版本时，页面说明可稍后重试；下载或唤起电脑端后，仅实际连接的电脑可以进入下一步。

### Requirement: IM 安装入口指定版本，程序包由独立发布源直接分发

#### Scenario: 安装当前服务选择的版本
- **WHEN** 用户运行当前 IM 提供的安装方式
- **THEN** 电脑按该 IM 提供的固定版本和校验信息，直接从发布源下载程序包；不随发布源 latest 变化选取其他版本，程序包不经 IM 转发，安装完成后仍连接发起安装的 IM。

#### Scenario: 下载失败保留原安装
- **WHEN** 指定程序包不可下载或校验失败
- **THEN** 明确显示重试方法，保留原安装与数据；不跳过校验、不切换未知版本，也不悄悄改经 IM 转发程序包。


#### Scenario: 普通部署保持安装版本
- **WHEN** 用户只要求合并代码、构建或部署更新
- **THEN** 不发布新的安装包，安装入口保留当前已验证版本；服务源码更新不自动切换安装版本。

#### Scenario: 明确发布命名版本
- **WHEN** 用户明确要求发布安装包并确定 `X.Y.Z` 版本号
- **THEN** 发布对应 `vX.Y.Z` Release，源码提交仅作为追溯信息，安装包内容经校验后才可供安装入口选择；已有版本不覆盖。
- **AND** 缺少确定版本号时不猜测或自动递增；现有已发布的 SHA 版本在被替换前仍可安装。

#### Scenario: 同一 IM 为不同电脑提供各自的受管版本
- **WHEN** 用户安装或请求更新一台受支持的电脑
- **THEN** IM 提供已验证且适用于该电脑的指定版本。该平台未发布或下载校验失败时显示可重试的结果；已安装的版本和数据仍可使用。
