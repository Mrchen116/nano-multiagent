# gateway tool-approval Specification (delta for feat-787)

## MODIFIED Requirements

### Requirement: Codex Auto 对普通工作区和临时文件编辑直接放行

路径解析以会话当前有效工作目录为相对路径基准，并以会话创建时绑定的不可变工作区根（及系统临时目录）作为授权边界根。

#### Scenario: 普通 Write/Edit/ApplyPatch
- **GIVEN** Codex Auto 已开启，工具自身约束允许，且没有需由模型解释的自定义审批规则
- **WHEN** Agent 通过 DSH 原生 `edit`、`write` 或 `apply_patch` 在当前绑定工作区或系统临时目录内创建、更新、删除或移动普通文件
- **THEN** 无需模型审核即可执行，补丁中的每个源路径与移动目标路径均通过同一边界与普通文件检查，现有工具执行约束继续生效。

#### Scenario: 越界、受保护路径与无法确认的补丁
- **WHEN** 任一目标路径（按会话有效工作目录解析后）或真实物理目标越界、指向非普通文件、命中受保护目录/文件，或补丁为空、语法无法解析、携带沙箱提权参数
- **THEN** 不获得免审放行，按原工具审批流程处理。

### Requirement: CC Auto 对普通工作区文件编辑直接放行

路径解析以会话当前有效工作目录为相对路径基准，并以会话创建时绑定的不可变工作区根作为唯一免审边界根。

#### Scenario: 普通 Write/Edit/ApplyPatch
- **GIVEN** CC Auto 已开启，工具自身约束允许，且未配置非默认自定义审批规则
- **WHEN** Agent 通过原生 `edit`、`write` 或 `apply_patch` 在绑定工作区内创建、更新、删除或移动普通文件
- **THEN** 无需分类模型审查即可执行，补丁涉及的全部源路径与移动目标路径均通过工作区边界与受保护文件校验，工具的读取与并发修改约束仍有效。

#### Scenario: 越界、受保护路径与无法确认的补丁
- **WHEN** 任一路径在绑定工作区外、真实目标越界、目标受保护、补丁语法无法解析或不能确认归属
- **THEN** 不获得工作区文件免审；相对路径基准变化、目录外路径或符号链接不会绕过权限约束。
