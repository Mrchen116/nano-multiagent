## MODIFIED Requirements

### Requirement: Web Work 可以从派工关系进入同一工作记录

#### Scenario: 查看时间范围和多层执行
- **WHEN** 用户打开派工关系或切换时间范围
- **THEN** 显示对应范围内有真实派工关系的会话及必要祖先，能继续查看未展开的分支；同一个会话的多次唤醒归属同一节点。
- **AND** 活动范围筛选图中的派工会话，派工卡片显示各自历史结束轮次和已报告的累计 token。主卡片累计该 Agent 各代主会话，子节点与作为路径的祖先累计自身会话。缺失值与报告不完整的范围明确区分。
- **AND** 点有轨迹的节点进入对应会话的工作记录，返回图保留范围和来源节点。派工关系提供按需打开的历史主执行与定时任务入口，保存的定时投递仍可打开原消息。

#### Scenario: 从新一级派工查看关系
- **WHEN** Global 在同一时间范围内派出多个 worker 并追加要求
- **THEN** 各委派显示标题、框架、真实状态，追加和结果归原关系。DSH、Codex、Claude Code 和 Antigravity 使用同一统计口径，各自按已结束的执行轮次累计，追加要求产生的新执行轮计入原 worker。已结束轮缺少 token 时显示缺报；尚无轮次记录时标明轮次及 token 未报告。根轨迹保留实际派工与回传，内部 helper 不在图中展开。
- **AND** Codex、Claude Code 和 Antigravity 的首条执行明细同步后，用户可以从派工图、活动弹窗、对应派工或追加指令以及带来源的汇报打开同一份工作记录。执行中展示已收到的任务输入、消息与工具活动，工具结束后可查看实际参数、返回结果或错误；当该轮报告上下文窗口与输出、缓存等细分统计时，展开轮次统计还可查看当前上下文已用 token、窗口上限及百分比、本轮输出、缓存命中与本轮总 token。最新工具可在运行中的派工卡查看。
- **AND** IM 持久保存这些工作记录，刷新或节点离线后可以按现有 Work 权限回看。仅有关系及用量的历史事项沿用关系展示。外部 CLI 提供工作记录，DSH 原生查看器继续用于受支持的原生会话。
