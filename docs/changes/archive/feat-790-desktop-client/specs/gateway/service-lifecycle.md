# Gateway Service Lifecycle Specification (delta for feat-790)

## ADDED Requirements

### Requirement: Desktop 受管节点按单实例接管已有配置并复用已下载运行环境

#### Scenario: 平滑接管同一 IM 连接的已有后台节点配置
- **GIVEN** 本机对应 IM 连接目录下已存在由命令行脚本或 Windows 轻量后台安装器建立的节点配置、凭据与工作区
- **WHEN** Crewden Desktop 在同一用户权限下接管该连接配置并启动本机节点
- **THEN** 在同一配置级生命周期锁下先正常停用旧的独立后台启动入口，再以受管版本启动唯一节点实例，完整保留原 `node_id`、设备凭据、模型配置与工作区目录，不出现双实例竞争

#### Scenario: 纯业务与应用界面更新复用既有运行环境缓存
- **GIVEN** 本机已存在校验通过的受管运行环境缓存，且 IM 指定的新 Desktop 版本继续引用相同运行环境摘要
- **WHEN** 用户执行 Desktop 受管更新
- **THEN** 更新过程直接复用本地已有运行环境缓存，仅下载并校验发生变化的应用或桌面壳归档及版本描述元数据

#### Scenario: 本机配置原子更新与启动失败回退
- **WHEN** 本机管理入口提交代理、一级委派 Worker 框架、运行环境变量或专用自动审批模型变更
- **THEN** 节点先完成完整配置与模型引用校验再原子写入；若需要重启且新进程未能在超时内完成初始化与运行时就绪，自动恢复更新前已验证可用的配置并重新拉起原可用实例，向调用方返回明确失败原因
