# IM Agents / Nodes Specification (delta for feat-790)

## MODIFIED Requirements

### Requirement: 托管 IM 提供连续首次设置

新个人用户可从连接电脑、连接模型、定义首个助手一路进入真实聊天。连接电脑步骤在支持桌面客户端的平台上同时提供「下载完整 Desktop 客户端」与「仅安装轻量后台节点」两套并存入口；命令行/本地 Agent 安装指引与轻量后台安装器继续保留，所有安装材料均针对当前 IM 且不包含用户密码或模型凭据。进度由真实节点、模型和助手状态恢复；已有用户不被强制重新引导。

#### Scenario: 短窗口完整完成设置

- **GIVEN** 首次设置步骤的表单内容超过当前窗口高度
- **WHEN** 用户在桌面或手机上继续填写设置
- **THEN** 可纵向滚动到完整表单、保存与继续操作，不因屏幕高度被截断。

#### Scenario: 安装并恢复
- **WHEN** 用户运行页面提供的安装方式并确认设备绑定
- **THEN** 页面显示本人电脑并继续模型步骤；重复安装/刷新不重建身份或丢失数据。
- **AND** 首次连接确认展示当前账号和电脑，并以连接成功引导继续设置；只有整机交接使用设备转移文案，不将首次连接描述为转移。绑定页与首次设置使用聚焦的设置页头，分别呈现账号确认与电脑端连接进度，实际提交完成前不展示连接成功。

#### Scenario: 有指导的助手创建
- **WHEN** 用户选择用途、名称与目标并完成创建
- **THEN** 获得独立助手及工作目录，进入真实聊天并可发送符合用途的起步任务；建议不冒充真实回复。
- **AND** 首次设置用个人助手、电脑和模型等用户可理解的称呼；创建前的连接摘要优先展示模型显示名，不以内部服务标识代替模型名称。

#### Scenario: Windows 用户从 IM 下载并连接工作电脑
- **GIVEN** 用户使用 Windows 10 或 Windows 11 x64，电脑上没有 Node.js 或 WSL。
- **WHEN** 用户从当前 IM 下载 Windows 安装包，双击安装并确认要连接的电脑和账号。
- **THEN** 用户无需终端或系统开发环境即可在同一 IM 看见电脑在线，连接模型、创建助手并收到真实回复。
- **AND** 当前服务尚未提供对应版本时，页面说明可稍后重试；下载或唤起电脑端后，仅实际连接的电脑可以进入下一步。

#### Scenario: 连接电脑并列提供完整 Desktop 客户端与轻量后台节点入口
- **WHEN** 用户在首次设置选择 macOS 或 Windows 10/11 x64 连接电脑
- **THEN** 页面同时提供「下载完整 Desktop 客户端」（macOS 标明支持 Apple Silicon 并引导 Intel Mac 选用轻量后台节点；支持下载安装包及通过桌面协议带入当前 IM 地址打开）和「仅装轻量后台节点」（保留终端/本地 Agent 脚本或 Windows 轻量后台安装器）两套可选路径，Linux/WSL 展示后台脚本路径
- **AND** 当某平台的 Desktop 安装包尚未发布时，该入口如实说明暂不可用并允许切换至轻量后台节点路径，仅实际完成绑定并上线的电脑可推进下一步

### Requirement: 电脑列表 SHALL 提供与当前服务一致的连接指引并区分空列表与读取失败

#### Scenario: 连接第一台或另一台电脑
- **WHEN** 用户从电脑页选择连接电脑。
- **THEN** 展示与当前服务首次设置一致的平台选择及「完整 Desktop 客户端 / 轻量后台节点」并存连接指引，并可返回列表；未发布对应安装包时明确说明不可用，不提供无效命令或失效链接。

#### Scenario: 读取失败
- **WHEN** 首次读取电脑失败或已有列表刷新失败。
- **THEN** 前者提供重试而非宣称没有电脑；后者保留已有列表并提示状态可能过时。
