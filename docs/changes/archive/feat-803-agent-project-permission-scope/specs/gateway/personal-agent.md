# gateway/personal-agent.md (delta for feat-803)

## MODIFIED Requirements

### Requirement: 独立披露检查限定于对外行为

PA 与普通/全局 Agent 各档位的协作与免审边界遵循 [IM 统一权限矩阵](../im/auth-tenancy.md#requirement-agent-与个人助手按统一权限矩阵控制发现会话轨迹与披露审核)。

#### Scenario: 纯主人私有域免审与跨圈强制审核
- **WHEN** PA 向主人专属私聊（Web PA 私聊或已绑定的飞书/微信主人单聊），或向仅含主人本人与同主人「私有」（`owner_only`）助手的纯主人私有会话发送消息、任意合法图片与通用附件（含 GIF、超长图、PDF 等文件，图片 `≤ 10 MiB`、通用文件 `≤ 25 MiB`，不受多模态审核图片帧数/像素上限限制）或修改任务内容
- **THEN** 无需独立披露审核直接提交送达并落库确认，原工具权限继续生效
- **WHEN** PA 向任何非纯主人私有域会话（包括同主人名下的「项目级」`project` 或「团队公开」`team` 助手会话、含外部成员的群聊或外部成员私聊）发出消息、附带附件或修改共享任务内容
- **THEN** 实际外发强制核对真实主人授权、完整 payload 与真实受众（当收件方包含非 PA 的 `project` 或 `team` 助手时，冻结受众证据显式标明该助手协作档位及下游可见的项目私密群成员或团队成员范围）
- **AND** 出站审核的交互卡片保留待发的完整源码和替换引用，省略渲染协议字段；不把该检查声明为任意代码/插件的完整网络隔离。

#### Scenario: 长期使用后继续已授权工作
- **WHEN** PA 已读取相关对话，主人已明确授权向指定受众发送
- **THEN** 独立审核依据 PA 当前有效上下文与真实受众核对，不因无关聊天历史积累而要求重复授权或阻止发送。
#### Scenario: 换窗后证据不足
- **WHEN** 当前有效上下文不足以核对外发授权或私有信息来源
- **THEN** 不发送；可以按正常历史恢复路径取回原话后重新审核，记忆、摘要和助手的授权声明不能单独放行。

### Requirement: PA 自身发送与代表用户发送使用明确工具边界
#### Scenario: 只有主人参加的会话
- **WHEN** 「团队公开」PA 可观察主人参加、但 PA 自身未参加的会话
- **THEN** 共用 send_message 不借主人权限发送；有真实委托时使用 PA 专属 send_user_message，在主人当前写权限及来源范围内代表发送。
- **AND** 普通 Agent 与内部子 Agent 不获得代表发送能力；PA 自身回复、报告与协作仍使用共用普通发送。

#### Scenario: 私有 PA 允许联系同主人名下助手但禁止向外部会话发言或代发
- **WHEN** 处于「私有」（`owner_only`）的 PA 向主人私聊或同主人名下的任意可用助手（含 `owner_only`、`project`、`team`）发送消息或附件
- **THEN** 均允许发起投递（其中发往 `owner_only` 助手免审，发往 `project` 或 `team` 助手须通过独立披露审核）
- **WHEN** 处于「私有」（`owner_only`）的 PA 尝试向含外部成员的群聊、与外部同事的私聊或非主人外部渠道调用 `send_message` 或 `send_user_message`
- **THEN** 发送在服务端与网关边界被拒绝，不产生任何对外消息，并向模型返回 `not_sent` 及明确私有范围说明，引导其改为在主人私聊或主人内部专属会话中汇报。

### Requirement: 披露审核实际消费待发图片与可审阅文本附件

#### Scenario: 可审阅图片与文本附件按内容审核外发
- **WHEN** PA 向非纯主人私有域会话发送支持范围内的静态光栅图片，或可审阅的严格 UTF-8 文本附件（`text/plain`、`text/markdown`、`text/csv`、`text/tab-separated-values`、`application/json`、`text/yaml`、`application/yaml`、`text/xml`、`application/xml`，严格 UTF-8 编码、不含 NUL 字节且单文件 `≤ 256 KiB`）
- **THEN** 本地待发文件须先经 `pa.action.status` 写权限预检并私密暂存至主人私聊；审核模型实际收到冻结图片或完整文本正文、受众与原授权上下文，按完整内容判断；文字无敏感信息不代表附件可免审
- **AND** 仅允许审核通过的同一字节内容复制到目标会话发送，内容或受众变化必须返回未发送并重新决策。

#### Scenario: PDF 等不可读通用附件按不可读材料结合来源与轨迹从严审核
- **WHEN** PA 向非纯主人私有域会话发送审核器无法直接展开内部正文的合法非光栅通用附件（如 `application/pdf`、Office 文档、压缩包或超 256 KiB 数据文件，单文件 `≤ 25 MiB`）
- **THEN** 系统不新增专用文档解析或二进制读取工具，而是在冻结证据中显式标记该附件内容不可直接读取（`content_review = "unreadable"`），并一并附带服务端核实的文件哈希、本地上传规范路径（若有，且落库公开消息时不向接收方暴露该路径）及可读会话内同哈希原消息附件来源；`download_attachment` 同步返回文件 `sha256` 供轨迹对照
- **AND** 独立披露审核 Agent 按不可读材料的更严格标准判断：仅当主人原始原话结合真实文件来源与可见执行轨迹能够确认主人明确授权向当前受众发送该特定文件（或该文件在可见轨迹中完全由获准面向该受众的材料生成、无未审阅私有来源混入风险）时才放行并复制同一字节内容投递；否则返回拒绝或需主人确认，绝不仅凭文件名放行。

#### Scenario: 损坏图片或审核能力缺失保持 fail-closed
- **WHEN** 发往非纯主人私有域会话的附件不可访问、哈希在准备与提交间变化、声明为光栅图片但解码失败或尺寸/数量超限、需审阅图片但审核模型不支持图像输入，或模型请求无法装入必要审核证据
- **THEN** 明确返回不可审阅/处理故障，不静默漏审放行
- **AND** PA 参与群接收非主人发来附件时的输入安全审核保持既有 fail-closed 边界不变。

### Requirement: 主 PA 按主人明确交办创建长期 Agent

#### Scenario: 创建前对齐并交付
- **WHEN** 主人明确要求 PA 创建独立 Agent
- **THEN** PA 按需取得创建指导和目标电脑真实选项（其中 `collaboration_scope` 默认 `team`，支持按主人要求直接设为 `project` 项目级或 `owner_only` 私有），在聊天中与主人确定配置后执行；已有选择不重复询问，主人可接受推荐值。
- **AND** 默认推荐 PA 所在电脑，不擅自替换主人指定的电脑；真实成功后说明 Agent、职责、电脑和使用入口。

#### Scenario: 讨论与执行边界
- **WHEN** 用户只是讨论需求、PA 提出建议、观察聊天出现相关内容，或用户在提交前撤回
- **THEN** 不据此创建；普通 Agent 和内部子 Agent 不获得该管理入口。

#### Scenario: 固定工具定义与按需细节
- **WHEN** 主 PA 查询选项、提交创建或确认原创建结果
- **THEN** 使用同一固定短工具入口，详细指导与配置选项按需读取；不因加载 Skill 或操作进度动态增删工具定义。
- **AND** Skill 选择与工具执行权限继续生效，无法取得指导或选项时如实说明。

#### Scenario: 配置页独立关闭与重新开启
- **WHEN** 主人打开 PA 配置页管理创建工具
- **THEN** 新建 PA 默认选中该工具，主人可单独关闭或重新开启；关闭后不可调用，Skill 选择独立生效。
- **AND** 关闭沿用既有运行能力生效及占用保护规则；不撤销已经接受的创建操作。
