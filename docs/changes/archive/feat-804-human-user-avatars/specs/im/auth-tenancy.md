# IM auth-tenancy Specification (delta for feat-804)

## ADDED Requirements

### Requirement: 真人账号可管理受保护的自定义静态图片头像

IM SHALL 支持真人账号上传、替换与移除单张自定义静态图片头像，对上传字节执行格式、帧数、尺寸上限与重新编码校验并剥离元数据，不提供免登录公开头像外链，且不在注册或首次设备/助手引导流程中强制设置头像。账号未设置或已移除自定义头像时，客户端按显示名回退首字母柔和色圆章。

#### Scenario: 上传与更换合法静态图片头像并同步版本标识
- **WHEN** 已认证真人客户端以合法静态 PNG、JPEG 或 WebP 图片字节调用 `PUT /im/v1/me/avatar`（体积不超过上限且像素尺寸合法）
- **THEN** IM 将头像标准化收敛为正方形静态图片保存、替换并清理该账号此前的旧头像文件，生成新的非空 `avatar_version`，并在当前账号资料（`GET/PATCH /im/v1/me`、`GET /im/v1/auth/me` 及登录/刷新返回）、可见联系人目录、公司成员列表及聊天参与者/消息身份中返回最新 `avatar_version`，同时通过用户实时流通知可见对端刷新
- **AND** 用户仅通过 `PATCH /im/v1/me` 修改显示名、默认入口设备或语言时，已保存的自定义头像与 `avatar_version` 保持不变

#### Scenario: 移除自定义头像恢复空版本
- **WHEN** 已认证真人客户端调用 `DELETE /im/v1/me/avatar`
- **THEN** IM 清除该账号的 `avatar_version` 并删除对应存储文件（本身无自定义头像时幂等成功），后续身份投影不再携带自定义头像版本并通知可见对端回退至首字母圆章

#### Scenario: 拒绝超限、动态、伪造类型或损坏文件且保留原头像
- **WHEN** 客户端上传空字节、超过单文件体积上限的数据、非支持媒体类型、动态多帧图片（如 GIF 或动态 WebP）、文件头与内容不匹配或无法解码的损坏图片
- **THEN** 请求返回 4xx 拒绝且不写入新文件，账号原有自定义头像与 `avatar_version` 保持不变

#### Scenario: 读取真人头像受登录与组织及会话可见性约束
- **WHEN** 调用方请求 `GET /im/v1/users/:user_id/avatar`
- **THEN** 未携带有效真人访问令牌（含未登录访客或机器中继凭据）返回 401；已认证真人仅在目标为本人、双方同为有效团队成员、当前调用方为管理准入的有效公司管理员（目标处于申请/有效/停用团队状态），或调用方对至少一个包含该目标真人的会话具备读取权限时返回头像图片字节（附带 `nosniff` 与私有缓存头）
- **AND** 目标不存在、为运行时保留身份（`system`、`agent:*`、`shadow:*`）、未设置头像，或调用方不满足上述可见性条件时统一返回 404，不暴露未授权账号是否存在或是否设置头像

## MODIFIED Requirements

### Requirement: Web 账号设置分清个人资料、空间资格与关联管理

Web 账号页以个人身份、自定义圆形图片头像管理与显示名编辑为主，账号 ID 和加入时间按需查看；个人空间与团队资格分别显示，电脑由摘要和入口导向既有电脑管理。注册与首次引导不增加真人头像前置步骤。

#### Scenario: 修改资料、管理个人头像和查看资格
- **WHEN** 用户进入账号页
- **THEN** 可查看当前圆形头像并通过选图与圆形裁剪预览上传或更换头像、在已有自定义头像时移除恢复首字母圆章，修改显示名，辨认当前登录用户名与个人/团队资格，并按资格找到加入申请、申请状态或管理员成员管理入口。
- **AND** 头像的确认保存与移除立即生效并同步导航栏个人菜单与移动端「我的」身份卡，无需额外提交显示名表单；尚未连接电脑时可继续助手设置，已有电脑时通过摘要进入电脑管理，不重复设备详情。

### Requirement: Web 账号与策略编辑反馈清楚且保留未提交内容

两页表单未修改或输入不合法时不可保存，提交期间防止重复操作，保存成功有明确反馈。保存失败与后台重新读取不覆盖当前草稿；账号页头像上传、取消裁剪或移除操作独立于显示名表单，不覆盖未提交的显示名草稿；离页不承诺保留草稿。

#### Scenario: 失败、刷新、头像操作与放弃
- **WHEN** 用户编辑显示名后保存失败、页面后台重新读取，或期间打开/取消裁剪预览、上传更换头像、移除头像及遇到头像上传校验/网络错误
- **THEN** 未提交的显示名草稿保持可见，头像失败给出明确原因且保留当前已生效头像；放弃修改恢复显示名已存值而不回滚已独立生效的头像，成功保存显示名退出未保存状态。
- **WHEN** 页面读取失败
- **THEN** 对应区域显示失败与重试入口，不阻断其他已加载区域。
