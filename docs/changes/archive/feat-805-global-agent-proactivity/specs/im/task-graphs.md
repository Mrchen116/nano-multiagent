# im - Task Graphs Delta Specification

> Target: `docs/specs/im/task-graphs.md`

## MODIFIED Requirements

### Requirement: 每个拆分层级提供结构与完成情况视图

全局任务入口默认呈现聚焦「与我有关」范围的**行动焦点台**，替换原五列根看板；顶栏提供「当前行动」与「长线目标」双视角切换及「状态说明」流转图解，支持切换「按负责人」「团队全部」范围、选择归属会话快速创建私人或团队任务，并保留从群聊进入「本群任务」。点击任一具体任务卡片可打开按所处阶段呈现有效信息的详情抽屉/面板；点开任一多节点长线目标进入**北极星全景图**，保留计划依赖图、探索衍生树及多层嵌套语义。历史已保存的 `schema_version: 2` 任务图完整兼容可读可改。

#### Scenario: 默认进入「与我有关」双视角焦点台并支持并列查看「先存着」、阶段详情与范围切换
- **GIVEN** IM 中同时存在用户私人空间事项、用户与团队数字员工在 1 对 1 私聊中协作的独立事项、本人牵头或直接负责的团队群任务，以及他人在公开群推进的无关任务
- **WHEN** 用户在 Web 或原生 iOS 打开全局任务入口
- **THEN** 默认展示「与我有关」范围下的「当前行动」视角：顶部将「待你拍板」（本人私人空间 `proposed`、本人与 Agent 1 对 1 `direct` 私聊中的 `proposed`［Agent 在该类 1 对 1 私聊创建或转入 `proposed` 且省略 `proposed_for_user_id` 时服务端自动补全对端真人 ID，显式指定 `proposed_for_user_id` 时须为所属会话有效真人成员］、显式面向本人的团队群 `proposed`、指定本人回答的 `waiting`、本人私人空间或本人与 Agent 1 对 1 私聊及本人创建或父级归属本人的 `in_review`）与「先存着」（本人私人空间、本人与 Agent 1 对 1 私聊、显式面向本人或团队中直接归属本人的 `backlog` / `paused`，支持一键「提上日程」或展开为目标图）并列切换呈现，中间主区展示「进行中」（本人私人空间、本人与 Agent 1 对 1 私聊活跃事项及团队群中直接分配给本人的 `doing` / `waiting` / `todo` 节点），底部默认折叠「已完结」（`done` / `closed`）；切换至顶栏「长线目标」视角时专门展示私人空间、本人与 Agent 1 对 1 私聊或本人发起/直接负责根节点的未完结多节点目标概览（含目标自身标准状态徽章与阶段进度）
- **AND** 子任务卡片始终展示所属长线目标与上级路径；任务文本收敛为常驻的标题（`title`）与任务说明（`description`，`proposed` 待拍板节点必填说明提议原因与批准后具体动作，且在转入 `backlog` / `paused` / `doing` 等状态后始终原位保留，列表摘要与详情抽屉一致）及按需出现的进展与结果（`result`，仅非空时展示）和等待说明（`wait.reason`，仅 `waiting` 时置顶）；单次修改附注（`change_note`）降级为底部轻量审计信息，不挤占正文区；本人发起的团队长线目标下由他人或其他数字员工负责的底层子任务收纳在该目标内页，无关公开群中他人的任务以及他人之间的私聊任务不进入默认焦点台；切换至「按负责人」或「团队全部」时顶栏「当前行动 / 长线目标」双视角同样一致生效，分别准确展示所选范围下的具体行动或长线目标，且桌面与手机窄屏均保留关键字搜索与新建单卡/多步目标入口
- **AND** 连续处理多张待拍板卡片时，瞬时确认反馈采用不挤动相邻待操作卡片坐标的轻量浮层；待拍板区清零时展示安静空态

#### Scenario: 桌面与手机按各自自然形态浏览北极星全景图与前沿新芽
- **GIVEN** 一个长线目标包含已完成阶段、当前推进前沿、探索试错分支以及 `proposed` 待拍板候选子节点
- **WHEN** 用户在桌面 Web、窄屏浏览器或原生 iOS 打开该长线目标
- **THEN** 视图顶部持续呈现该长线目标的标题与目标说明；用户能清晰辨认已完成阶段、当前推进前沿、探索选定方向与保留的负结果，以及尚未获批执行的待拍板新芽节点（提供批准、「先存着」与关闭入口），并可通过点击负责人头像查看运行状态与工作记录及新增/编辑子节点
- **AND** 桌面端支持结合脉络结构同屏查阅节点详情；手机窄屏与原生 iOS 采用适合竖屏单手阅读与点按的纵向阶段脉络呈现（前序已完成阶段可展开回看），不要求通过二维画布双指缩放平移才能完成浏览、编辑或拍板

#### Scenario: 多层子作用域逐级进入与面包屑返回
- **WHEN** 长线目标下某个阶段节点或探索分支内部继续拆分为多层子任务图，用户点击进入该子脉络
- **THEN** 界面保持顶层终局目标可见并展示当前层级的直属子结构与面包屑路径，深层后代不越层混入外层阶段；点击面包屑可逐级返回外层或焦点台且保留浏览上下文

#### Scenario: 焦点台各分区与列表视图的有界增量加载
- **WHEN** 焦点台分区、折叠的「已完结」列表、「按负责人」或「团队全部」匹配结果超出首屏批次上限
- **THEN** 首屏按有界批次返回并在用户展开或滚动接近底部时增量加载后续记录，加载中、失败重试与已到底状态可辨认且不影响其他分区已渲染卡片位置

#### Scenario: 探索与计划嵌套
- **WHEN** 用户在探索方向及其验证计划间导航
- **THEN** 仍能辨认当前选择、方向结果和相应结构关系；关闭的方向不计为成功完成，未选方向不自动变成必做工作。
