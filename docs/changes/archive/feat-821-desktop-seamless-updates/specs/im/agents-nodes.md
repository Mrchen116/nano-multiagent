# IM agents-nodes Specification (delta for feat-821)

## MODIFIED Requirements

### Requirement: 电脑端更新由 owner 主动发起并显示真实结果

在 Web IM 远端管理电脑时，电脑端更新由 owner 主动点击发起并如实反映阶段与结果；在 Crewden Desktop 本机客户端内，额外支持本机用户可随时开关的「自动保持最新」（默认开启后台静默预下载并在空闲或一键确认时平滑切换）。

#### Scenario: 查看并发起
- **WHEN** owner 查看电脑设置或聊天的本人电脑入口
- **THEN** 可发现该电脑可用版本及说明；在 Web 远端管理页点击更新后才下载、安装和重启，不重复确认，不影响其他电脑；在 Crewden Desktop 本机内则与桌面端更新状态及「自动保持最新」偏好保持一致。

#### Scenario: 等待与取消
- **WHEN** 新包已准备但电脑仍有任务
- **THEN** 显示任务结束后更新，切换前可取消；下载和等待不强制中断工作。

#### Scenario: 结果与恢复
- **WHEN** 用户刷新或重新打开更新页面
- **THEN** 显示实际阶段或结果；只有新版已上线才显示成功，只有旧版已恢复才显示已回退，失败可重试或进入明确恢复指引。

#### Scenario: 不可更新与旧安装
- **WHEN** 电脑离线、无新版、清单未发布、旧安装缺少能力、桌面端需升级外层客户端安装包或由源码运行
- **THEN** 分别显示通俗可理解的状态与适用入口：需要升级外层桌面客户端时引导在该电脑 Crewden Desktop 内一键下载安装新版客户端（不向桌面端展示终端命令行升级报错），旧独立节点安装提供一次性升级说明，源码运行不会被网页更改部署。
