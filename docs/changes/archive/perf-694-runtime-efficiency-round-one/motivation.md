# 第一轮运行开销检查与修复

## 用户原话与范围

- “进行三轮 检查 - 批量修复 - 检查 - 批量修复 的 loop。”
- “很好，后面每次修复完也要在合并后的main做新一轮的检查。开始吧”

本 unit 是三轮循环中的第一轮。保持现有产品设计和体验，检查真实路径的时间/空间开销、资源生命周期和维护成本；确认具体触发条件后批量修复，验证、独立审查并合入，再从合并后的 main 开始下一轮。快速实施后据实补文档；未修改任何通用流程或 Skill，也不将工程验证写成用户亲测。当前轮未部署生产。
