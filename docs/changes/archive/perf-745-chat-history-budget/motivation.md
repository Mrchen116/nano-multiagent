# 聊天首屏与历史页

## 用户要求

用户对五项审查发现逐项要求修复，并授权安排节奏：“都得解。怎么节奏做，你自己规划”。本单元对应“聊天首屏与历史页”。

## 现状与动机

已有审查用真实消息读取与 JSON 序列化对比 50 条消息，工具明细较重时原始响应可从 27 KB 增至 32.9 MB。指定聊天的消息请求还受完整侧栏加载约束。

本项覆盖历史读取与前端消费。实时写入存储重构与审批内部读写成本另看，不以删减历史换速度。

## Requirement: 聊天首屏与历史页

### Scenario: 长历史下完成原有操作

- **WHEN** 用户打开指定聊天、翻历史或查看工具过程
- **THEN** 当前会话和首批消息可独立加载。历史页继续保持原有顺序、引用、权限和审批状态；工具明细可按需读全，消息页的传输成本不随工具输出正文增长。
