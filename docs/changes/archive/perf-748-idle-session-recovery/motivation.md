# 节点恢复仅加载待处理会话

## 用户要求

用户对五项审查发现逐项要求修复，并授权安排节奏：“都得解。怎么节奏做，你自己规划”。本单元对应“节点恢复仅加载待处理会话”。

## 现状与动机

节点重连会串行 ensure 与 observe 所有启用的单线程绑定。1,000 个无待办会话产生 2,000 个调用。

恢复不主动续跑已经中断的执行，不清理历史。

## Requirement: 节点恢复仅加载待处理会话

### Scenario: 长历史下完成原有操作

- **WHEN** 拥有大量已完成历史的节点重启或重连，部分会话还有未完成的输入、回执或审批
- **THEN** 空闲历史保持可读并在真正访问时恢复。节点优先恢复有明确义务的会话；已持久化但尚未完成的输入、交付、审批与中断均按真实状态恢复，去重和停用边界保持。
