# 从旧回复直接定位 Work

## 用户要求

用户对五项审查发现逐项要求修复，并授权安排节奏：“都得解。怎么节奏做，你自己规划”。本单元对应“从旧回复直接定位 Work”。

## 现状与动机

现有 API 已给出目标轮次，Web 仍以每页 20 轮从最新开始自动翻页；第 1,000 轮约需 50 次串行请求。

保留同一 Work 页面和阅读路径，历史轮次位置不以聊天时间或标题推断。

## Requirement: 从旧回复直接定位 Work

### Scenario: 长历史下完成原有操作

- **WHEN** 用户从一条很早的聊天回复打开 View Work
- **THEN** 直接展开与该回复对应的真实轮次。完整 Work 保持最新优先、历史分页可达。可在新旧回复间来回切换，保持折叠和阅读行为；迟到的关联和权限变化按既有规则处理。
