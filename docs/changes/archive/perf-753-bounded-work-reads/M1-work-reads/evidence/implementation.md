# 有界 Work 读取实现验证

## 中心 HTTP 容量对照

在 Air 本机用 Node 24.22.1、真实 IM Fastify 进程和独立 SQLite 文件对照同一版本的旧 `?view=summary` 路径和协商后的 `?view=summary&catalog=separate` 路径。通过真实登录会话格式签发授权，所有读经过 HTTP 鉴权。每组先预热，两个模式交替各读 7 次。时间包含 loopback HTTP、同步投影、序列化与接收响应正文，按中位数和最大值记录。本机同时有开发构建等活动，延迟只作方向性观察。

主 Agent 样本包含 15,000 轮，仅最早一轮报告 usage。最新一轮含近 15,000 条约 2 KiB 的工具记录，无后台返回。会话控制记录含一条 256 KiB 的正文。两个模式都返回同样的 20 条轮次及最近已报告 usage。表中为未压缩响应。

| 主根关联执行数 | 旧响应字节 | 新响应字节 | 旧中位 / 最大 ms | 新中位 / 最大 ms |
| ---: | ---: | ---: | ---: | ---: |
| 1,000 | 476,143 | 5,492 | 304.25 / 414.57 | 4.77 / 10.01 |
| 10,000 | 2,348,143 | 5,492 | 433.55 / 487.94 | 5.86 / 28.38 |
| 100,000 | 21,158,143 | 5,492 | 2,114.25 / 7,656.97 | 13.87 / 75.84 |

另建 49 个同节点 Agent，每个 40 轮和 100 个关联执行，数据库内共 1,000 个人账号。以 10 个公司账号并发读全部 50 个 Agent 的头页，每轮 10 个 HTTP 请求，50 次均返回 200 和 20 轮，合计样本中位 26.40 ms，最大 45.71 ms。只有个人空间资格、公司成员状态待定的账号请求公司 Work 得到 404。数据量为确定性构造，未模拟一年运行或 1,000 个浏览器。

在 1,000 关联执行初始样本上，以删除本次 7 个索引模拟旧 schema 后重新启动。中心启动及索引安装合计约 600 ms，checkpoint 后数据库文件增加 1,880,064 字节。该值包含启动成本，未测 100,000 关联执行的索引安装时间。

SQLite 在实测样本为 usage、目录、弱关联和 revision 分别使用 `agent_work_turns_usage`、`agent_work_sessions_catalog`、`agent_work_sessions_parent_child`、`agent_work_items_revision`。首轮计划显示缺少统计时 SQLite 为当前主执行选了较宽的根索引。最终查询固定使用 `agent_work_sessions_current_main`，在同一 100,000 关联执行数据库上复核得到按 `root_agent_id` seek 的部分索引计划。上表是固定该索引前的时间，响应字节与固定前相同。轻摘要跳过逐轮工具 COUNT、后台返回 JSON 和控制正文查询。

## 行为验证

- 中心 build 和 typecheck 通过。实际进程测试 `work-bounded-reads.test.ts` 与 `work-message-focus.test.ts` 串行通过。覆盖非管理成员读取、公司资格、未登录、当前及退休 Session、旧响应、独立控制记录、有界候选、按确切 call 和 session ID 读取、同一 seq 的 revision 替换、变化分页与空页。现有原生轨迹 HTML 启动测试也通过。
- Web 的 42 个 Work 与资料页组件测试通过，覆盖协商标记、旧响应、旧回复定位、直接读取未加载的执行、已打开详情的后页原序号更新、三页历史后的头部刷新、跨整页新增后的缺口补读及主 Session 更换。HTML bootstrap 使用协商路径，并按相同 URL key 预取精确回复焦点。
- 真实 Chrome 在 100,000 关联执行的中心进入设置 Work，从消息直达第 99,999 个执行，只请求选中 Session 元数据与头页。翻过三页历史后，向隔离中心写入 42 个新轮次并发出 Work 更新，浏览器保留旧轮次与展开状态。自动读取后历史请求仍为原先 3 次，间隔提示可见。主动点击两次后显示全部连续的 122 轮，历史请求总数变为 5 次。Chrome 使用中心的真实鉴权和客户端构建，轮次来自合成数据。
- iOS 已用 Xcode 26.4 构建模拟器 App。单独建立的模拟器运行测试时本机资源紧张，测试进程停止并删除该模拟器。iOS 测试与真实设备交互待后续验证。
