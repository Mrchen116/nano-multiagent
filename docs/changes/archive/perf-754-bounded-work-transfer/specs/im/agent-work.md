# Delta · 大型 Work 明细

## MODIFIED Requirements

### Requirement: 工作记录补传与聊天沟通独立且恢复后完整可查

#### Scenario: 大结果在中断后恢复回看
- **WHEN** 受支持大小的工具参数或结果经历分段同步、中断、重复传输和恢复，用户重新打开 Work
- **THEN** 可以回看完整正文、真实顺序及父子归属，不新增重复条目或把未完成的记录报为完整。

#### Scenario: 工作记录暂未同步
- **WHEN** 工作记录仍在补传而实时聊天可用
- **THEN** 聊天消息与必要操作照常进行，普通聊天不增加同步实现、确认阶段或运维诊断信息；用户仍可主动打开现有 Work。

#### Scenario: 传输和检查超过内联范围的原文
- **WHEN** 支持大记录的节点和中心同步超出内联范围、处于可镜像上限内的事实
- **THEN** 保留同一 Work 事实的身份与预览；原文可在传输完成后由有该 Work 权限的用户按需读取。

#### Scenario: 原文无法在中心完整镜像
- **WHEN** 原文超过支持上限或传输容量不足
- **THEN** 明确显示中心原文尚不可查，保留节点原文，并继续同步后续可处理的事实；不以预览冒充完整正文。
