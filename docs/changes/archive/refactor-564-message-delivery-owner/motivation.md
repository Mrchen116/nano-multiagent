## 用户侧验收标准（不变性）

### Requirement: 设备背景和消息来源解释保持

#### Scenario: 不同入口及执行环境
- **WHEN** 用户在 Web IM 或飞书询问页面或要求查看本地产物
- **THEN** Agent 获得已确认的 Runtime 文本、真实 Web IM 用户入口与可选执行环境地址，逐消息 channel/time 仍正确，不把回环地址当用户可达地址。

### Requirement: 普通和显式图文完整交付

#### Scenario: 本地及多轮图文
- **WHEN** 用户要求普通/群聊 Agent 或全局 Agent 发送工作区内外的图片，或同一运行中先发图一、调用工具、再发图二
- **THEN** 获准图片按原顺序完整显示，每个实际输出只发送一次，图片长期回看、放大和非成员访问控制保持；思考、工具过程和完成状态仍正常。

### Requirement: 私有失败反馈与权限边界保持

#### Scenario: 来源或上传失败
- **WHEN** 图文含缺图或上传失败
- **THEN** 未发送草稿不显示给用户，Agent 收到具体内部反馈并可修正，最终只看到完整图文或真实未完成说明。

#### Scenario: 权限、新输入和取消
- **WHEN** 图片外发被拒绝、准备期间到达新输入，或用户停止/重置
- **THEN** 不越权发送、不发布已过时或已撤销的候选；显式发送不重复审批，普通发送沿用同等权限策略；停止后不因内部反馈自启动新回复。

### Requirement: 跨渠道恢复保持真实且不重复

#### Scenario: 外部送达与内部离线
- **WHEN** 飞书可用而内部 IM 离线，随后 IM 恢复
- **THEN** 飞书先收到一次图文，IM 后补相同内容且正常完成；删除原文件不影响已准备图片的恢复。

#### Scenario: 回执丢失与部分成功
- **WHEN** 消息回执不确定或只有部分目标已成功
- **THEN** 只恢复原交付未确认部分，不让 Agent 新建一份去重复发送，不谎报整条从未送达。
