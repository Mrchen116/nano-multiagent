# IM agent-work Specification (delta for refactor-655)

## ADDED Requirements

### Requirement: 已保存工作记录直接读取，节点恢复只补缺口

#### Scenario: 完成历史增长后普通重启
- **GIVEN** 主子执行的工作记录已保存且中心已确认
- **WHEN** 节点普通重启，用户查看 Work 和更早分页
- **THEN** 用户直接看到中心保存的工具过程、主子关系、轮次与已报告统计；不为展示恢复全量重建不变的完成历史。

#### Scenario: 崩溃后补齐未处理事实
- **WHEN** 原生事实已持久化但产品记录或中心确认尚未完成时节点崩溃并恢复
- **THEN** 处理和传输各自从持久位置补齐，主子执行均无遗漏、重复或虚构完成；在途执行、审批和交付按真实状态恢复。

#### Scenario: 查看尚未补齐的记录
- **WHEN** 用户查看尚在补齐的 Work，或节点未确认最新记录位置
- **THEN** 已保存内容与分页立即可用，并分别提示正在补齐或最新进度尚未确认；补齐不阻塞新输入及必要控制。
- **AND** 页面持续接收工具开始/结束及真实新记录；新用量未报告时仍展示最近已报告统计。
