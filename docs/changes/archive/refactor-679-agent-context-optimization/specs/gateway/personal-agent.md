# Personal Agent delta — refactor-679

## MODIFIED Requirements

### Requirement: 来源控制停止后续访问与文档记忆采用，保留原始历史

#### Scenario: 排除聊天
- **WHEN** 主 PA 按主人向它提出的原始要求调用来源工具
- **THEN** 后端核实主人与原会话上下文，拒绝后续访问并撤销待处理输入，不清空原始上下文、成果、Git 或备份。
- **AND** 用户明确提出的停止采用要求当轮及后续适用回答立即遵守，不调用遗忘工具、不登记持久停用名单；Dreaming 从聊天原文理解适用范围并修改正式记忆；来源设置生效与持久记忆清理分别报告，不因保存配置就宣称清理完成。

#### Scenario: 观察文本不控制来源
- **WHEN** 主人向他人说了与来源设置相关的话
- **THEN** 不能仅引用该观察消息替 PA 改变来源权限。

#### Scenario: 外部来源变化和重新允许
- **WHEN** 当前访问资格因成员或来源政策变化而撤销，或主人以后重新允许访问
- **THEN** 权威资格同步覆盖已消费来源，不以未读队列代替完整来源；后续读取和后台整理仍核对当前资格。
- **AND** 重新允许未来访问不自动解除明确的停止使用要求。
