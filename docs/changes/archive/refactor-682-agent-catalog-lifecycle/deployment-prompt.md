# refactor-682 一次性历史 preview 整理

仅在用户另外授权部署包含本 unit 的已验证版本后执行。本文件不授权部署。

旧版本在长期 DSH home 的 `sessions/` 下遗留 `preview-<UUID>`。新版本所有临时检查只使用 inspector 专属临时 home；实际聊天 Session 不迁移。

1. 记录部署版本、该节点准确 DSH home、当前 writer PID 和服务状态。停止旧 Node/DSH 并确认无写进程，保留正常生产停启流程；不要求额外重启演练。
2. 在受保护本地部署记录保存候选清单、数量及备份路径。仅选择名字严格匹配 `preview-<UUID>` 且 header identity 与同名 preview 一致、无真实聊天绑定的目录；任何不确定项保留并报告。
3. 将确认的目录移动到同卷、受保护、带本次部署 ID 的归档目录，逐项追加移动结果；不永久删除。禁止通配删除整个 sessions、workspace、数据库或其他节点 home。
4. 启动新版本后只读检查节点健康、新 inspector root、真实 Session 数量不变；生产不发测试消息、不创建任务，不执行 soak。
5. 中断后根据清单检查源/目标：目标已存在且源不存在为已完成；源存在且目标不存在继续；两边同时存在或都不存在停止并核对。失败可停服务后按清单将归档移回；新产品代码不依赖历史目录被整理成功。

交付前在隔离副本中验证候选筛选、正常移动、重复执行与中断后恢复，包含必须保留的普通 Session、伪造 preview 名、真实 binding 和不匹配 header。证据归 M1。正式生产仅核对清单计数与所述不变量，不用生产补功能验收。
