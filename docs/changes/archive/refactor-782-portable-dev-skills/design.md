# 可编辑的跨仓开发 skills

## 设计

独立库 dev-workflow-skills 拥有技能、默认流程、模板、工具及工具测试。项目文件从当前 Git checkout 读取；工具和附带资料从 skill 的实际源码目录读取。安装脚本逐 skill 注册用户级目录链接，保留已有无关设置，报告同名冲突。Codex 和 Claude Code 本地环境首批支持；云端实例各自安装。独立库版本由 Git 管理，日常编辑无需发布制品。

Nano 移除仓内 21 个通用条目，保留部署、iOS 安装和上下文缓存验证。通用规范归库，Nano 的开发基线、构建、运行隔离、证据、产品案例和文档检查仍由 Nano 维护。固定历史评测及产品随包资源不动。已分配编号（包括未建目录的号）保持兼容。使用仓库 URL 和技能名称引用外部入口，使 CI 无需用户机器的安装。

## M1-cutover

从安装、源码修改到 Nano 切换是一个交付 milestone。独立库和 Nano 各自提交。独立审查核对引用、路径、安装冲突、证据和配置归属；窄测覆盖首次建目录、并发编号和 Nano 文档/归档检查。Sol 轻量试用从业务仓读取通用版本，核实新会话读到修改。对 Nano 使用真实 worktree，对空或既有外仓使用最小 Git 样例。项目产品 API 与运行行为无变化，无产品 spec delta。

## 切换顺序与检查归属

外库先可获取、可安装，两宿主路径若已指向同一源应可重复注册。用一个 Sol 小任务验证真实加载后才交付 Nano PR。若安装或验证失败，Nano 继续从原入口运行；切换合入后若必须回退，可 revert 切换提交并恢复仓内入口。
编号器测试和 PR 模板链接测试随工具迁移，Nano 保留独立的分支归档检查、CI 接线与本地技能链接检查。Nano CI 不依赖用户级安装，也不跨库下载测试材料。
