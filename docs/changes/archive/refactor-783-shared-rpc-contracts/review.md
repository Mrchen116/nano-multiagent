## 用户入口和兼容

[隔离现场验收](acceptance.md) 记录了真实模型会话分支、在线与离线计划、配置确认恢复、历史 Work 权限和普通单聊工具授权。审查者独立读取认证 HTTP / WS 的脱敏产物及隔离数据库，对照会话归属、消息正文、配置版本和授权后的真实文件结果。实际故障注入使用受控节点，历史权限使用重建记录。验收覆盖 API 用户旅程，界面呈现、上游模型请求原文与生产环境未在本次观察范围。

发布基线是 v2.1.0（`ac275ecc7`）。通过正常入口组合当前 IM / 当前 Node、发布版 IM / 当前 Node、当前 IM / 发布版 Node，验证真实 WebSocket 往返、原始帧名及关联身份。旧 Node 对历史权限可能超时，支持明确拒绝的新 Node 返回同一请求的 HTTP 409 `request_ended`。当前 Global 执行策略不会创建人工等待卡。
