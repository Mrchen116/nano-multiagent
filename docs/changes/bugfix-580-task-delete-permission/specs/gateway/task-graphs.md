## MODIFIED Requirements

### Requirement: 删除任务遵守真实用户明确要求与既有图一致性

#### Scenario: 删除或自主工作
- **WHEN** 成员明确要求删除已指定范围或确认 Agent 说明的范围
- **THEN** Agent 按会话上下文和统一工具权限流程判断授权，获准后删除该范围并报告真实结果；笼统整理、解散群或主动调度不等于删除授权。
- **AND** 用户无需重复任务标题、ID 或固定确认口令；工具获准后，不要求本轮重新读取真人消息或重新收集删除授权。统一权限拒绝时不执行删除。
- **AND** stale revision、非法结构与结果未知继续按既有冲突/回执契约处理，不能无条件覆盖或重复删除。
