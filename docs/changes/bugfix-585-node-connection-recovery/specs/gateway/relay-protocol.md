# Gateway relay protocol delta for bugfix-585

## ADDED Requirements

### Requirement: 临时断线自动恢复且不绕过撤权

节点因连接失败、心跳超时或服务短暂关闭而断线时，使用有效凭据按退避自动重连并重新注册；注册成功后恢复新消息收发。明确撤权或账户停用仍终止自动重连。连接层不补发离线请求或重放投递结果不确定的业务帧。

#### Scenario: 临时连接条件恢复
- **WHEN** 连接条件恢复且授权有效
- **THEN** 节点无需用户重启、重新绑定或登录即可注册上线，用户新消息可正常获得 Agent 回复。

#### Scenario: 权限终止
- **WHEN** 节点被撤权或账户停用
- **THEN** 节点停止自动重连，不继续接收业务消息。

### Requirement: 断连及重连过程有安全持久诊断

托管 Node 的 gateway.log 记录节点、时间、阶段、可获的关闭码和安全原因、异常类型/分类、重试次数及退避、注册恢复与中断时长。前台运行可通过 stderr 留存同一诊断。不记录凭据、URL 或消息正文，未知远端关闭原因脱敏；不逐条记录正常心跳。

#### Scenario: 维护者追溯连接故障
- **WHEN** 节点发生连接失败、心跳超时或远端关闭
- **THEN** 持久日志可以关联断线、重试与注册恢复；未知原因明确为未知/脱敏，不捏造网络根因。
