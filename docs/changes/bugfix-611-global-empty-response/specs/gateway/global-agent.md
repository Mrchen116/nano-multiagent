# gateway global-agent Specification (delta for bugfix-611)

## ADDED Requirements

### Requirement: 全局轮次区分内部收尾与公开交付

#### Scenario: 模型空返回
- **WHEN** 全局 Agent 的模型请求返回空响应错误
- **THEN** 使用运行时既有重试策略恢复，耗尽后报告失败，不因全局模式把错误当作成功结束。

#### Scenario: 已交付或无需公开更新
- **WHEN** 全局 Agent 已交付结果、已告知阻塞或没有需要公开的更新
- **THEN** 系统要求它以简短、非空的内部说明收尾，说明留在工作轨迹，不自动成为聊天消息。
- **AND** 公开回复仍须显式发送，内部说明不代表用户已收到结果，也不要求重复发送已交付的内容。

### Requirement: 全局 Agent 在任务执行期间主动沟通

#### Scenario: 接到真人任务
- **WHEN** 全局 Agent 读取到真人交办的任务，且用户未要求不回复
- **THEN** 系统要求它在深入调查或执行前，向原会话显式发送简短确认和下一步说明，不让用户只能等到最终结果。

#### Scenario: 长任务过程更新
- **WHEN** 全局 Agent 处理长任务或多步骤任务
- **THEN** 系统要求它通过显式消息发送必要的进度，包括有意义的发现、阻塞或计划变化。
- **AND** 确认和进度通常为一两句话，避免重复状态、工具日志或空闲播报；用户明确不回复的要求仍受尊重。
- **AND** 确认和进度不代表最终结果已交付，内部草稿不算向用户更新。
