# 设计画面走查 · 2026-10-19

基线 main@dfdbf6bf3。真实 IM fixture + Vite、合成 alice 与成员群“发布计划协作”，通过浏览器登录并打开聊天。基线截图 [current-chat.png](current-chat.png)：当前窄屏将两位作者依次展示，头像/节点名/气泡/时间有稳定层级，输入区占底部。观察聊天保留阅读顺序，用只读说明替换输入区，避免误以为可以插话。基线是普通成员群，用于布局对照，不把它称为已经可观察私聊。

原型实际浏览器渲染 1280×720：[桌面](prototype-web.png)、390 宽聊天容器的[窄屏](prototype-narrow.png)、[原生设计示意](prototype-ios.png)。Desktop Network 中双方名字与选中会话对应；底栏能直接读懂只读约束，消息无输入按钮。窄屏追加长消息后内部滚动保留标题与只读底栏，内容换行不挤出容器。模拟撤销后显示不可访问、底栏消失。iOS 示意独立居中导航与 material 底栏，未把 Web 列表缩小称为原生；实际 SwiftUI 必须在实施模拟器核对。

以上证明设计意图及原型交互，不代表产品实现通过。实际产品的双 owner、重连、撤权与原生 UI 由后续独立产品验收观察。
