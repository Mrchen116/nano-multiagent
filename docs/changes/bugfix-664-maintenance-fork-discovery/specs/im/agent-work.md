## ADDED Requirements

### Requirement: 系统维护保留独立可回溯轨迹

系统维护不进入模型管理目录时，SHALL 继续在既有轨迹发起位置保留用途、父会话、本次起止范围、状态和真实会话入口；轨迹访问遵守既有 Work 权限。

#### Scenario: 维护效果不佳后回溯

- **GIVEN** 维护执行已完成、取消或失败，运行资源已经释放
- **WHEN** 用户在重启后从维护记录打开该次轨迹
- **THEN** 可按需查看继承上下文、维护输入、模型与工具记录、输出和结束事实。
- **AND** 查看不恢复执行，不需要先遍历全部维护历史或使用 `list_agents` 找到它。
