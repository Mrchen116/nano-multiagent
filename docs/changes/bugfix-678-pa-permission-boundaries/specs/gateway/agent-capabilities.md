# Gateway Agent Capabilities — bugfix-678 Delta

Target: `docs/specs/gateway/agent-capabilities.md`

## ADDED Requirements

### Requirement: Codex 独立审核通过原生只读工具调查

#### Scenario: 文件后段与关联证据
- **WHEN** 独立审核需要核实待审动作
- **THEN** 可使用 read/read_image/glob/grep 的原生读取、图像和查找能力，不受专用调查器仅文件开头或固定目录首批限制。
- **AND** 无 bash、网络、写入或委派权限；需要命令调查而无法得到的事实保持未知。

### Requirement: Codex 审核保留原始指令及完整性边界

#### Scenario: 长会话、委派与重建
- **WHEN** 审核经历长历史、子 Agent 委派、fork 或上下文重建
- **THEN** 独立保留有界的完整真人原话与必要问答/回复背景、可信来源及顺序；对照实际模型可见上下文补送缺失单元，后续限制/撤回同样适用。
- **AND** 父 Agent 转述、历史摘要、记忆和旧 allow 不产生新真人授权。

#### Scenario: 不完整原话
- **WHEN** 原始指令无法在预算内完整提供或来源不全
- **THEN** 明示缺失及剩余证据非完整授权；不截掉限制留下半条许可，不保证无限保留历史。

### Requirement: 所有模型调用具备匹配入口的技术恢复

#### Scenario: 各用途临时失败
- **WHEN** 主/子 Agent、审核、输入分类、摘要压缩、记忆知识处理、网页提炼或模型连接验证遇到可恢复技术错误
- **THEN** 已有 Agent 请求保持 DSH 原生恢复；当前未覆盖的独立请求通过一个共享组件补齐，按适用策略重试、支持取消并记录尝试；同一请求只由其中一条恢复路径负责，业务层和供应商不叠加重复重试额度。默认恢复有界；普通执行的用户显式 provider 策略保留，审核额外上限仍生效。
- **AND** 后续审核尝试仍获得正常判断预算；有效拒绝和永久配置错误不重试至允许。

#### Scenario: 部分输出与耗尽
- **WHEN** 模型流已输出一部分后失败，或恢复耗尽/被取消
- **THEN** 不把失败片段和新结果拼成伪完整响应，不重复已执行工具副作用；最终失败和取消准确交付业务层，不隐式新开一轮业务恢复。

## MODIFIED Requirements

### Requirement: 普通工具审批遵守当前有效执行上下文

#### Scenario: PA 长期跨聊天历史
- **GIVEN** PA 的消息库含长期、跨聊天历史，当前有效执行上下文和待审动作能够容纳在审核窗口内
- **WHEN** PA 请求执行需自动审核的普通工具动作
- **THEN** 审核不另行读取全库授权或聊天历史，不因库内记录规模使该动作审核输入膨胀。
- **AND** 真实身份、Inbox 原话和实际发送回执按所选策略投影；用户选择的规则、模型和工具约束继续生效。

#### Scenario: 主会话压缩后延续
- **WHEN** 主会话压缩后继续发起工具动作
- **THEN** CC/DSH 继续依据当前有效历史及必要宿主事实，不从消息库重放被压缩移除的原文；Codex 额外使用有界原始指令保留层，仅补送该层保留且实际缺失的完整单元，不重放全部消息库。
- **AND** CC 保持既有省略普通工具正文和超窗分流；Codex 按固定策略保留与选择证据，并明确遗漏；证据不足不伪造授权，摘要和助手转述不替代原话。

#### Scenario: PA 消息安全保持独立
- **WHEN** PA 接收外部直接请求或向非主人私聊受众发送内容
- **THEN** 继续执行各自的独立消息检查；普通工具审批结果不替代它们，也不因此附加其全量消息证据。
