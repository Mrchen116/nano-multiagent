# bugfix-681：配置页只展示当前有效计划

## 原始报告与决定

用户原话：
> 过期的完全没必要展示了吧，否则会一直增加进去
> 你来设计吧，从商业产品的角度去思考
> 好，改吧，快修模式，直接改完再补文档，改完把实际效果对比截图给我

已确认范围：将配置页作为当前计划管理入口，只显示有效计划；时间使用可读文案，指令收进详情，操作命名为取消计划。底层历史保留，不新增历史中心，不改变调度与执行行为。

## 现象与根因

运行时 catalog 返回 active/inactive 全部保存记录，接口已提供 enabled；Web CronCard 未使用该字段筛选，并直接渲染 schedule JSON 与完整指令摘要。一次性复核不断新建，失效记录因而持续堆积。

## 验收场景

- 混合有效与失效记录时，只展示 enabled=true 的计划；不能因为计划时间已过而隐藏仍有效的待投递计划。
- 全部记录失效时显示“暂无待执行的定时任务”。
- 单次、间隔、每日、每周、自定义周期有可读说明及带时区的下一次计划时间。
- 指令默认收起，详情可展开；取消仍调用原删除接口，保留已有离线与刷新保护。
- 接口、底层历史与 schedule_history 不改变；列表按已有查询刷新机制更新。

## 状态

实现和隔离组件预览完成；用户尚未亲自验收，unit 保持 active。无合并、生产部署或数据迁移。
