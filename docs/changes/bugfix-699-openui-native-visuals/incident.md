## 根因与原始观察

- Web 对 ThemeProvider 注入 Nano 专用颜色、字体、间距、圆角、图表调色板；另用 CSS 覆盖卡片内边距、背景和边框等。
- 生成指导强制 Nano 皮肤与预设间距。模型在酒店样本中选普通文字按钮代替圆形收藏图标，卡片采用大间距；看板用数量比例横条替代居中示意流程。
- 初轮错误地以 react-ui 标准目录代表官方 Intelligent UI 示例。open-intelligent-ui 本身有通用 Box/Svg/HtmlView 等能力；不能把本仓未接入的能力归为官方不支持，或要求预制每个业务页面。
- 线上修前 Book 为中号绿色按钮，约 46.4px 高、8px 圆角；卡片内边距 24px、gap 16px。仅限该样本、该视口。
