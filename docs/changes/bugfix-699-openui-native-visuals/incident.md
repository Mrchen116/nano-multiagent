## 范围与验收

- 恢复已固定 OpenUI 版本的默认颜色、字体、间距、圆角、卡片和图表视觉。
- Agent 通过通用组件自主选择布局、尺寸、图标与图表表达；不新增酒店或看板专用模板、组件、路由。
- 对照上述聊天中的酒店和广告看板参考图，用真实模型与浏览器核对实际效果，并明确不能还原的部分。
- 保留消息读取/提交权限、私人状态、宿主阅读空间和窄屏换行。
- 不扩大至生产部署、依赖升级或 iOS 视觉重写。

## 根因与原始观察

- Web 对 ThemeProvider 注入 Nano 专用颜色、字体、间距、圆角、图表调色板；另用 CSS 覆盖卡片内边距、背景和边框等。
- 生成指导强制 Nano 皮肤与预设间距。模型在酒店样本中选普通文字按钮代替圆形收藏图标，卡片采用大间距；看板用数量比例横条替代居中示意流程。
- 官网酒店示例采用专用展示样式；完整注册组件不能证明具有相同视觉，不能把这解释为无需改善 Agent 的通用组合能力。
- 线上修前 Book 为中号绿色按钮，约 46.4px 高、8px 圆角；卡片内边距 24px、gap 16px。仅限该样本、该视口。
