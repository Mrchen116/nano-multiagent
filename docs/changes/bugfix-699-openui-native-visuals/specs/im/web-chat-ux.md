# Web 交互回复 delta

归并目标：docs/specs/im/web-chat-ux.md 的“交互回复的统一视觉和信息层级”。用户确认前不归并。

### Requirement: 交互回复复用 Open Intelligent UI 通用表达与视觉

#### Scenario: 页面自主组合
- **WHEN** Agent 生成交互解释、工具或参考图复现
- **THEN** 使用固定上游 Open Intelligent UI 的布局、控件、计算、SVG/HTML 绘图及生成示例；宿主不以 Nano 皮肤覆盖组件，也不要求预先建立业务专用模板。
- **AND** 按参考的信息层级、密度、比例和交互含义选择表达；照片与示意图、示意宽度与定量刻度、演示数据与真实数据保持可辨。

#### Scenario: 本地编辑与只读历史
- **WHEN** 用户操作可编辑卡片或阅读只读历史
- **THEN** 响应式控件可本地计算并保存私有状态；只读卡片不能通过非原生点击控件修改共享状态或提交请求；业务工具仍遵守既有身份和审批规则。
- **AND** HtmlView 为独立受限页面，内部编辑不冒充 Nano 已保存状态，不获得宿主凭据或工具。

#### Scenario: 图片与地图资源
- **WHEN** 卡片使用上游图片查询或街道路由
- **THEN** 同源接口通过现有身份认证后请求固定公共服务，失败如实反映；可使用用户或工具提供的图片 URL，不将占位图当作已加载照片。

#### Scenario: 目录版本
- **WHEN** 发布本轮新卡片
- **THEN** 宿主填入 openui / nano-iui-1；Web 使用新目录，不提供旧 Web DSL 转换。未支持该版本的 native 客户端保留可读摘要与既有不支持提示。

#### Scenario: 自主选择与界面设计
- **WHEN** 用户给出复杂信息、比较、关系、过程或变化任务，未明确要求界面
- **THEN** 开启Intelligent UI的Agent获得主动使用UI的公共指导，先决定用户应优先理解什么，再选择结构、布局及可视化，并照顾视觉层级、间距、文字可读性与颜色一致性。
- **AND** 简短回答、情感交流及复用文字优先文字，遵守用户明确格式；交互只在有助于任务时加入，仍保持独立可读摘要及原有权限边界。实际是否采用与视觉效果通过真实case分别记录，不保证每次一定采用。
