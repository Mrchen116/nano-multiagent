# Web 交互回复视觉 delta

归并目标：docs/specs/im/web-chat-ux.md 的“交互回复的统一视觉和信息层级”。

### Requirement: 交互回复保留 OpenUI 默认视觉

#### Scenario: 不同内容与历史回复
- **WHEN** 用户阅读来自不同 Agent 的交互内容或重新打开历史卡片
- **THEN** Web 使用固定 OpenUI 版本的默认字体、颜色、间距、圆角、卡片与图表视觉；宿主仅提供聊天空间、窄屏布局和既有状态/权限反馈，历史组件和私人状态仍可使用。

#### Scenario: 按参考自主组合
- **WHEN** 用户提供界面参考，要求 Agent 复现大致效果
- **THEN** Agent 根据参考的信息层级、密度、比例和交互含义组合通用组件，选择合适尺寸、图标与图表表达，不要求预先建立业务专用模板；无法表达的部分明确说明，不将不同图形冒充同样效果。
