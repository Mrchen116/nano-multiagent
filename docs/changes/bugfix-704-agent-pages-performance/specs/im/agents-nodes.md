# Agent 配置读取体验增量

### Requirement: 已确认配置在普通后台刷新时保持可编辑

#### Scenario: 普通刷新保留草稿
- **GIVEN** 已确认当前用户、Agent、节点连接和配置版本，且没有未确认操作
- **WHEN** 配置在后台刷新或用户从其他窗口返回
- **THEN** 既有已确认字段可查看和编辑，草稿不被覆盖；刷新状态可辨认。
- **AND** 保存前重新确认当前准入、版本和依赖；不能确认时保留草稿且不声称保存成功。

#### Scenario: 连接或准入失效
- **WHEN** 节点断线、用户身份或权限变化、版本冲突或操作仍待确认
- **THEN** 不使用过期数据授权提交；展示可辨认状态并保留允许保留的草稿。
