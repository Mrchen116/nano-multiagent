## ADDED Requirements

### Requirement: Web 切换聊天保持会话界面和阅读位置

- 选中聊天后立即使用可用的列表头像和名称显示目标会话；短暂加载保持消息区安静，持续等待或首次读取失败时在该处给出状态或重试。欢迎页仅在没有选中会话时出现；空会话引导须等待消息历史确认。
- 本次浏览中返回已打开的聊天，访问复核成功后可先显示缓存消息，再刷新最新一页。离开期间有新消息则定位底部，否则恢复原阅读位置，包括之前翻到的较早历史。两种情况都恢复该聊天自己的草稿。
- 显式打开消息定位链接时优先定位目标消息；正在阅读历史时收到实时消息遵守既有滚动规则。

## MODIFIED Requirements

### Requirement: Web IM 新消息到达不打扰正在翻看历史的用户

将“普通打开会话时看到最新消息”场景替换为下列条件，保留同一需求下用户已在会话内阅读的两个场景。

#### Scenario: 首次打开或离开期间有新消息时看到最新消息
- **WHEN** 用户从聊天列表或不带消息定位的链接打开会话，当前浏览没有保存阅读位置，或该会话自上次离开后新增了消息
- **THEN** 消息列表定位到最底部
- **AND** 内容稍后展开时，仍在底部附近的视图继续跟随；用户已上翻时保留阅读位置
