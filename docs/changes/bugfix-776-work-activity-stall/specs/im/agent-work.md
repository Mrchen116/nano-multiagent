## ADDED Requirements

### Requirement: 在线 Agent 的工作状态独立反映其记录完整性

IM SHALL 依据目标 Agent 已确认的记录，分别呈现头像弹窗的执行状态与派工图的同步状态。

#### Scenario: 同机其他 Agent 回补或上传历史

- **WHEN** 其他 Agent 在同一节点回补或上传历史，且目标 Agent 的记录已获中心确认
- **THEN** 头像弹窗显示目标 Agent 的主执行状态和子执行数量，派工图显示目标 Agent 的同步状态。

#### Scenario: 主执行已确认而子执行仍在回补

- **WHEN** 主执行的记录已确认而该 Agent 的子执行仍在回补
- **THEN** 主执行行可独立显示实际状态，子执行行继续等待可信计数。
- **AND** 回补完成且对应事件已获中心确认后，已打开的弹窗显示实际子执行数量；离线或未知期间不得据此推断为零。

#### Scenario: 补齐完成时没有新增工作记录

- **WHEN** 打开的头像弹窗或派工图仍在等待，节点只上报进度且中心已经确认对应记录
- **THEN** 在线页面及时重读该 Agent 已确认的状态，即使工作记录版本号没有改变，也无需等待下一轮定时刷新。
