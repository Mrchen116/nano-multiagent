提案改动点（对应上面右侧效果）：
  • 折叠态一行就有信息量：emoji + 工具名 + 主参数摘要 + 失败标红（exit 1 不用点开就能看到）。
  • Bash 展开 = 终端块：命令 + stdout/stderr（presenter 已生成，Gateway 透传即可），超长截断 + "已截断" 提示。
  • Edit 展开 = diff 视图：presenter 已生成 unified diff，前端着色渲染。
  • Web 展开 = 标题 + URL + 正文摘录（presenter 已有 500 字符摘录）。
  • Agent / Memory / Skill / Stop 有专属卡片：现状 agent/memory/skill_manage/task_stop 全落 default presenter，显示截断 JSON。Agent 展开必含完整派发 prompt。
  • 路径做 home 缩短（…/heartbeat/state.py），长输出/秘钥做脱敏截断。
