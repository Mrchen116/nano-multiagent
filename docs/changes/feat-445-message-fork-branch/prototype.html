原型覆盖的 spec 行为

  • 已完成 agent 回复可 fork：hover agent 气泡卡片右侧出现 ⑂ fork（仅 isAgent && delivery_status==="completed"）。
  • 一次提问多条气泡各自可 fork：同一 run 连续两条 agent 气泡（“分三点” + “补一句”）各带独立 fork，分别 fork 截断点不同。
  • 用户消息 / 生成中消息无 fork：用户气泡、running 态（⏱ 脉冲）气泡都不出按钮。
  • 带入起点→fork 点：fork 第一条 → 分支到该条；fork 后一条 → 多带一条，fork 点之后不带。
  • fork 后自动进入 + 原会话不变：右侧自动填充并可输入；左侧原封不动。
  • agent 离线禁用：切离线后 fork 置灰 + “该 agent 当前不可用，暂时无法 fork”。
