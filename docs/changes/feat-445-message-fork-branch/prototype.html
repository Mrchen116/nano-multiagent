原型覆盖的 spec 行为

  • 已完成 agent 回复可 fork：hover 出 ⑂ 按钮（仅 agent 且已完成的气泡）。
  • 用户消息无 fork：自己发的消息 hover 不出按钮。
  • 生成中无 fork：仍在「打字」的 agent 气泡无按钮，待完成才出现。
  • 带入起点→fork 点：fork 第一条 agent 回复 → 分支只含到该条；fork 后面的回复 → 分支含更多，fork 点之后的不带。
  • fork 后自动进入 + 原会话不变：右侧自动填充并可输入；左侧源会话原封不动。
  • agent 离线禁用：点「切到离线」后，fork 按钮置灰 + 「该 agent 当前不可用，暂时无法 fork」提示。
