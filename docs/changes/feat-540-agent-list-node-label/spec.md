## 用户场景

用户在多台设备上运行节点:mac-mini 上 4 个 agent、macbook-air 上 8 个 agent。打开 IM Web 的 Agents 页,左侧列表里 12 个条目混在一起。今天想知道某个 agent 属于哪台设备,只能逐个点开详情页看头部的设备名。

将来:打开 Agents 设置首页,或点开任一 agent 的详情页、新建页(左侧是同一个列表),每个条目的右缘直接标注它归属的设备名,右对齐排成一条竖线,扫一眼就完成「这个 agent 在哪台设备上」的区分。条目的行高、显示名与 Agent ID 两行完全保持今天的样子,不因为设备名少显示一个字符。agent 的在线/离线状态从条目头像右下角的角标辨认,右缘不再有独立圆点。设备离线时设备名照常显示——归属不随离线消失。移动端打开同一个列表,每个条目同样标注。

同一批改动里,桌面端 Agents 设置首页的列表变得真正能看:今天未选中条目的名字用深色字写在深色侧栏上,几乎看不见;修好后,首页列表和详情页列表的每个条目、每种选中状态下文字都清晰可读、观感一致。

## 验收标准

### Requirement: Agents 列表每个条目右缘标注归属设备

#### Scenario: 多设备下逐条标注
- **GIVEN** 当前账号有多台设备且各有若干 agent
- **WHEN** 打开 Agents 设置首页的左侧列表,或打开任一 agent 详情页 / 新建页左侧的同款列表
- **THEN** 每个条目的右缘显示该 agent 归属设备的名字,与 Account 页显示的设备名一致
- **AND** 各条目的设备名右对齐,在所有条目间位置一致

#### Scenario: 设备设置别名时显示别名
- **GIVEN** 某 agent 归属的设备设置了别名
- **WHEN** 查看列表
- **THEN** 该条目右缘显示该别名,与 Account 页该设备的展示一致

#### Scenario: 设备离线仍显示归属
- **GIVEN** 某 agent 归属的设备当前离线
- **WHEN** 查看列表
- **THEN** 该条目右缘仍显示该设备名

#### Scenario: 移动端同样标注
- **WHEN** 在移动端打开 Agents 列表
- **THEN** 每个条目同样显示归属设备名

### Requirement: 标注不牺牲条目既有信息与状态表达

#### Scenario: 名字两行与行高不被挤压
- **WHEN** 查看加入设备标注后的列表条目
- **THEN** 显示名行与 Agent ID 行的内容、字号与截断行为保持原样,不因设备名少显示字符
- **AND** 条目行高保持原样

#### Scenario: 在线状态由头像角标表达
- **WHEN** 查看列表条目
- **THEN** 条目的在线 / 离线状态从头像右下角角标辨认
- **AND** 条目右缘不再出现独立的状态圆点

### Requirement: 三处列表条目文字在深色侧栏上清晰可读

#### Scenario: 桌面端首页列表未选中条目可读
- **WHEN** 在桌面端打开 Agents 设置首页的左侧列表
- **THEN** 未选中条目的显示名与 Agent ID 以与详情页侧栏相同的浅色文字呈现,清晰可读

#### Scenario: 选中与 hover 条目可读性一致
- **WHEN** 在桌面端三处列表中选中或 hover 任一条目
- **THEN** 条目文字在选中 / hover 底色上保持可读,且三处列表观感一致

## 范围与非目标

- 在范围:
  - Agents 设置首页、agent 详情页、agent 新建页左侧同款列表的条目设备归属标注;
  - Agents 设置首页侧栏桌面端条目文字颜色修复(深底深字,与详情页侧栏统一);
  - 桌面端与移动端。
- 非目标:
  - 按设备筛选、分组、搜索或调整条目排序;
  - Chat 页会话列表、Account 页、Nodes 页的任何改动;
  - 后端接口改动(设备名已由现有 Agents 接口随条目返回);
  - 显示名 / Agent ID / 设备名三者的具体字号、字色、字重取值——用户要求「符合审美」的这份视觉设计属设计阶段产物,本 spec 只锁定用户可观察结果(右缘标注、名字两行不让位、行高不变、状态由头像角标表达)。
