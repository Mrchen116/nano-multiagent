# gateway routing-delivery Specification (delta for feat-563)

## ADDED Requirements

### Requirement: Agent 获得执行环境与用户界面的背景

PA 的普通与全局 Agent 获得执行环境与用户端可能不同的说明，以及 Web IM 用户访问入口；可选的执行环境访问地址仅在配置时提供。系统提示不固定当前消息渠道或动态时间，逐消息来源保持权威。

#### Scenario: 用户描述当前页面
- **WHEN** 用户从 Web IM 或飞书描述界面问题
- **THEN** Agent 能依据消息来源理解用户使用的界面；Web IM URL 只解释内部聊天界面，不代替飞书入口或执行环境地址。

#### Scenario: 执行端文件或预览
- **WHEN** 用户要求查看 Agent 本地生成的产物
- **THEN** Agent 知道本地文件和服务不必然对用户可达，依据实际配置和已确认条件交付，不猜测用户网络权限。

#### Scenario: 节点或配置变化
- **WHEN** 后续运行使用了新的执行节点或已更新的访问配置
- **THEN** Agent 使用与该次运行一致的背景，正在进行的运行保留原始快照，历史消息来源时间不被重写。

### Requirement: 图片发送结果能指导 Agent 恢复

#### Scenario: 普通回复被拦截
- **WHEN** 普通回复因图片问题而未发送
- **THEN** Agent 得到系统反馈，明确该草稿未送达而此前成功消息仍可见，并根据具体原因继续修正或如实说明未完成。

#### Scenario: 显式发送被拦截
- **WHEN** send_message 因图片问题而未发送
- **THEN** 工具返回简短的未发送事实、原因和修正方向，不返回成功，不向用户发布内部错误正文；已有新输入拦截反馈保持。

#### Scenario: 重试与部分完成
- **WHEN** 已准备图文的投递回执丢失或仅部分渠道成功
- **THEN** 继续恢复时复用原交付身份与已知回执，不重复投递已成功渠道，不向 Agent 谎称所有收件人都未收到；无法确认时保留未确认状态。

## MODIFIED Requirements

### Requirement: 当前会话的 Agent 图片回复具有统一交付语义

Gateway MUST 将普通 assistant 回复中的可交付图片与文字按原顺序交付到当前聊天；全局 Agent 向已有聊天显式调用 `send_message` 时沿用相同图片交付。支持本地 PNG/JPEG/WebP 产物和既有可获取网络图片。Agent 可直接引用获准读取并向目标发送的本地文件，不要求位于固定交付目录；图片引用本身不授予额外权限。显式发送沿用一次工具权限判断，普通图片回复执行同等发送权限判断。每气泡最多五个不同来源、单图最多 10 MiB；同来源重复引用不重复准备资源。

#### Scenario: 本地产物跨机器查看
- **WHEN** 用户请求 Agent 展示其通过工具准备的本地图片
- **THEN** 原聊天可以直接查看图片和说明，无需用户访问运行机器。

#### Scenario: 图片语法不绕过权限
- **WHEN** 回复引用无权读取或未准备为可交付产物的文件
- **THEN** 图片不发送，失败反馈给 Agent 按现有权限规则处理，用户正文不出现内部失败占位。

#### Scenario: 图文投递保持入口路由
- **WHEN** 飞书触发的 run 产生中间或最终图文回复
- **THEN** 原飞书聊天和内部影子会话收到等价内容，普通富文本和运行信息卡片均可显示图片
- **WHEN** 内部 IM 影子会话触发同类回复
- **THEN** 只在内部 IM 显示，不回写飞书。

#### Scenario: IM 离线不阻塞飞书图片
- **GIVEN** 飞书可用、IM 暂不可用
- **WHEN** Agent 产生图片回复，随后 IM 恢复
- **THEN** 飞书先收到图文，IM 后续补齐相同图片的历史且不重复创建气泡。

#### Scenario: 局部图片失败
- **WHEN** 图片不可读、格式不支持、超限或上传失败
- **THEN** 该候选在发布前被拦截，具体失败对象、原因和修正方向返回 Agent；Agent 可修正后重新交付，用户不会收到内部错误占位或声称全部图片已发出的不完整成品。

#### Scenario: 普通文本和示例保持原语义
- **WHEN** Agent 回复纯文字或代码中的 Markdown 图片示例
- **THEN** 保持原有文字，示例不触发文件读取或图片发送。

#### Scenario: 全局 Agent 向已有聊天显式发送图片
- **GIVEN** 全局 Agent 已有可投递的 IM 聊天目标
- **WHEN** Agent 通过 `send_message` 发送其准备的本地图片及说明
- **THEN** 聊天成员直接看到保护后的图片，刷新后仍可回看；持同一 URL 的非成员不能读取
- **AND** 同次投递重试复用原快照与上传回执，已知过时的群候选不准备外发资源；资源准备后提交前再次复核，过时草稿不公开，已准备资源不冒充已送达消息。
