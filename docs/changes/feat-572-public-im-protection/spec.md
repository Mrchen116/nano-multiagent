## 用户场景

1. **本人手机访问**：用户在 iPhone 保持 Shadowrocket 开启，直接打开 `https://im.nanoim.win`，仅登录 Nano IM 即可聊天、上传附件、查看 Work 和收到实时回复，无需 Tailscale 或额外 Cloudflare 身份验证。
2. **朋友加入与协作**：朋友从正常注册页创建自己的账号，进入共享联系人与 Agent。用户和朋友可参加同一个群；聊天、附件和管理权限继续遵守既有成员／owner 规则，全局完整 Work 的共享行为保持。
3. **认证遭遇滥用**：来源反复注册、尝试密码或轮换来源攻击同一账号时，系统在实际昂贵操作前限制滥用，并给正常用户可理解、可恢复的反馈。攻击者不能靠伪造来源声明绕过限制；共享网络下的合理少量使用仍可进行。
4. **会话退出、刷新与重启**：用户正常刷新登录，旧刷新凭据失效；用户退出后不能用已吊销的刷新凭据恢复会话。服务重启不会恢复这些失效凭据，仍有效的正常会话也不因无关重启被强制全部登出。
5. **附件与资源滥用**：成员上传的正常图片与文件可使用；伪造地址不能使 Agent 自动访问宿主机内网或读取非成员附件。反复上传、发送过大消息或建立过量实时连接时，服务拒绝超限请求并保持正常账号可用，不持续占满磁盘、内存或连接资源。
6. **管理与运维**：部署管理员可维护系统级设置，普通用户只能执行其获准的个人及资源管理操作。运维人员可确认当前保护生效、发现认证／资源拒绝异常，并在故障时关闭公网入口、恢复服务和已保存的数据，不公开登录凭据或宿主机其他服务。

## 验收标准

### Requirement: 正常用户只需 Nano IM 账号即可从公网访问

#### Scenario: 手机直接访问与实时使用
- **GIVEN** 已部署公开 Nano IM，iPhone 正在使用 Shadowrocket
- **WHEN** 用户从手机浏览器打开部署网址并登录自己的 Nano IM 账号
- **THEN** 可正常聊天、上传允许的附件、查看 Work 并收到实时回复，无需 Tailscale、Cloudflare 账号或额外身份登录
- **AND** 浏览器连接安全，不出现证书警告

#### Scenario: 朋友公开注册
- **WHEN** 一位未注册朋友打开注册页并提交符合现有规则的账号信息
- **THEN** 可创建自己的账号并进入产品，不要求邀请链接或邀请凭据
- **AND** 重名、保留身份和不合规则的输入继续按现有规则拒绝

#### Scenario: 匿名访客只能进入公开认证入口
- **WHEN** 未登录访客打开认证页面，或尝试直接读取聊天、附件、Work 和使用实时消息
- **THEN** 认证入口可正常使用，受保护内容及实时能力拒绝访问，不泄漏其正文

### Requirement: 注册与认证具有实际生效且可恢复的滥用防护

#### Scenario: 单一来源反复尝试被节流
- **WHEN** 同一来源短时间大量注册或尝试登录
- **THEN** 超限请求被暂时拒绝，页面明确提示稍后重试；被拒的注册不产生账号
- **AND** 限制期结束后，符合规则的正常请求可继续

#### Scenario: 同一账号的分散密码猜测受到限制
- **WHEN** 多个来源持续对同一账号尝试错误密码
- **THEN** 该账号的重复尝试受到临时限制，错误反馈不区分账号不存在与密码错误
- **AND** 合理等待后账号可恢复登录，不因攻击永久锁死

#### Scenario: 客户端不能伪造来源绕过防护
- **WHEN** 超限客户端只修改其请求中的来源声明后继续尝试认证
- **THEN** 不能凭自报身份解除限制，真实公网用户仍按实际来源处理

#### Scenario: 合理少量用户与会话恢复可用
- **WHEN** 少量朋友在同一网络正常注册、登录或恢复有效会话
- **THEN** 可完成正常操作；登录、注册与限流提示使用当前页面语言，失败不清空无关输入

### Requirement: 刷新凭据吊销在并发和服务重启后仍可靠

#### Scenario: 刷新轮换后旧凭据保持失效
- **GIVEN** 用户持有有效会话
- **WHEN** 用户成功刷新后再次用旧刷新凭据恢复会话，包括服务重启后重试
- **THEN** 旧刷新凭据被拒，新会话可正常继续

#### Scenario: 并发刷新不能重复恢复会话
- **WHEN** 同一刷新凭据同时被重复用于恢复会话
- **THEN** 至多一次成功，其余请求拒绝使用已消费凭据

#### Scenario: 退出后失效状态跨重启保留
- **GIVEN** 用户已正常退出一个会话
- **WHEN** 服务重启后用该会话旧刷新凭据尝试登录恢复
- **THEN** 仍被拒绝；其他未失效的正常会话可继续使用

### Requirement: 系统级管理与既有协作权限有明确边界

#### Scenario: 系统策略仅管理员可写
- **WHEN** 部署指定的管理员修改系统级策略
- **THEN** 可保存并回看生效配置
- **AND** 普通登录用户执行相同修改被拒绝且不改变配置；页面明确显示其可操作范围

#### Scenario: 新注册不能自动获得系统管理权
- **WHEN** 普通用户注册账号或提交自称管理员的信息
- **THEN** 不因此取得系统级写权限，个人设置与已获准的聊天能力仍可使用

#### Scenario: 既有共享 Work 保持
- **WHEN** 已登录朋友查看共享联系人、全局 Agent Work 和已有子执行明细
- **THEN** 仍可查看 current 设计允许的完整工作轨迹，不新增按来源聊天过滤或邀请门禁

#### Scenario: 成员和 owner 边界保持
- **GIVEN** 两个独立账号拥有各自私聊、附件及资源，并参加一个共同群聊
- **WHEN** 两人分别读取与修改这些对象
- **THEN** 共同群成员可正常协作，非成员不能读取或写入原私聊及附件，非 owner 不能修改他人的 Agent／节点配置或读取其受限管理数据
- **AND** 从共享 Work 跳转原聊天或附件时仍按成员关系判定

### Requirement: 自动附件处理不能访问任意服务端目标

#### Scenario: 正常上传与 Agent 图片理解保持
- **WHEN** 成员上传允许的图片或文件并发送到有 Agent 的聊天
- **THEN** 成员可读取附件，Agent 可处理正常图片并回复；正常外部频道附件链路保持可用

#### Scenario: 伪造地址和附件引用被拒绝
- **WHEN** 客户端提交宿主机内部地址、其他未经允许的自动下载目标或非成员附件引用
- **THEN** 请求或附件处理被拒绝且给出明确失败反馈，不会借 IM／Gateway 自动访问该目标或读取无权附件
- **AND** 普通文本中的外链不会仅因这项防护失去原有展示能力

### Requirement: 公网滥用不能无界消耗服务的有限资源

#### Scenario: 超限上传和请求有明确拒绝
- **WHEN** 账号重复上传超过允许累计额度，或提交超过允许大小的消息／附件
- **THEN** 超限操作被拒绝并得到可理解的限制说明，不留下不完整的成功对象；额度内的正常使用可继续

#### Scenario: 实时连接受控且可恢复
- **WHEN** 同一主体建立过量实时连接、发送过大内容或高频重复操作
- **THEN** 超限行为受到限制，正常聊天连接继续可用；释放连接或限制期结束后可正常重新连接

### Requirement: 发布与恢复可验收，凭据不随运维证据公开

#### Scenario: 公网仅开放预定 IM 服务
- **WHEN** 运维完成上线并从外部检查公开入口
- **THEN** 可使用预定 Nano IM 入口，宿主机其他服务、内部控制入口与运行文件不因本次接入变得公开可访问
- **AND** 用户侧注册、登录、实时消息和附件均经过已生效的应用安全边界

#### Scenario: 运维证据不包含可复用凭据
- **WHEN** 运维核对认证拒绝、资源超限、服务健康或收集公开交付证据
- **THEN** 可辨认保护是否生效及故障类别，常规访问记录、错误反馈和交付材料不暴露密码、可复用会话凭据或 Tunnel 连接凭据

#### Scenario: 故障时可停止公开访问并恢复
- **GIVEN** 上线后发现故障或需要回退
- **WHEN** 运维按经验证的恢复流程操作
- **THEN** 可停止新的公网访问，恢复已保存的数据与原服务可用性，不因回退改变账号身份或覆盖无关配置

#### Scenario: 免费部署范围可核对
- **WHEN** 运维核对上线使用的 Cloudflare 功能与域名续费配置
- **THEN** 使用已确认的免费 Tunnel 方案，未新增付费附加功能；域名续费价格和自动续费状态可明确核对

## 范围与非目标

### 在范围

- 正常公开注册、Nano IM 登录以及保护生效时的前端可理解反馈。
- 认证滥用限流、可信来源处理、持久刷新凭据吊销及并发轮换。
- 系统级策略管理权限，既有成员、owner、机器身份与共享 Work 边界回归。
- IM／Gateway 自动图片与附件访问边界、资源大小与累计上传限制、实时连接及操作滥用保护。
- HTTPS 公网入口、只接入预定 IM 服务、常规诊断中的凭据保护、发布前验收和可执行恢复流程。
- 免费入口防护能力的选择与费用范围核对；所有本次文件位于仓库内。

### 非目标与边界

- 不做邀请注册，不增加 Cloudflare 账号登录，不重做共享 Work 或完整多租户产品模型。
- 不增加付费 Cloudflare 套餐或附加产品，不开放其他主机服务，不构建通用商业计费或配额平台。
- 不承诺任何规模的 DDoS 下都可用，也不把认证限流当作全网 DDoS 防护；公网入口与应用资源防护各自承担其可验证范围。
- 不把有限安全审查、mock 或通过既有回归当作“零漏洞”或生产公网验收证明。
- 不在首文档阶段选择存储结构、接口字段、限额数值、代理实现或 milestone 拆分；交给 design，并对照真实部署与既有能力作最小适当实现。
- 本次调用只完成首文档；实施、独立门禁、上线分别按后续生命周期执行。新建 unit 不表示已修复、已部署或已批准公网开放。
