# IM conversations-messages Specification (delta for feat-572)

## ADDED Requirements

### Requirement: 上传与实时资源具有累计边界

#### Scenario: 上传累计超额与正常文件
- **WHEN** 用户或机器上传合法附件
- **THEN** 同时受单文件、账号累计和服务累计限制；并发及断流不能绕过配额或永久占用未完成预留，超额给出可恢复反馈。
- **AND** 合法会话成员可继续上传、发送和回看限额内附件；非成员不能借附件 ID/URL 绕过会话权限。

#### Scenario: 当前聊天草稿中的附件失败反馈
- **WHEN** 附件因单文件大小、格式、累计空间、限流或网络问题上传失败
- **THEN** 在当前聊天草稿区对应文件显示原因及移除/适用的重试动作，正文及其他已上传文件保留，不伪装成已发送消息。
- **AND** 存在失败文件时不静默忽略文件发送；可明确选择仅发送文字并保留全部未发送附件，或移除失败项/重试成功后一起发送。限流按 Retry-After 等待；消息发送失败也保留待发内容，确认发送成功后才清理本次提交项。

#### Scenario: 容量告警由管理员处理
- **WHEN** 账号累计或服务累计容量触顶导致附件上传被拒绝
- **THEN** 普通聊天用户仅见“暂时无法上传附件”，正常文字消息继续可发，不要求用户清理附件或联系管理员。
- **AND** 管理员在现有“策略”页的存储状态区查看容量告警并处理；普通成员不可读取告警中的容量明细和相关账号。容量恢复后上传恢复，不新增附件管理或计费平台。

#### Scenario: 超大请求与慢实时客户端
- **WHEN** 请求体、WS 帧、连接数或待发送缓冲超过配置上限
- **THEN** 有界拒绝、限流或断开，不持续无限堆积；正常客户端重连沿用既有重放语义并重新验证资格。

### Requirement: 公网入口与凭据保持限定范围

#### Scenario: HTTPS 入口与日志
- **WHEN** 用户从公网浏览器访问 IM
- **THEN** 只有预定的 IM Web/API/WS 经 HTTPS 开放，无额外身份产品登录；其他服务与本机控制入口不随之公开。
- **AND** 长期令牌、密码、渠道密钥和私钥不进入 URL/access log 或错误回显，客户端不能伪造受信代理来源。
