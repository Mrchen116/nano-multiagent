## 已走通的交互

- 根层完成情况 → 第二层（仅两个直属节点）→ 节点详情 → 编辑并提交待确认结果。
- Agent A 改派 Agent B → 所属群出现一条 @A/@B 系统消息；状态保持进行中。
- 结构图/完成情况切换；全局负责人筛选包含直接匹配的深层节点及父路径。
- 公开访客只读且新建禁用 → 自行加入 → 领取未分配任务；普通成员仍无其他创建者任务的删除入口。
- 普通成员打开群设置：范围不可修改。
- 管理员公开→私密保存并关闭弹窗→解散确认→只读任务历史；未完成关闭、done 保留。
- 删除父任务确认显示共 3 个节点，取消正确关闭；新建根任务表单保存；手机新建群默认公开。

修正：群设置保存/取消的 inline handler 中 close 名称与浏览器环境冲突，统一改为 closeModal，并重新走通保存、取消、解散确认；不再遮挡后续操作。最初聊天演示沿用了任务侧栏，已改为会话侧栏；加入后的显示身份和成员名单随演示状态更新。更新后的聊天消息截图已重新渲染并查看。
