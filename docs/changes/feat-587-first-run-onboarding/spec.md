## 澄清记录

- 用户确认 IM 已托管，目标是让外部用户安装本机节点后连接现有 IM，不要求用户部署 IM。
- 用户确认个人注册直接获得自己的空间，加入团队才需批准；不得把自动批准误实现为开放现有团队数据。
- 用户要求同时提供可复制给本地 Agent 的安装 prompt 和简明手动安装路径。
- 用户明确授权本 unit 内自主完成体验与技术取舍，不再逐项请求设计确认。
- Agent 裁决：首版聚焦桌面浏览器 + macOS/Linux 电脑端，Windows 明确指引 WSL；手机页面可查看/复制步骤，安装须在运行助手的电脑上执行。保留已有用户、团队及节点。
- Agent 裁决：以个人空间、连接电脑、连接模型、定义助手、第一次真实回复形成一个连续可恢复旅程；进阶配置保留在现有设置页面。
- Agent 裁决：交付包含独立审查、真实隔离栈验证、可播放的新用户流程视频和 Ready PR；不把录屏、合并或生产部署混为同一事实。

## 用户场景

一个第一次访问 Nano 的用户，创建账号后立即进入自己的空间。他看见清晰的进度与当前唯一主要动作。已经使用本地 coding agent 的用户复制专属安装说明给它；其他用户复制一条安装命令到自己电脑的终端。安装过程自动准备依赖和私有工作目录，连接当前 IM，引导用户在已登录网页确认这台电脑。已有安装重复执行后保留数据并继续，而不是创建多个节点。

电脑上线后，页面检测该电脑已有的模型连接/登录。用户可以确认使用发现的连接，也可以选择 API 服务商并输入 Key；自定义服务可填写地址和模型。用户看到可验证的成功或可执行的修复建议，失效连接不伪装成成功，也不要求他编辑 YAML。

用户选择希望助手主要帮助什么，给助手一个名字并填写自己的目标；可使用合理默认值。界面解释助手工作的电脑和文件位置，复杂的工作模式、工具列表与推理参数不抢占首次体验。创建后进入和该助手的聊天，并提供符合刚才目标的起步任务；只有真实回复到达，才表示第一次体验成功。

用户可关闭页面再回来继续，也能修复离线电脑和失败模型连接。已有用户照常进入聊天，不被强制重新引导。需要与现有团队协作的人主动申请加入，批准前可继续使用个人助手但不可读取团队联系人、Agent、任务或会话。

## 验收标准

### Requirement: 个人注册立即可用并与现有团队隔离

#### Scenario: S1 新用户拥有独立空间
- **WHEN** 新用户从普通注册入口创建账号
- **THEN** 无需管理员批准即可进入个人首次设置、连接自己的电脑
- **AND** 不展示其他个人或团队的联系人、助手、任务与工作记录。

#### Scenario: S2 团队加入需批准
- **WHEN** 个人用户主动申请加入团队
- **THEN** 看见等待批准状态，个人使用不受阻
- **AND** 团队管理员批准后才获得团队协作范围；现有团队用户原有访问保持。

### Requirement: 页面提供两条真实可执行的安装路径

#### Scenario: S3 交给本地 Agent 安装
- **WHEN** 用户选择“交给本地 Agent”并复制安装说明
- **THEN** 得到包含当前 IM 地址和完整操作目标的 prompt，可交给其本地 Agent 安装并连接电脑
- **AND** 不包含账号密码或模型密钥，不要求用户提供仓库路径。

#### Scenario: S4 手动安装
- **WHEN** macOS/Linux 用户选择手动安装并执行页面命令
- **THEN** 自动准备电脑端依赖和配置，进入网页确认绑定，无需构建前端、启动 IM 或手写 YAML
- **AND** 页面明确安装发生在用户自己的电脑，并说明 Windows 的 WSL 路径。

#### Scenario: S5 安装恢复与电脑掉线
- **WHEN** 用户重复执行安装，或已连接电脑暂时掉线
- **THEN** 保留已有身份和工作数据，页面显示继续/恢复动作，不要求重新注册或重新建助手。

### Requirement: 模型接入在页面完成并验证真实可用性

#### Scenario: S6 复用已有本机连接
- **GIVEN** 目标电脑上存在受支持的 Codex 登录或本地模型代理
- **WHEN** 用户进入模型步骤并确认使用发现的连接
- **THEN** 无需复制令牌、配置文件或手写代理配置，页面完成验证并显示可用结果。

#### Scenario: S7 使用 API
- **WHEN** 用户选择服务商并填写 Key，或填写自定义地址和模型
- **THEN** 可在页面测试并保存连接，随后首个助手可使用该模型
- **AND** 再次进入不回显 Key，安装 prompt 和诊断不泄露凭据。

#### Scenario: S8 连接不可用
- **WHEN** 没有发现连接、登录失效或 API 验证失败
- **THEN** 页面区分当前状态，给出重新登录、修正配置或重试的动作
- **AND** 失败不跳过模型步骤，也不丢失已完成的安装和绑定。

### Requirement: 有指导地创建首个助手

#### Scenario: S9 用少量输入定义助手
- **WHEN** 用户完成模型接入
- **THEN** 可选择用途并以名称、目标等少量输入创建助手，看到工作的电脑和文件位置
- **AND** 有可用默认值，进阶配置不阻断首次创建。

#### Scenario: S10 完成第一件事
- **WHEN** 用户创建助手并发送建议起步任务或自己的任务
- **THEN** 进入真实聊天，收到使用所选模型产生的回复
- **AND** 清楚看到结果，能够继续对话和进入现有管理功能。

### Requirement: 引导连续、可恢复且与已有体验一致

#### Scenario: S11 刷新恢复
- **WHEN** 用户刷新或重新登录
- **THEN** 按已经连接的电脑、模型和创建的助手继续，不重复安装或创建。

#### Scenario: S12 已有用户与窄屏
- **WHEN** 已有用户进入产品，或新用户在窄屏打开引导
- **THEN** 已有用户仍正常进入自己的聊天；窄屏下说明、复制、表单、反馈和主要操作均可读可用
- **AND** 中英文入口和错误反馈保持一致。

## 范围与非目标

- 在范围：个人访问与团队审批分离、托管 IM 的首次设置、两种电脑端安装入口、节点配置引导、模型发现/API 配置与验证、首个助手指导、首次真实聊天、失败恢复、独立验收及完整体验视频。
- 非目标：重新部署 IM 的产品教程、全面团队组织重构、原生桌面安装器/App Store 上架、iOS 推送、重做整个 IM、引入第二套 Agent Loop、默认开启主动外发或大量后台任务。
- 录屏须区分真实产品与本机终端安装过程；允许标注压缩等待时长，但不能用 mock 回复或预置助手冒充首次成功。
