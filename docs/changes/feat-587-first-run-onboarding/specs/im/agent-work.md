## MODIFIED Requirements

### Requirement: 聊天沟通与全局工作轨迹分开呈现

#### Scenario: Agent 向聊天报告进展或结果
- **WHEN** 主 Agent 选择向某个群聊或单聊发送进展、问题或结果
- **THEN** 消息出现在它明确选择的聊天中
- **AND** 不附带与该聊天无关的整段全局执行轨迹

#### Scenario: 查看员工整体工作
- **WHEN** 对该 Agent 所在空间有访问权的已登录用户进入全局 Agent 的工作视图
- **THEN** 可以查看主 Agent 跨聊天的连续工作轨迹，辨认其读取、执行及委派过程

#### Scenario: 深入查看 subagent 工作
- **GIVEN** 主 Agent 已委派 subagent
- **WHEN** 用户查看这次委派对应的执行过程
- **THEN** 可以查看 subagent 的工作轨迹及当前结果，并辨认其与主 Agent 委派的关联，不要求是 Agent 管理者

#### Scenario: Work 内容完整可见，原聊天仍按成员访问
- **GIVEN** 主执行和子执行记录包含查看者未参与的聊天内容
- **WHEN** 有该 Agent 空间权限的用户查看 Work，或从中点击来源聊天及受保护附件
- **THEN** Work 的已有内容不按来源聊天过滤或遮盖；原聊天和受保护附件仍按成员关系判定，非成员无法读取。

#### Scenario: 非管理者持续查看工作进度
- **GIVEN** 用户打开有权访问的公司全局 Agent Work
- **WHEN** Agent 产生新的过程记录，或用户刷新、恢复可见页
- **THEN** 可继续看到更新后的完整记录；节点离线及尚未知的执行状态可辨认。

### Requirement: Work 提供工作记录与原生轨迹两种查看方式

#### Scenario: 查看当前主执行或关联执行的原生轨迹
- **GIVEN** 全局 Agent 的 Work 已有主执行或关联执行
- **WHEN** 有该 Agent 空间权限的用户在 Work 内切换到原生轨迹并选择一次执行
- **THEN** 在原页面看到所选执行的原生轨迹及明确归属，可以检查已有记录的输入、输出、时间和已报告统计。
- **AND** 切回工作记录保留原有查看位置；切换执行不会混入迟到的其他执行内容。

#### Scenario: 保留官方轨迹检查能力
- **WHEN** 用户使用原生轨迹
- **THEN** 可以使用时长切换、轮次／调用折叠和搜索，以及输入／模型／工具时间概览与记录选择联动。
- **AND** 系统提示词、用户、上下文注入、助手（含仅工具调用）、工具／嵌套调用和压缩按原生事实显示；相应检查器保留原文／来源、当时的提示词与工具目录、参数／结果／Schema、请求选项／用量／计时。
- **AND** 历史缺失不借当前配置补造；桌面和窄屏均能检查完整内容。

#### Scenario: 尚无可查看执行
- **WHEN** 用户进入尚未产生执行的 Agent 原生轨迹
- **THEN** 显示无可查看执行，不因此新建或启动 Agent。

### Requirement: 原生轨迹是既有 Work 权限下的只读检查

#### Scenario: 非管理者查看共享工作
- **GIVEN** 查看者是该公司 Agent 的有效公司成员但不是其管理者
- **WHEN** 查看该全局 Agent 的原生轨迹
- **THEN** 可以查看其真实主／关联执行；不会取得发送指令、审批、取消或配置权限。
- **AND** 原聊天和受保护附件仍按原有成员访问规则处理，不因原生记录中存在附件副本而绕过。

#### Scenario: 当前查看者失去访问资格
- **WHEN** 查看者退出登录、切换账号或被停用
- **THEN** 已打开的轨迹停止更新并清除该账号的显示内容，后续轨迹和附件读取被拒绝。

#### Scenario: 检查执行读取的工作区图片
- **GIVEN** 原生执行使用读图工具成功读取了所属工作区内的图片，且该图片确实被所选执行引用
- **WHEN** 有效 Work 查看者在原生记录中预览该图片
- **THEN** 可以查看图片；这类工作区来源不要求不存在的原聊天成员关系。
- **AND** 仅存在路径文本或来源无法证明时，不返回图片字节。
