## 体验判断与修正

- 功能：进入、嵌套、返回、范围／历史切换、记录选择与明细入口的连续路径成立；顶层选择器是辅助入口。
- 视觉：沿用现有外壳与低饱和输入／模型／工具色彩；发起记录采用克制的左标记和用途标题，状态及 fork 次于用途；区间边界与继承记录有视觉区别。
- 交互：返回与来源始终邻接，当前范围不依赖详情面板；窄屏无需左右拖动寻找主要操作。走查发现时间线标签原本定位到页面左侧，已改为相对时间线定位后复核。
- 原型模拟缩放、选择和返回，用于判断交互状态；真实产品必须使用实际记录、区间和官方完整明细，不能用原型固定数据替代。
