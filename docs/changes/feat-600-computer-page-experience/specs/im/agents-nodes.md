# IM agents-nodes Specification (delta for feat-600)

## ADDED Requirements

### Requirement: 电脑管理 SHALL 以身份与实际可用性为首要信息并按需展开管理操作

#### Scenario: 日常浏览与按需管理
- **WHEN** 用户浏览电脑页并打开一台电脑详情。
- **THEN** 列表优先显示名称、可用性、现用版本及可执行动作，名称编辑和连接诊断按需进入。
- **AND** 普通离线不被原始错误码呈现为必须处理的更新故障，不可更新时不提供可执行的更新按钮。

#### Scenario: 编辑失败与实时状态变化
- **WHEN** 用户正在改名时状态变化或保存失败。
- **THEN** 未保存的名称输入保留；只有保存成功才改变列表中的名称，离线时明确说明无法保存的原因。

### Requirement: 电脑列表 SHALL 提供与当前服务一致的连接指引并区分空列表与读取失败

#### Scenario: 连接第一台或另一台电脑
- **WHEN** 用户从电脑页选择连接电脑。
- **THEN** 展示当前服务的安装与绑定指引，并可返回列表；未发布安装包时明确说明不可用，不提供无效命令。

#### Scenario: 读取失败
- **WHEN** 首次读取电脑失败或已有列表刷新失败。
- **THEN** 前者提供重试而非宣称没有电脑；后者保留已有列表并提示状态可能过时。
