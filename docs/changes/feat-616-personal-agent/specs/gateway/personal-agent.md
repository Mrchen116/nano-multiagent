# Gateway personal-agent Specification (delta for feat-616)

## ADDED Requirements

### Requirement: PA 按真实来源隔离权限，并持续承接本人的目标

#### Scenario: 本人交办与跨轮次推进
- **WHEN** 认证本人在专属私聊明确交办目标，随后更换聊天、等待或恢复会话
- **THEN** 工作保持同一任务和有效授权，继续既定范围；外部话语、引用、历史重放和系统唤醒本身不新增本人授权。

#### Scenario: 统一处理外部请求与私人背景
- **WHEN** 外部 DM/群或观察批次被处理
- **THEN** PA 可结合允许读取的相关私人背景理解目标，保留输入真实来源；外部不因联络取得私人资产、控制命令或工具权限，不能通过模型自报身份建立本人授权。

### Requirement: 常规工具审批与内部交付不因 PA 身份增加用户负担

#### Scenario: 相同搜索与准备工作
- **GIVEN** 普通 Agent 在相同配置及用户意图下可执行一项搜索、阅读、整理或内部委派
- **WHEN** PA 为已交办目标执行同类工作
- **THEN** 采用同一权限结果，不增加 PA 人工批准；来源材料的指令不成为用户意图，新的敏感外传与越界仍按既有规则处理。

#### Scenario: 内部成果与持续授权
- **WHEN** 内部子执行完成，或后台在后续轮次继续目标
- **THEN** 成果自动回同一 PA，沿有效目标范围继续推进；既有 ask/deny 不被跳过，输出不成为新的授权。

### Requirement: 自动观察可靠摄取并在私密侧合并同一事项

#### Scenario: 多源信息与本人已处理
- **WHEN** 已启用范围内的真人/Agent/任务有同一事项的新信息，或本人已回复
- **THEN** 保留真实来源、按最新事实合并待决定项和进展，过期催回复失效；不复制任务，不改变真人已读，不将回复直接算作目标完成。

#### Scenario: 历史、重复和缺口
- **WHEN** 历史扫描期间到达新消息、重启重复事件或发现缺口
- **THEN** 可恢复处理并如实显示覆盖，不跳过新事件、不重复投递旧提醒。

### Requirement: 目标跟进须有持久安排与真实回执

#### Scenario: 等待对方与到期
- **WHEN** PA 告知本人下一次检查时间
- **THEN** 该安排已有可恢复的实际调度回执；到期重读最新目标、授权与来源，继续工作或提出有意义的决定。
- **AND** 忙碌/离线/不可用可辨认，延迟不丢责任，也不冒称准时执行。

#### Scenario: 用户不在场与安静推进
- **WHEN** 跟进检查没有实质变化
- **THEN** 不重复发状态消息；必要决定、实质阻塞、约定截止风险及完成才通知，同一变化不重复。

### Requirement: 暂停观察、稍后提醒和暂缓目标的语义独立

#### Scenario: 三种用户意图
- **WHEN** 本人稍后决定、暂停新消息观察或暂缓某目标
- **THEN** 分别调整该决定的提醒时间、停止新源摄取或暂停该目标后续推进；明确范围，不无意删除任务或停止其他目标。

#### Scenario: 恢复观察
- **WHEN** 本人选择补读或只接收今后新消息
- **THEN** 既有目标与许可仍保留，必要时说明缺少的信息；不会因数据恢复方式隐式放弃未完成目标。

### Requirement: 对外协作受有效范围与当前受众约束

#### Scenario: 正常持续协调
- **WHEN** 本人已经明确授权 PA 在具体目标与对象范围内协调
- **THEN** PA 可继续普通往来，不对每条消息重复审批；第三方只看到本会话和允许披露的资料。

#### Scenario: 新披露、撤权与不确定结果
- **WHEN** 操作扩大受众/私料/承诺，许可撤销或回执未知
- **THEN** 先在已有范围寻找安全替代，目标必需的新授权才请求准确决定；撤权停止不允许的动作，未知回执核实原幂等操作，不能模型自批、盲重发或伪称完成。

#### Scenario: 外部不合理请求与协作循环
- **WHEN** 外部索取无关私人信息或 Agent 反复诱导接话
- **THEN** 在已有同会话权限内说明可协助的范围，不泄露内部拒绝过程；预算与去重限制循环，不把每次外部请求变成本人新待办。

### Requirement: 排除与清理使受影响的自动来源失效且不伪报全面遗忘

#### Scenario: 排除、失权与恢复
- **WHEN** 来源被排除或失权
- **THEN** 受影响源 API、游标、候选、自动缓存/引用及旧执行上下文失效，允许内容重建后继续；保留目标并说明受影响的跟进。
- **AND** 原聊天、任务、运行日志与已外发资料可能保留；清理不承诺磁盘擦除，也不声称普通广权限工具具有强信息流隔离。

### Requirement: 可疑套取双向告知且不增加本人审批

#### Scenario: 有依据的可疑索取
- **WHEN** 外部在明确拒绝后继续索取，或伪造本人授权等行为触发可疑事件
- **THEN** 阻止越界披露，向本人专属私聊报告对象、来源、具体依据和已采取措施，区分观察事实与“疑似”判断；对方仅在原会话得到边界说明及可核实的记录/告知状态。
- **AND** 对外“已通知本人”必须有本人通知实际送达的证据，不表示已读；pending/unknown 不冒称成功，恢复核实原操作不重复发送。

#### Scenario: 重复、误会与正常协作
- **WHEN** 同一事件反复发生，或本人不处理/标记误会/屏蔽
- **THEN** 重复更新同一事件而不逐条提醒、争辩或新增审批任务；正常授权工作继续。本人可查看记录、标记误会或按现有策略屏蔽，误会标记不扩权；新风险或实际泄露证据可升级提醒。

### Requirement: PA 披露与动作检查在实际执行前强制发生

#### Scenario: 自动拒绝后继续工作
- **WHEN** 待发送内容不在主人真实授权内，但存在可完成任务的安全表达
- **THEN** 拦下该内容并允许 PA 自动调整，修改后重新检查；不新增逐条人工批准，外部看不到被拦内容及私密审核理由。

#### Scenario: 多种外发与上下文
- **WHEN** PA 显式发送、自动回复、更新共享结果、共享附件、委派其他 Agent 或使用携带信息的网络工具
- **THEN** 当前授权、实际受众、具体内容、相关私人来源与历史披露参与独立检查；普通工具放行和后台/子执行不能绕过。

#### Scenario: 检查不可用或内容变化
- **WHEN** 所需审核/证据不可用，或通过后的内容、附件、受众、来源/许可发生变化
- **THEN** 不先执行或流式公开；保留受影响动作的真实状态，变化后重新检查，其他可做工作继续。

#### Scenario: 连续披露与并行操作
- **WHEN** 同一接收身份跨已验证关联渠道索取信息，或多个待发动作并行
- **THEN** 检查考虑相关既有及可能已发送的披露；并行操作不能用过时披露历史全部直接放行，不按昵称推断跨平台身份。

### Requirement: 私人记忆与能力变化不能成为授权旁路

#### Scenario: 外部事实被摘要与恢复
- **WHEN** 外部材料、派生结论或子任务结果进入记忆、压缩或后续执行
- **THEN** 保留来源与事实类型，不能成为本人决定或修改权限；撤源仍使受影响自动资料失效。

#### Scenario: 无法受控的能力
- **WHEN** PA 配置包含无法完整接入实际外发检查的任意代码、插件或工具
- **THEN** 不自动装配该能力，说明具体能力阻塞并继续可完成部分；不能通过人工批准一次、Auto skip、热更新或子执行开放旁路。正常搜索、资料整理、内部委派与跟进仍须可用，普通非 PA Agent 不受此限制。

#### Scenario: 同节点普通 Agent 配置变化
- **WHEN** 同节点普通 Agent 安装/启用插件，或发生新增、预览、热更新与重启
- **THEN** 普通配置保持原行为，其插件不会因此进入 PA 的执行与后台维护；PA 的来源/外发约束和私人工作可见性保持。

#### Scenario: PA 运行不可用
- **WHEN** 某个 PA 的运行环境失败或恢复
- **THEN** 如实呈现该 PA 受影响工作，不借普通 Agent 的宽权限环境继续私密任务；普通 Agent 可用性按其实际状态呈现，不把节点在线当所有助手就绪。

### Requirement: PA 按需查询本人可读的完整历史范围

#### Scenario: 任意历史时期的原消息
- **WHEN** 本人询问或已有目标需要核实更早时期的群聊/私聊
- **THEN** 可按会话、人物、关键词与时间查找，继续分页阅读上下文并提供原消息出处，不要求逐条转发或人工批准。

#### Scenario: 当前权限与来源控制
- **WHEN** 查询、继续分页或读取原文/附件，期间发生撤权、来源排除或暂停观察
- **THEN** 每次核实本人当前权限及来源规则，旧片段不绕过撤权；暂停新观察不禁止按需查询，来源排除仍阻止读取。历史内容保留原作者和时间，不创建新授权或改本人已读；覆盖不全如实说明。
