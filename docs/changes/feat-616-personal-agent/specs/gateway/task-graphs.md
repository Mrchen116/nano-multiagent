# gateway/task-graphs Specification (delta for feat-616)

## MODIFIED Requirements

### Requirement: 图操作使用真实会话与账号归属

以下普通任务路径与场景保持不变。个人助手另有窄化委托路径：可信 owner_private 或 observation 批次可按 owner 当前 read ACL（含空间资格）∩已启用观察范围∩本次目标/批次读取任务，无需逐任务批准；external 与普通 child 不取得这一投影。仅可信 owner_private 的写入路径可依据 owner 当前 write ACL、已启用任务能力和精确一次性 grant 补充结果或状态；不要求 PA 自己入群或改变其固定空间。PA 成员资格不能替代 owner 当前资格。所有写入仍记录 actor=PA、authorized_by=owner，并在同事务复核任务、来源、受众和策略版本；不授予 claim、改派、删除或创建公共任务权限。

资源空间资格是前提，任务访问由固定所属会话决定；私人 Agent 仅访问本人私人空间，公司 Agent 须保持 owner 的公司资格。账号归属核实真实主体，不替代会话权限。加入公司不发布私人会话或其任务。

#### Scenario: 真实身份与公司能力
- **WHEN** 有效成员交办已启用任务工具的真实注册 PA Agent 维护任务
- **THEN** 可跨 owner/Gateway 在所属会话范围内读取同一持久图，写入要求会话成员资格；不接受模型指定身份、未核实内核 child、停用 owner 或过期机器连接。
- **AND** 工具开关和 allowlist 继续同时生效；工具不按任务依赖调度执行；协作系统消息按原群策略处理。

#### Scenario: 外部渠道复用现有主人与 Agent 资格
- **WHEN** 飞书等外部渠道的 Agent 调用任务工具
- **THEN** 复用既有 ownerOpenId 及交办规则；IM 校验 Agent/Gateway 的有效身份、目标空间资格与任务能力，不要求外部发言人另行关联 IM 登录账号。
- **AND** 私人 Agent 不要求公司资格但只能读写自身私人任务；公司 Agent 的管理者未加入公司、待批准或停用时无权读写公司任务；ownerOpenId 不替代这些检查，也不自动转换成外部发言人的 IM user_id。
- **AND** 飞书私聊/群的正常沟通、背景与回复去向保持，无全群核验、关联页面或仅发链接限制。

#### Scenario: IM 不可达时任务调用如实失败
- **WHEN** 飞书 Agent 正常对话期间无法连接 IM 任务服务
- **THEN** 普通渠道继续既有本地自治；任务工具明确返回不可用或结果未知，不宣称任务已保存、不创建本地替代图。

#### Scenario: 来源与无来源操作
- **WHEN** Agent 创建或更新节点
- **THEN** 普通绑定会话采用真实聊天，全局会话只记录可核实来源；显式来源未映射时明确失败，不猜测聊天或创建本地影子图。
- **AND** 创建必须解析所属会话，无绑定来源时显式指定已有会话；编辑可不指定讨论来源，但仍需所属会话写入资格，不伪造用户；每次仅更新实际受影响节点的来源和群活动关联，重试保持原记录。

#### Scenario: 返回稳定入口
- **WHEN** Agent 返回任务图及更新结果
- **THEN** 图与节点短 ID 稳定，外部链接指向既有 IM 公开入口；打开后仍验证资源空间资格、所属会话及受保护来源。

#### Scenario: 个人助手代表本人有界协助
- **WHEN** 私人 PA 为本人公司或私人源任务申请写回
- **THEN** 仅批准的结果/状态 patch 可按 owner 当前资格写入，任务归属与负责人不变；owner 已退群或失去资格时，即使 PA 仍为成员也拒绝。
- **AND** 现有任务系统通知仍按原所属会话产生，确认前明确其受众；普通 Agent 不获得此委托能力。

### Requirement: Agent 可发现、创建与自行加入内置群

以下自行加入规则适用于真人及普通 Agent。personal-role PA 加入任何群（包括公开群、邀请加入和创建群）额外要求 owner 对具体群、当前可见范围与成员受众的明确确认；最终加入重验 owner/PA 当前公司与群资格、群及受众版本和一次性许可。外部邀请、观察事件、PA 自己的决定不能建立此许可；拒绝或过期不加入。

#### Scenario: 真实主体创建或加入
- **WHEN** 具有既有产品会话工具资格的真实 Agent 列出公开群、创建群或自行加入
- **THEN** 公司内公开群可读；新建群默认公开且可选私密；加入仅作用于 Agent 自己，私密群不允许自行加入。
- **AND** 此能力不授权模型指定其他 Agent 身份，不绕过内部 child 的既有工具限制，不把 Agent owner 身份转换为群管理员。

#### Scenario: PA 不自行加入公开群
- **WHEN** PA 发现公开群或收到邀请，尚无 owner 对该群的有效批准
- **THEN** 可在本人私聊提出加入建议，但不成为成员；批准只对该群有效，不扩大观察来源或私人资料放行范围。
