# im/conversations-messages Specification (delta for feat-616)

## MODIFIED Requirements

### Requirement: 群类型具有明确默认值、加入方式与切换资格

以下自行创建和加入规则适用于真人及普通 Agent。personal-role PA 不通过 Agent 工具自行创建或加入群；owner 可通过既有会话成员操作明确将自己的 PA 加入具体群，操作仍核对当前 owner/PA 的公司资格、会话权限和成员资格。外部邀请、观察事件或 PA 自己的决定不能替代 owner 的成员操作；加入群也不授予私人资料披露许可。

新建群默认公开，可选私密；旧群升级时默认私密。公开群允许公司内有资格的人和 Agent 自行加入，私密群需邀请。公开／私密双向切换仅限已加入该群的公司管理员。

#### Scenario: 创建和加入

- **WHEN** 人或 Agent 新建群，或希望参与已有公开群
- **THEN** 新建时默认公开且能选择私密；公开群可自行加入，无需逐次邀请审批，私密群不提供自行加入；人有界面入口，Agent 有工具入口。

#### Scenario: 从已有会话入口发现公开群

- **WHEN** 用户在聊天列表的“＋”菜单选择发现公开群
- **THEN** 搜索框与会话列表保持原有布局；弹窗沿用聊天界面的遮罩、标题栏、群头像及可点击列表行，按内容决定高度，长列表在弹窗内滚动，手机使用对应底部面板。
- **AND** 能关闭或按 Escape 返回原会话，选择群进入原有访客查看／加入流程，不因浏览而入群。

#### Scenario: 更改可见范围

- **WHEN** 已入群的公司管理员把群改为公开或私密
- **THEN** 群消息和所属任务一起采用新范围，已有成员与内容保留。
- **AND** 非管理员群创建者或普通成员不能仅凭创建／改名权限切换；未入群的公司管理员也不能直接切换。

#### Scenario: 外部影子会话保持原可见范围
- **WHEN** Gateway 同步外部 channel 并创建影子会话
- **THEN** 不因内置群默认公开而公开外部聊天；影子会话仍按成员范围访问。

#### Scenario: 公司内读取与成员写入分离
- **WHEN** 有效公司成员或真实 Agent 发现并浏览公开群
- **THEN** 可读取详情、消息与会话附件；默认聊天列表仍显示已加入会话，查看不自动加入。发言、上传与任务维护需加入未解散会话；私密群、私聊及解散历史采用各自权限。
- **AND** 改范围后，详情、消息、附件、任务、Agent 查询和待投递消息重试使用当前资格；不宣称撤回已被接收者读取的内容。

#### Scenario: PA 不自行加入公开群
- **WHEN** PA 发现公开群或收到邀请，owner 尚未通过成员操作将 PA 加入该群
- **THEN** 可在本人私聊提出加入建议，但不自行成为成员；owner 的后续成员操作只改变该群参与关系，不扩大观察来源或私人资料披露范围。
