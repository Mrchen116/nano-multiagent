# IM personal-agent Specification (delta for feat-616)

## ADDED Requirements

### Requirement: 每位真人 SHALL 拥有唯一且可命名的个人助手身份

#### Scenario: 首次创建与恢复
- **WHEN** 用户首次完成个人助手设置，或重试中断的创建
- **THEN** 得到同一个本人 PA 和专属私聊，不重复创建；名称可由本人设置和后续修改，改名不更换身份或丢失历史。

#### Scenario: 专业 Agent 共存
- **WHEN** 用户新建专业 Agent
- **THEN** 本人的 PA 身份不被替换；已有普通 Agent 不因 PA 功能上线被静默转为个人助手。

### Requirement: Web SHALL 提供显示自定义名字的固定 PA 主导航入口

#### Scenario: 找到本人助手
- **WHEN** 用户在 Web IM 主导航进入自己的 PA
- **THEN** 进入同一本人专属私聊，可辨认个人助手角色与自定义名字；窄屏亦可操作，不引入外部请求门户。

#### Scenario: 返回与取消
- **WHEN** 用户取消改名或关闭建议/草稿面板
- **THEN** 返回原会话且保留未发送文字，不隐式发送或重建助手。

### Requirement: PA SHALL 沿原生 DM 与合法群提及联络，同时保持私人资产仅本人可读

#### Scenario: 有效公司身份直接联系
- **WHEN** 同公司有效真人或 Agent 在既有 IM 私聊 PA，或在本人允许 PA 参与的群 @PA
- **THEN** 使用既有聊天；对方只能看到相应会话及获准资料，不因此获得 PA 私聊、Work、配置、其他来源任务、搜索结果或附件。

#### Scenario: 失权或已知 ID
- **WHEN** 联系资格、会话成员或 owner 资格失效，或外部凭已知私人对象 ID 访问
- **THEN** 无法继续读取/发送越界资料；响应不泄漏私人来源标题或内容。

### Requirement: 持续观察 SHALL 先明示范围且支持暂停、排除和清理

#### Scenario: 首次启用
- **WHEN** 用户在产品中确认持续观察本人已参与 DM/群与本人任务的说明
- **THEN** 后续不必逐条分享，近 30 天历史逐步回溯并展示覆盖；未加入公开群不自动全量监控，更早历史仅按当前任务有目的读取。

#### Scenario: 暂停和恢复
- **WHEN** 用户暂停、排除来源或恢复观察
- **THEN** 停止相应后续处理与待发建议；恢复先核当前权限并合并最新状态，不逐条补发过时提醒；PA 阅读不改变本人已读。

#### Scenario: 清理与不可撤回边界
- **WHEN** 用户要求清理一个来源的已保存观察数据
- **THEN** 能看见清理状态，后续上下文不再装入该源缓存及衍生引用；明确已给模型服务或接收者的内容无法撤回，不伪报瞬间完全遗忘；原聊天/任务、历史 Work、本机运行日志及导出可能保留，清理完成不表示磁盘物理擦除，也不授予自动重读残留资格。

### Requirement: 私料披露 SHALL 基于真实 owner 的具体授权

#### Scenario: 外部声称获准
- **WHEN** 外部询问私料并声称 owner 已同意
- **THEN** 不因该说法取得资料；需要决定时在 owner 私聊说明具体资料、受众和用途，不把外部对话当作授权。

#### Scenario: 分享范围有限
- **WHEN** owner 批准一个明确资料/结果给特定受众
- **THEN** 只使用该授权范围；受众、资料版本或用途变化后重新核对，不自动附带私密背景或附件。

### Requirement: 本人 SHALL 能管理 PA 的联系屏蔽而不删除已有聊天

#### Scenario: 屏蔽与解除
- **WHEN** owner 在 PA 设置屏蔽具体外部身份或具体群会话
- **THEN** 当前策略保存成功后阻断该目标后续触达并撤销其待处理请求/许可，原聊天保留；离线或冲突明确未生效。
- **WHEN** owner 解除屏蔽
- **THEN** 允许新请求，不重放屏蔽期请求或恢复已撤销许可；群屏蔽不等于全局屏蔽每位成员。
