# IM web-chat-ux Specification (delta for feat-617)

## ADDED Requirements

### Requirement: 交互内容保持聊天阅读与操作连贯

Web IM SHALL 在对应 Agent 回复中呈现交互；文字说明、选择与操作含义可辨认。用户可调整控件，也可通过普通文字继续。

#### Scenario: 调整后继续
- **WHEN** 用户调整字段并点击继续，或带当前选择发送文字
- **THEN** 立即反馈本地变化；提交后显示本人选择摘要与已提交状态，业务完成由实际结果另行说明。

#### Scenario: 手机与桌面
- **WHEN** 用户在桌面或手机阅读和操作交互回复
- **THEN** 字段、主要动作和聊天输入可读可用，不因卡片宽度或内层滚动妨碍主对话。

#### Scenario: 生成与渲染失败
- **WHEN** 回复正在生成或交互无法渲染
- **THEN** 用户能识别运行状态，已可读内容不无故消失，失败时仍能阅读摘要并继续打字。

#### Scenario: 私人草稿与跨设备修改
- **WHEN** 用户重新打开未提交卡片，或两台设备同时修改
- **THEN** 恢复本人已保存草稿；冲突明确提示且保留当前编辑，不静默覆盖另一设备内容。
