# Gateway global-agent Specification (delta for feat-630)

## ADDED Requirements

### Requirement: 全局输入的持久接收与工作记录上传独立

#### Scenario: 旧记录未同步仍接收新交办
- **GIVEN** 工作记录补传失败或积压，节点仍能持久接收消息
- **WHEN** 用户向全局 Agent 或 PA 发送符合原触发规则的交办
- **THEN** 输入持久保留并可唤醒处理，不等待旧记录完成中心同步。

#### Scenario: 执行运行时暂不可用
- **WHEN** 节点已持久接收输入而执行进程暂不可用，随后执行进程恢复
- **THEN** 自动继续原输入，回执暂不可达不阻止待办恢复；重复投递和重启不重复执行已接受的相同输入。

### Requirement: 查询回复与必要控制不受无关轨迹积压阻塞

#### Scenario: 查询聊天并向原目标回复
- **GIVEN** 目标访问与必要权威事实可用，历史工作记录同步失败
- **WHEN** Agent 查询聊天并准备发送回复
- **THEN** 不等待无关历史同步，仍按原权限、来源证据与新消息复核处理；旧草稿被要求重读时不会自动发布。

#### Scenario: 停止与权限决定
- **WHEN** 用户按现有规则停止 Agent 或响应权限请求，且实时通路可用
- **THEN** 控制作用于真实执行，不等待历史过程全部上传，不因重试绕过撤销或审批边界。
