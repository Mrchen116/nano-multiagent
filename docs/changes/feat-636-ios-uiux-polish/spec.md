## 用户场景

用户在手机上创建可用助手、维护自己的模型服务；阅读长中文消息和工作结果；一屏比较任务进度并进入子任务；在 Web 与 iOS 都能快速找到自己的 PA 配置。流程优先呈现用户需要理解和操作的信息，把诊断与高级设置留到需要时。

## 验收标准

### Requirement: 创建助手从目的出发，模型配置有常驻入口
#### Scenario: 创建与高级设置
- **WHEN** 用户新建助手
- **THEN** 首先看到名称、用途与说明，再选择设备及模型；默认生成标识和工作目录，高级设置可展开编辑；创建成功可进入真实聊天，未确认创建不冒充成功。
#### Scenario: 管理模型服务
- **WHEN** 用户从“我的”或本人设备进入模型服务
- **THEN** 可查看、新增、编辑服务及多个模型，连接验证成功后才保存；已有密钥不回显，空输入保留凭据。
#### Scenario: 修改未完成
- **WHEN** 测试失败、取消、离线或版本冲突
- **THEN** 保留草稿和原配置，显示恢复动作；移除仍被使用的服务时显示受影响助手及修改入口。

### Requirement: 完整阅读消息和工作结果
#### Scenario: 大字号普通 Markdown
- **WHEN** 用户以默认及辅助大字号阅读长中文段落、列表
- **THEN** 正文完整换行，不出现无法展开的单行省略；原有复制和表格横向浏览保持。
#### Scenario: 工作轨迹阅读
- **WHEN** 用户进入 Work 并展开轮次、工具结果
- **THEN** 先看到实际运行状态和轮次摘要，再查看可换行的结果，技术详情按需展开；展开不改变父页标题，不能把工具完成当作对外已发送。

### Requirement: 配置与表单清晰表达当前状态
#### Scenario: 群回复策略
- **WHEN** 用户读取已保存的群回复策略并保存无关修改
- **THEN** 当前策略有可理解的可见值，保持真实语义，不因显示修正悄悄改变策略。
#### Scenario: 表单与文案
- **WHEN** 用户编辑资料、设备、系统策略或查看帮助
- **THEN** 字段填写后仍有标签，每页一个主要保存入口；草稿可放弃且成功失败反馈可见；中文日常路径不暴露不必要实现措辞，任务详情的关闭动作不与完成任务混淆。

### Requirement: 默认字号下能比较任务并理解结构
#### Scenario: 任务总览与定位
- **WHEN** 用户浏览默认字号任务列表
- **THEN** 紧凑卡片保留标题、负责人、状态与子任务线索，提供各状态计数及定位；分页计数不冒充全量，原有权限和分组含义不变。
#### Scenario: 子任务与结构
- **WHEN** 用户查看子任务或并行结构
- **THEN** 能读清进度并从结构总览定位节点，再进入详情；长标题和大字号不被固定高度裁切。

### Requirement: 双端突出当前用户 PA 的配置入口
#### Scenario: Web 与原生查找 PA
- **GIVEN** 用户已有自己的 PA
- **WHEN** 用户进入 Web 或 iOS Agent 页
- **THEN** 顶部有明确“我的个人助手”区并能直接进入现有配置；搜索仍有效，其他人的 PA 不获得本人入口或管理权限。
#### Scenario: 无 PA 与读取失败
- **WHEN** 用户尚无 PA，或 PA 信息暂时无法读取
- **THEN** 普通 Agent 列表仍可用；读取失败能重试，不把失败当作未创建，也不跳入别人的配置。

### Requirement: 以真实画面对照交付
#### Scenario: 用户确认前
- **WHEN** 本轮修改完成
- **THEN** 提供每个优化点对应的修改前后真实截图和验证结果，标明字号、平台、内容及不能直接比较的条件；等用户确认效果后才提 PR。

## 范围与非目标

在范围：报告 U1–U6 和五项细节；iOS 原生界面、模型服务现有 API 接入、Web PA 入口；适用窄测试、真实隔离服务、模拟器和浏览器验证。

非目标：不改 DSH 运行时、PA 权限、消息发送/审批业务策略；不做全产品视觉重做；不部署生产、不安装用户手机、不提前创建 PR。无需真实 LLM 任务或生产凭据，模型连通验收使用隔离测试端点。

## 用户追加：移动端消息身份与时间

> 提个意见，任何成熟IM都不会移动端在消息框内写名字和时间吧

### Requirement: 消息内容与会话元信息分层
#### Scenario: 单聊与群聊
- **WHEN** 用户阅读原生手机的单聊、群聊
- **THEN** 单聊不在每个气泡重复对方名称，群聊的对方名称位于气泡上方；首次、相邻消息间隔5分钟或跨日时，时间作为独立分隔；正常完成消息不重复显示“已完成/已发送”，进行中和失败状态保持可见。消息正文、交互卡片、过程、权限及发送恢复不改变。
