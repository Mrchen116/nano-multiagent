# gateway/personal-agent 增量

## ADDED Requirements

### Requirement: PA 个人记忆可检索、可纠正且不提供授权
#### Scenario: 使用与纠正
- **WHEN** PA 保存并随后使用个人偏好或决定
- **THEN** 保留真实主体、适用情境和来源，相关问题可按需检索，明确纠正在下一安全模型边界生效；第三方说法不冒充主人自述。
#### Scenario: 遗忘
- **WHEN** 主人要求忘记明确记录
- **THEN** 删除受控正文及派生召回，阻止旧来源复活，重建或停止使用受影响活跃上下文；返回各层实际完成/未完成范围，不承诺删除原始聊天、审计或备份。若同一请求还有未完成工作，续接只保留经验证不含被忘正文的最小工作摘要与原主人会话；不能安全续接时明确未完成，不把旧值带入新上下文。

### Requirement: 私人关注不改变执行授权或任务责任
#### Scenario: 发现与准备
- **WHEN** 获准消息形成承诺、机会或冲突线索
- **THEN** 可核对和私人准备，关注与已有委托分开；新外发仍依据真实授权。
#### Scenario: 查阅与反馈
- **WHEN** 用户查询、更正、稍后或忽略私人关注
- **THEN** 返回有来源的当前状态，反馈有版本及重试保护，主题抑制不混同单条忽略。
#### Scenario: 新鲜度与静默
- **WHEN** 主动结果准备发送
- **THEN** 核对最新来源和原事项，已处理/无变化/策略不允许时保持静默；真实发送回执才算通知完成，不抑制用户明确要求的定时提醒。

### Requirement: 私人组合查询不消费主 Inbox
#### Scenario: 有限读取
- **WHEN** PA 查询相关记忆、消息和当前事项
- **THEN** 保留来源、覆盖范围和未读分页，失败不视为空结果，查询不改变主 Inbox 消费位置、不提升 child 身份；来源撤销后新读取拒绝。

### Requirement: 生成产物通过持久媒体交付
#### Scenario: 私人发布与外发
- **WHEN** PA 发布生成文件
- **THEN** 只有真实字节已进入主人可访问的持久资源后才报告成功，重试不重复创建；指定版本外发继续检查受众与完整载荷并复制为该受众可访问的副本。
