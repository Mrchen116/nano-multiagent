# Gateway Global Agent Specification (delta for feat-680)

## ADDED Requirements

### Requirement: Agent 可搜索并回查允许访问的聊天历史

主 Agent 能在当前可访问的 IM 已同步消息历史中，按精确文本或多个字面线索搜索，并组合聊天、发送人和时间范围；可按相关性或最新时间排序，未指定时间不默认排除旧历史。结果保留实际发送者、来源、时间和可继续读取的定位，权限与 Inbox 消费语义沿用现有规则。

#### Scenario: 多线索和准确文本
- **WHEN** Agent 根据用户的中文关键词或准确编号回溯历史
- **THEN** 它可以查到含多个分散线索的消息，也可以按完整准确文本查找；结果按相关性优先展示，较新弱匹配不会仅凭时间压过较早的明确匹配

#### Scenario: 最近和筛选
- **WHEN** Agent 按聊天、发送人和时间组合条件搜索并选择最新优先
- **THEN** 返回符合全部条件的消息，较新结果在前；不指定时间时较旧匹配仍可查到

#### Scenario: 来源和前后文
- **WHEN** Agent 找到相关消息并按结果定位回查
- **THEN** 它能辨认真正的发送者和来源、取得原消息及同一聊天的前后文，并保留个人助手的可读来源和主人可读性事实

#### Scenario: 分页与当前权限
- **WHEN** 结果需要继续读取，或结果来源的权限在续页前被撤销
- **THEN** Agent 可继续查看允许访问的快照结果；不可再访问的内容不再返回，权限变化不使其他仍可访问结果被误认为已查完

#### Scenario: 完整与分段消息
- **WHEN** 搜索或回查返回完整消息，或因结果预算只返回消息的一部分
- **THEN** 完整内容无需重复的完整状态标记；部分内容能被辨认，并能判断是否需要继续读取以及前面是否还有未获得的部分
- **AND** 同一页收到的同一消息正文和附件描述保持顺序，完整取得附件描述不等同已读取附件内容

#### Scenario: 结果为空或历史不可用
- **WHEN** 已同步 IM 范围内没有匹配，或查询/所需来源不可用
- **THEN** Agent 能区分空结果与未查全或查询失败；已同步范围不被表述为外部平台全部历史
