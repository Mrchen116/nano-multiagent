# IM Personal Agent Specification (delta for feat-703)

## ADDED Requirements

### Requirement: PA 创建使用原主人来源与既有节点创建边界

#### Scenario: 创建可在现有产品中使用
- **WHEN** 可信主 PA 根据主人向它提出的原始创建要求完成创建
- **THEN** 新 Agent 出现在本人的现有列表，可长期聊天并经现有配置页维护；创建仍遵守本人绑定节点、在线校验及实际工作区和能力校验。
- **AND** 观察内容、他人消息或 PA 自己代发的消息不能成为新的主人创建依据。

#### Scenario: 同次请求恢复与冲突
- **WHEN** 同一次创建遇到断线、重启或结果尚未确认
- **THEN** 按同一请求确认原操作，不重复创建，未确认时不宣称成功。
- **AND** 请求标识被用于不同目标或配置时拒绝混用；离线、权限、ID/路径或配置冲突均明确说明，不静默换机。
