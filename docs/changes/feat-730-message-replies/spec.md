## 本轮范围与状态

用户已确认引用回复方向：菜单回复、可取消的输入区摘要、发送后的引用卡片、点击定位、单聊/群聊及文字/图片/文件支持，并让 Agent 理解所引用的消息。

本轮按明确授权的快速开发模式实施 Web 与服务端链路，浏览器实际试用后交用户验收；原生 iOS 必须等待用户认可 Web 后再开始。正式 as-built 文档、独立代码审查及交付在用户验收后按 change-fast-close 完成。未执行发布或生产部署。

群聊回复 Agent 视为明确向该 Agent 发言；回复真人保持既有群聊路由。保留现有草稿、附件、失败重试、文本选择和分支体验。

补充原话：

> 顺便改掉这6个字，直接改成复制。哪有正常的商业IM会用6个字表达复制一条消息？

本轮统一缩短 Web 消息复制动作名称为“复制”（英文 Copy）。
