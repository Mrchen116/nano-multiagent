# Gateway 路由与交付（feat-762）

## ADDED Requirements

### Requirement: 群聊 Agent 理解本地文件所在的执行环境

产品 root Agent 获得自身执行节点身份与多机文件访问规则。普通与 Global 模式通过已启用的聊天详情查询获取原生群聊可见同伴的当前节点关系。

#### Scenario: 复核另一 Agent 的本地文件

- **WHEN** 用户要求在原生群聊中复核另一 Agent 给出的本地路径
- **THEN** Agent 根据当前可见的节点关系和文件来源判断能否使用该路径。本机路径按实际权限和读取结果处理。不同节点、文件来源未知或读取失败时，请求有权读取的会话附件或可访问链接。
- **AND** 获得有权读取的副本后，基于其实际内容复核。
