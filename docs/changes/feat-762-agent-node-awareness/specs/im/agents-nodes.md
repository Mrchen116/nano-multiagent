# IM Agent 和节点（feat-762）

## ADDED Requirements

### Requirement: Agent 可辨认原生群聊同伴的执行节点身份

节点信息受现有会话与设备信息的可见范围约束。Agent 查询自己已加入的原生群聊时，可获取可见同伴的节点 ID 和允许查看的设备显示名。显示名可重名，节点 ID 可用于比较。

#### Scenario: 无法确认节点归属

- **WHEN** 群成员的执行节点未知或当前 Agent 无权查看
- **THEN** 该成员不返回节点身份。

#### Scenario: 归属已知但设备离线

- **WHEN** 当前 Agent 查询有权限查看的群成员，而该成员的已知节点离线
- **THEN** 仍能获取已知节点 ID，设备显示名在存在且允许查看时一并返回。
