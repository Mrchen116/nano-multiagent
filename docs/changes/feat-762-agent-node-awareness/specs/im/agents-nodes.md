# IM Agent 和节点（feat-762）

## ADDED Requirements

### Requirement: Agent 可辨认原生群聊同伴的执行节点关系

节点信息受现有会话与设备信息的可见范围约束。Agent 查询自己已加入的原生群聊时，可辨认可见同伴运行在同一节点或其他节点，并可获得允许查看的设备显示名。

#### Scenario: 无法确认节点归属

- **WHEN** 群成员的执行节点未知或当前 Agent 无权查看
- **THEN** 该成员的节点关系表达为未知。

#### Scenario: 归属已知但设备离线

- **WHEN** 当前 Agent 查询有权限查看的群成员，而该成员的已知节点离线
- **THEN** 仍能获取已知节点关系，设备显示名在存在且允许查看时一并返回。
