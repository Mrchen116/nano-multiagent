# feat-764: Web Agent 工作记录与头像状态卡

> 对齐: [spec.md](spec.md)

## Changelog

## 现状分析

- Web 聊天用 `message-pane.tsx` 的会话头和消息头像。现有 `View Work` 通过 Agent ID 和实际发信消息 ID 跳转。Work 由 `agent-work-panel.tsx` 组装，已有主、子执行分页和原生轨迹路由。工具详情已有 `WorkTool`、`ToolDetailBody`、`NativeToolDetail` 和 `ConversationToolCard`。
- 中心 `work.ts` 统一校验登录、空间、个人归属和删除状态；`work-records.ts` 有主执行查询、精确回复锚点、关联执行元数据、轮次状态和 usage。节点在线与 Work 同步可信度是不同信号。Work 现有 API 不能从一页目录推断全树活跃子执行数。
- Dreaming 的宿主回执从 DSH `knowledge.facts` 经 PA `KnowledgeUpdates` 投影至独立维护会话，原生轨迹已有真实身份。当前该投影没有报告工具次数、模型和用量。原生查看器、权限、导出、轨迹数据格式沿用现有实现。
- [perf-749](../archive/perf-749-direct-work-focus/design.md) 用持久发信关系直达旧轮次，不遍历中间历史。[perf-751](../archive/perf-751-incremental-global-descendants/design.md) 将 Gateway 子树发现和恢复改为增量。[perf-753](../archive/perf-753-bounded-work-reads/M1-work-reads/evidence/implementation.md) 将目录和正文从首屏摘要中拆出。在 15,000 轮、最新一轮约 15,000 个工具项、10 万关联执行的隔离样本里，中心头页从约 21.16 MB 降到 5,492 B，HTTP 中位数从约 2.11 s 降到 13.87 ms。该数字是历史实验，候选和本次基线另行重测。[perf-754](../perf-754-bounded-work-transfer/design.md) 正在设计独立大明细传输，本 unit 保留其兼容边界，既有投影和原文读入口继续负责大小限制与授权。

## 关键决策

1. **共用一个记录阅读区。** 主、历史主、子执行共用既有 Turn/WorkTool 与按需查询。选中执行替换阅读区，父级导航保存执行、实际来源行、滚动及展开状态。聊天锚点、派工节点和关联入口复用现有精确身份；普通页与锚点的缓存保持独立。派工图范围与选中节点不随返回丢失。原生轨迹继续走现有 `work_view=trajectory&execution=...` 入口。
2. **连续阅读使用有界正文。** 头页继续走 `view=summary&catalog=separate`。记录按日期和轮次连续排版，首屏及读到视区的轮次自动展示首批过程，最多两个并发，使用现有每页 20 项的正文入口；页面以下未到达的轮次只保留轻摘要。长结果和后续过程显式按需加载，保留旧回复直达、缺口、控制/授权和独立的原文入口。实时刷新复用头部和 `after_revision` 增量，不重读已加载历史；离开页面停止新读取。以稳定 key 和锚点补偿到达正文后的高度变化。
3. **中心聚合派工与头像状态。** 复用持久的 session 父链和轮次投影。用已确认的身份边，不凭标题、时间或聊天室归属拼派工。图按会话展示，同会话重复唤醒归在一个节点；保留所选窗口内的活动会话和其必要祖先。主节点含该 Agent 的主执行用量，各子节点只合计自身。图的时间范围用明确的截至时间和最近 3 天／2 小时；轮次开始或结束在窗口内即可作为活动，token 取窗口内结束的轮次已报告的 `total_tokens`，标明报告覆盖率。祖先只为路径完整时不被视作窗口内执行。运行中缺失数值继续显示未报告。后台维护和其他关联目录沿用既有可达性，普通派工的活跃数不混入 Dreaming。
4. **头像只查询一份小状态。** 私聊头和消息头像、群聊 Agent 消息头像共用锚定浮窗。点击时才请求，权限沿用 Work；可编辑配置由现有服务端权限决定。只读返回主 Agent 状态、执行中本轮最后一次工具及其实际开始/结束状态、全量已确认活跃子 Agent 的去重计数、前一页简要名单。等待授权单列；同一个真实子 Agent 多轮只算一个，缺少 Agent 标识时使用确切会话身份。名单展开分页；正在补齐显示同步指示，离线或仍有未确认的活动态时不报实时数。复用 `agent.work.updated` 对可见浮窗的 revision 更新合并，关闭后停止读取。完整 Work 和配置复用现有路由，聊天不换页直至用户明确导航。
5. **工具详情复用已有语义视图。** 折叠行用真实名称、现有描述、状态及耗时，展开按调用、结果、来源组织。保留终端、文件、差异、inbox 等专用渲染；结构化通用字段按键值呈现，嵌套值折叠，原始文本保持原样。按确切 call ID 关联相邻回执和原消息，时间及回执状态可见。相同的请求／实发正文只展示一次；不同值分别标记。委派启动与结束保持不同事实。原始参数和结果沿用原生轨迹，未授权或未镜像的原文不因新组件扩大可见范围。
6. **Dreaming 指向独立维护会话。** 主时间线用同一时间排序插入轻量维护条目，显示真实阶段、状态、工具次数、模型与 token。DSH 集成在维护结束时从已打开会话的自有事件投影统计并持久化到 run；复用既有 token 口径，仅在完整边界确认时报告零次／未发起模型请求。通过 `knowledge.facts` 附统计，在 PA 追加版本化的结束投影事件，保留同 session/run ID、原宿主回执与旧投递事实。历史缺统计时按已授权用户点开的对应维护执行在 DSH 只读、有界请求具体会话的指标，结果可缓存到 run；缺日志或未确认时保留未报告。禁止在日常 Work 首屏、节点启动或每次知识通知遍历历史原生会话补算。现有原生查看器内部不改。

## 接口与数据流

- Work 主/子摘要、详细过程、控制记录和 exact focus 继续用现有路由。增加独立维护轻摘要游标，当前主记录与维护子会话分别有界取页，前端按已持久的时间与稳定身份合并；独立更新头页与游标，当前主执行更换及旧锚点保留已有语义。其他关联执行目录继续独立分页。
- 中心新增 `GET .../work/activity`（头像状态和分页名单）与 `GET .../work/delegation`（窗口、分页图节点与必要祖先、独立用量）。两者只读现有中心投影，复用 `readable()` / Agent 删除拒绝，按当前 viewer 资格检查 Work。返回 scope/revision/同步信号，响应只含需要的身份、展示名、时间、状态、轻量工具标题和聚合数。按已授权根过滤后再取边与聚合，排除被删除或无资格的记录；缓存沿用账号和 Agent 的隔离范围。头像配置资格不从 Work 可读或可发消息推导。
- 头像聚合使用最新轮次中的活动投影及只覆盖运行中、等待授权、未知态的索引，按已授权根和真实身份归并；可用同一 SQLite 快照分别算计数与名单。派工范围通过按根、事件类型及时间的覆盖索引取得轮次开始/结束候选，再使用有界列的 turn 摘要和精确会话/父边索引；不读原始工具事件 payload，历史之外仅查活动集合及祖先。新图读取按节点分页，前端只画首批 24 个活动会话及已选路径，展开才读后续节点，完整聚合由中心按窗口查询，不用页面节点凑总量。最新工具走当前主轮次的工具序号索引，不跨轮或遍历历史。
- 相关投影新字段向后兼容，既有 iOS 及旧节点仍使用原 Work 路径。删除/撤权用原检查，新增索引在正常 schema 初始化注册；验收记录大历史启动/索引安装代价。无一次性历史重写或生产数据迁移。对模型可见信息无变化，读取或修正投影不进入 prompt。

## 前端原型

复用此对话已经对齐的两份可交互原型。工作时间线、真实工具与派工返回基于已保存 Work；头像卡使用拟议响应示例。两份原型的本机路径分别为 `/Users/czj/.codex/visualizations/2026/11/12/01a1cded-705e-7592-a00d-2d838fe7b587/work-delegation.html` 和同目录的 `chat-agent-progress.html`。Work 含私有轨迹，仓库只保存行为设计，不提交原型快照或用户记录。

| 区域 | 基线与取舍 | 产品入口与必验 | 退出投影 |
| --- | --- | --- | --- |
| Work 时间线和返回 | 既有页面主／子两条长内容共滚动；统一一个阅读区域，工具仍可展开 | Agent Work、旧回复 View Work、两层委派；桌面及窄 Web，连续历史与锚点缺口 | must-match R1 |
| 派工图与工具详情 | 既有关联入口和原生轨迹留在对应来源；图只负责关系和用量 | 3 天／2 小时、主子分别统计、Dreaming 独立轨迹、代表工具及回退 | must-match R2 |
| 头像状态 | 既有私聊／群聊头像作为锚点；卡内配置图标与单一 Work 主操作 | 私聊与群聊、桌面及窄 Web、运行／等待／同步、关闭回焦点、权限 | must-match R3 |

对话中已用 Chromium 检查 320px 溢出、逐级返回、展开状态、真实 Dreaming 会话 URL、工具详情和头像开合，已目视检查桌面 Work 时间线和图。真实连接状态、中心授权、完整分页和大量历史的浏览器表现仍需实现后验收。
