# gateway agent-capabilities Specification (delta for feat-770)

## ADDED Requirements

### Requirement: 普通执行 Agent 可选择程序化工具调用且不扩大职责

#### Scenario: 指定普通执行者参加试用
- **WHEN** 节点所有者为指定 Agent 显式启用普通执行 PTC
- **THEN** 具备通用代码执行能力的普通执行者可以组合工具完成任务并返回必要依据；未选择者、受限执行者、Global/PA 主会话、Dreaming 和审核器保持既有工作方式。
- **AND** 普通 worker 仍将任务结果交给原负责人，不能取得主会话的聊天或对外投递权限。

### Requirement: 程序化工具调用保留原权限与执行事实

#### Scenario: 程序及实际动作受到权限约束
- **WHEN** 执行者通过程序请求代码执行或工具操作
- **THEN** 实际效果仍受当前自动审核、人工批准、无人值守与显式跳过设置约束；程序包装不构成免审授权。
- **AND** 拒绝、取消和部分执行保持真实状态，不自动重放整段程序。

#### Scenario: 回查被程序缩减的中间结果
- **WHEN** 执行者继续任务、回应用户对原始依据的追问，或 Dreaming 整理执行经验
- **THEN** 可在各自获准的执行历史范围内恢复宿主记录的调用、参数和结果，保留真实来源和错误状态；程序汇总不替代原始证据；已存在的子调用回执不因外层程序未输出而丢失。
- **AND** 原始执行轨迹与实时聊天补查遵循各自当前契约，缺失或超范围不伪报为已完成。

### Requirement: 退出程序化执行保留原工作成果

#### Scenario: 关闭指定 Agent 的试用
- **WHEN** 所有者关闭试用
- **THEN** 当前执行在安全结束后恢复既有调用方式，保留会话、产物与原始记录，不改变其他 Agent 的设置或自动扩大试用。
