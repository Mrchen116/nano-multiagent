# gateway agent-capabilities Specification (delta for feat-770)

## ADDED Requirements

### Requirement: 普通执行 Agent 默认程序化工具调用且不扩大职责

#### Scenario: 未显式回退的普通执行者
- **WHEN** 节点所有者未在配置文件中为该 Agent 显式回退 native
- **THEN** 具备通用代码执行能力的普通执行者默认用 PTC 组合工具完成任务并返回必要依据；受限执行者、Global/PA 主会话、Dreaming 提炼和审核器保持既有工作方式。不要求逐 Agent 开启，不增加 IM 网页选项。
- **AND** 普通 worker 仍将任务结果交给原负责人，不能取得主会话的聊天或对外投递权限。

### Requirement: 程序化工具调用保留原权限与执行事实

#### Scenario: 程序及实际动作受到权限约束
- **WHEN** 执行者通过程序请求代码执行或工具操作
- **THEN** 实际效果仍受当前自动审核、人工批准、无人值守与显式跳过设置约束；程序包装不构成免审授权。
- **AND** 拒绝、取消和部分执行保持真实状态，不自动重放整段程序。

#### Scenario: 回查被程序缩减的中间结果
- **WHEN** 执行者继续任务、回应用户对原始依据的追问，或 Dreaming 整理执行经验
- **THEN** 可在各自获准的执行历史范围内恢复宿主记录的调用、参数和结果，保留真实来源和错误状态；程序汇总不替代原始证据；已存在的子调用回执不因外层程序未输出而丢失。
- **AND** 原始执行轨迹与实时聊天补查遵循各自当前契约，缺失或超范围不伪报为已完成。

### Requirement: 配置回退保留原工作成果

#### Scenario: 从配置文件回退 native
- **WHEN** 所有者在配置文件为该 owner 显式设置 native 回退
- **THEN** 普通执行在安全边界恢复 native，后续 Dreaming 整合批次使用 native，当前批次按既有完成/取消规则结束。保留会话、产物与原始记录，不改变其他 owner 的设置；未设置回退仍默认 PTC。

### Requirement: Dreaming 整合默认程序化调用且提炼保持原模式

#### Scenario: 默认整理正式记忆
- **WHEN** Dreaming 开始新的整合批次且配置文件未显式回退 native
- **THEN** 整合以 PTC 编排已有来源回查、文件及 Bash 工具，保持正式仓写入范围、来源资格、单写者、前台执行、宿主 Git 核验与原有失败恢复规则。
- **AND** 提炼仍以既有模式读取宿主提供的材料并返回原有摘要结构；不增加提炼工具、轨迹分析系统或持久 REPL。

#### Scenario: 整合中的失败与来源回查
- **WHEN** 整合程序部分执行后失败，或需要恢复被省略的结果
- **THEN** 在维护自身记录与获准业务来源各自范围内恢复已记录依据，保留真实完成/失败/未知状态，不因外层输出缺失重放整段程序；只有原有宿主完成条件全部满足才推进来源进度。
