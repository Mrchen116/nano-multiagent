## ADDED Requirements

### Requirement: 私聊名称按实际查看者投影

未手动改名的站内私聊 SHALL 在参与者视角显示对方的当前公开名称，在观察者视角显示双方名称，以「 ↔ 」连接。群名、用户手动修改的标题和外部渠道提供的会话名保持原值。名称只用于展示，不改写存储标题、会话 ID、成员、权限或路由。

#### Scenario: 用户与 PA 或普通 Agent 查看同一私聊
- **WHEN** 用户、PA 或普通 Agent 查询同一个私聊
- **THEN** 用户看到对方 Agent 名，Agent 看到对方用户名；Agent 与 Agent 私聊同样显示对方名字。
- **AND** 会话列表、详情、同步、搜索、Agent 的 list/describe/info/read/search 及 Inbox 使用同一命名规则，自定义标题下仍保留结构化参与者与发送者身份。

#### Scenario: PA 通过主人权限观察其他私聊
- **WHEN** PA 读取主人可访问、但 PA 自身不是参与者的私聊
- **THEN** 名称列出实际双方，不把主人的查看视角当作 PA 的视角；PA 自己参与的私聊仍显示对方名称。读取资格与原有观察关系不变。
- **AND** 已缓存的 Inbox 来源名在下一次来源查询或读取时刷新；已交付历史上下文不追溯重写。
