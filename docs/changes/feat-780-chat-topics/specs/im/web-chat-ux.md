# im/web-chat-ux Specification (delta for feat-780)

## ADDED Requirements

### Requirement: Web 能把话题与主时间线引用分开

#### Scenario: 桌面同时看见话题
- **GIVEN** 一条主时间线消息已有话题
- **WHEN** 用户在约 1100 像素宽的浏览器里打开它
- **THEN** 主时间线仍留在原处，话题在聊天内的另一列按时间展开
- **AND** 新的话题回复不插入主时间线

#### Scenario: 窄屏推入话题
- **WHEN** 用户在约 390 像素宽的浏览器里打开话题并返回
- **THEN** 话题占据当前聊天层，返回后回到原来的主时间线位置
- **AND** 两个动作仍能分清：现有「回复」留在主时间线，「在话题中回复」进入话题

#### Scenario: 话题内引用和失败
- **WHEN** 用户在话题里引用其中一条并发送，或发送失败
- **THEN** 成功时引用卡片和正文都留在该话题，点击引用能回到话题里的那一条
- **AND** 失败时不增加半截消息，已写内容还在

#### Scenario: 关注状态在话题顶栏
- **WHEN** 用户在话题顶栏关注或取消
- **THEN** 能看出当前是否还会收到这个话题的新回复
- **AND** 这个开关不出现在主时间线的每一条消息上
