# im agent-work Specification (delta for feat-787)

## MODIFIED Requirements

### Requirement: Work 提供工作记录与原生轨迹两种查看方式

此双视图要求适用于 Web。iPhone 提供原生 Crewden 工作记录与派工查阅，详见 [iOS 客户端](../../../../specs/im/ios-client.md)。

#### Scenario: 查看当前主执行或关联执行的原生轨迹
- **GIVEN** 全局 Agent 的 Work 已有主执行或关联执行
- **WHEN** 有该 Agent 空间权限的用户在 Work 内切换到原生轨迹，或从工作记录打开对应的轨迹
- **THEN** 在原页面直接看到当前执行的原生轨迹及明确归属，可以检查已有记录的输入、输出、时间和已报告统计。
- **AND** 切回工作记录保留原有查看位置；切换执行不会混入迟到的其他执行内容。

#### Scenario: 保留官方轨迹检查能力
- **WHEN** 用户使用原生轨迹
- **THEN** 可以使用时长切换、轮次／调用折叠、嵌套子调用独立或工具栏批量折叠和搜索，以及输入／模型／工具时间概览与记录选择联动；搜索或定位命中被折叠的子调用时自动展开对应项。
- **AND** 系统提示词、用户、上下文注入、助手（含仅工具调用）、工具／嵌套调用和压缩按原生事实显示；相应检查器保留原文／来源、当时的提示词与工具目录、参数／结果／Schema、请求选项／用量／计时。
- **AND** 等待响应、流式输出与请求重试期间如实显示进行中计时及最近一次尝试错误；失败的工具调用在列表、详情与复制内容中保留工具返回的错误原文；历史缺失不借当前配置补造，桌面和窄屏均能检查完整内容。

#### Scenario: 对照查看存活会话实时工具原始结果与冷态降级提示
- **WHEN** 有权限的用户在原生轨迹中检查存活会话刚产生的工具调用结果
- **THEN** 检查器在只读边界内同时展示剥离未授权内联图片字节后的工具原始结构化结果与模型可见渲染结果。
- **WHEN** 用户检查冷态历史会话或已离开内存保留窗口的工具调用结果
- **THEN** 完整展示持久化的渲染结果，并明确说明原始结果仅对实时工具调用可用，不报错、不白屏，也不为此激活冷会话。

#### Scenario: 尚无可查看执行
- **WHEN** 用户进入尚未产生执行的 Agent 原生轨迹
- **THEN** 显示无可查看执行，不因此新建或启动 Agent。
