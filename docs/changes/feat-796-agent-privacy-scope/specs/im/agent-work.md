# im/agent-work.md (delta for feat-796)

## MODIFIED Requirements

### Requirement: 聊天沟通与全局工作轨迹分开呈现

#### Scenario: Agent 向聊天报告进展或结果
- **WHEN** 主 Agent 选择向某个群聊或单聊发送进展、问题或结果
- **THEN** 消息出现在它明确选择的聊天中
- **AND** 不附带与该聊天无关的整段全局执行轨迹

#### Scenario: 查看员工整体工作
- **WHEN** 全局 Agent 的管理者本人，或（当该全局普通 Agent 处于「团队公开」且其管理者为有效团队成员时）其他有效团队成员进入该全局 Agent 的工作视图
- **THEN** 可以查看主 Agent 跨聊天的连续工作轨迹，辨认其读取、执行及委派过程（无论管理者是否启用了个人空间）
- **AND** 若该全局 Agent 处于「私有」（`owner_only`）或属于个人助手（PA），非管理者访问其 Work 相关接口返回 404 且不接收其实时 `agent.work.updated` 事件。

#### Scenario: 深入查看 subagent 工作
- **GIVEN** 主 Agent 已委派 subagent 且查看者具备该主 Agent 的 Work 查看资格
- **WHEN** 用户查看这次委派对应的执行过程
- **THEN** 可以查看 subagent 的工作轨迹及当前结果，并辨认其与主 Agent 委派的关联，不要求是 Agent 管理者

#### Scenario: Work 内容完整可见，原聊天仍按会话范围访问
- **GIVEN** 主执行和子执行记录包含查看者未参与的聊天内容
- **WHEN** 有该 Agent Work 查看资格的用户查看 Work，或从中点击来源聊天及受保护附件
- **THEN** Work 的已有内容不按来源聊天过滤或遮盖；打开原聊天和受保护附件仍按[当前会话读取资格](auth-tenancy.md#requirement-数据面按登录身份聊天成员与资源管理归属确定访问)单独判定，Work 可见不额外授予来源访问权。

#### Scenario: 非管理者持续查看工作进度
- **GIVEN** 有效团队成员打开有权访问的「团队公开」全局普通 Agent Work
- **WHEN** Agent 产生新的过程记录，或用户刷新、恢复可见页
- **THEN** 可继续看到更新后的完整记录；节点离线及尚未知的执行状态可辨认。

### Requirement: Work 提供工作记录与原生轨迹两种查看方式

此双视图要求适用于 Web 与 Desktop 客户端（iPhone 提供原生 Crewden 工作记录与派工查阅，遵循原生 [iOS 客户端](ios-client.md)契约）。

#### Scenario: 查看当前主执行或关联执行的原生轨迹
- **GIVEN** 全局 Agent 的 Work 已有主执行或关联执行
- **WHEN** 具备该 Agent Work 查看资格的用户（管理者本人，或在该全局普通 Agent 处于「团队公开」且管理者团队资格有效时的其他有效团队成员）在 Work 内切换到原生轨迹，或从工作记录打开对应的轨迹及轨迹内工作区附件
- **THEN** 在原页面直接看到当前执行的原生轨迹及明确归属，可以检查已有记录的输入、输出、时间和已报告统计（无论该「团队公开」全局普通 Agent 创建于公司空间还是个人空间）
- **AND** 切回工作记录保留原有查看位置；切换执行不会混入迟到的其他执行内容；若该全局 Agent 处于「私有」（`owner_only`）或属于 PA，非管理者请求准备/读取原生轨迹或轨迹附件均被拒绝，且当管理者将全局 Agent 从「团队公开」切换为「私有」时，非管理者已打开的实时原生轨迹连接立即关闭。

#### Scenario: 保留官方轨迹检查能力
- **WHEN** 用户使用原生轨迹
- **THEN** 可以使用时长切换、轮次／调用折叠、工具栏嵌套子调用批量折叠／展开与点击已折叠摘要独立展开和搜索，以及输入／模型／工具时间概览与记录选择联动；搜索或定位命中被折叠的子调用时自动展开对应项。
- **AND** 系统提示词、用户、上下文注入、助手（含仅工具调用）、工具／嵌套调用和压缩按原生事实显示；相应检查器保留原文／来源、当时的提示词与工具目录、参数／结果／Schema、请求选项／用量／计时。
- **AND** 等待响应、流式输出与请求重试期间如实显示进行中计时及最近一次尝试错误；失败的工具调用在列表、详情与复制内容中保留工具返回的错误原文；历史缺失不借当前配置补造，桌面和窄屏均能检查完整内容。

#### Scenario: 对照查看存活会话实时工具原始结果与冷态降级提示
- **WHEN** 有权限的用户在原生轨迹中检查存活会话刚产生的工具调用结果
- **THEN** 检查器在只读边界内同时展示剥离未授权内联图片字节后的工具原始结构化结果与模型可见渲染结果。
- **WHEN** 用户检查冷态历史会话或已离开内存保留窗口的工具调用结果
- **THEN** 完整展示持久化的渲染结果，并明确说明原始结果仅对实时工具调用可用，不报错、不白屏，也不为此激活冷会话。

#### Scenario: 尚无可查看执行
- **WHEN** 用户进入尚未产生执行的 Agent 原生轨迹
- **THEN** 显示无可查看执行，不因此新建或启动 Agent。
