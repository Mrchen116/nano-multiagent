## MODIFIED Requirements

### Requirement: 原生日常页面优先呈现任务内容与下一步
#### Scenario: 创建与模型服务
- **WHEN** 用户在原生客户端新建或编辑普通/全局助手，或维护本人的模型服务
- **THEN** 创建先呈现名称、用途与「团队公开 / 私有（仅自己与名下助手）」权限档位（新建默认选中「团队公开」，支持创建时直接选为「私有」），技术设置按需展开；新建群聊勾选本人「私有」助手时自动锁定群可见性为私密并禁止混入其他真人同事（群详情加人同样遵循互斥过滤）；模型服务有常驻原生入口，保存、验证、失败与恢复遵循 [agents-nodes](agents-nodes.md) 契约；模型选择使用可辨认的服务与模型名称，底层选择值不改变。
#### Scenario: 工作与任务阅读
- **WHEN** 用户阅读工作结果、任务总览与子任务结构
- **THEN** 先看到运行状态和可读内容，诊断信息按需展开；任务提供紧凑状态定位与结构总览，原有权限、分页含义不变。
#### Scenario: 表单与完整阅读
- **WHEN** 用户在原生页面阅读内容或编辑表单
- **THEN** 正文可完整换行，字段保留标签，每页有明确主保存动作，展开内容不修改所在页标题。

### Requirement: iPhone 可完成首次交办与个人助手专属管理

#### Scenario: 首次设置与恢复
- **WHEN** 已获准用户在手机上开始设置或回到进行中的创建
- **THEN** 能分清需在电脑完成的步骤，在手机验证模型连接、为助手命名、选择形象并选择「团队公开」（默认）或「私有（仅自己与名下助手）」协作权限，恢复同一次创建及原选定权限档位，确认就绪后进入对应私聊。开始提示可填入空草稿，正文由用户确认发送。

#### Scenario: 主人调整观察与联系人限制及历史私聊只读说明
- **WHEN** 主人打开 PA 的协作设置或风险事件，或同事在手机打开对端助手已被设为「私有」的历史一对一私聊（`write_blocked_reason == "agent_private"`）
- **THEN** 主人可以核实来源与作用对象、切换「团队公开 / 私有」权限档位、修改排除会话、处理事件和解除联系人限制，结果与 Web 共享，未经确认的修改不会显示为已生效；同事在历史私聊中可正常阅读记录且隐藏输入框，底部显示明确的私有助手未开放说明，不将其误标为“公开群 · 加入后可参与”。
