# im/personal-agent.md (delta for feat-796)

## MODIFIED Requirements

### Requirement: 固定个人助手保持原 IM 体验
#### Scenario: 聊天列表中的固定个人助手
- **WHEN** 主人查看 Web 聊天列表
- **THEN** PA 保留独立的置顶聊天入口，使用普通聊天行呈现最新消息摘要、消息时间与未读数，不用告警式底框或固定角色说明覆盖已有消息。
- **AND** 摘要与普通聊天使用相同的 mention、卡片和系统通知呈现，收到更新与已读变化时同步刷新；尚无消息时可显示角色说明。固定入口与工作区欢迎页使用会话当前标题，手动命名不被助手配置保存覆盖。

#### Scenario: 工作电脑保持固定
- **WHEN** 主人打开 PA 配置页
- **THEN** 不提供跨电脑迁移入口；PA 专用换机接口不可用，不能借该接口改变现有绑定、工作区或聊天归属
- **AND** 已有 PA 的日常配置、聊天访问控制与当前运行位置继续沿用

#### Scenario: 创建、改名和配置
- **WHEN** 用户创建或配置自己的 PA
- **THEN** 固定主人关系与私聊入口保持，使用原 Agent 设置与导航；创建时与配置页均可选择「团队公开」（默认）或「私有（仅自己与名下助手）」；「团队公开」下其他有效团队成员可联系 PA 但不能读取主人私人配置和 Work，「私有」下 PA 对其他成员隐藏且不接受或发起外部联系。
- **AND** 已创建 PA 的聊天配置入口直接进入现有 Agent 配置页；名字、模型、指令、技能、协作权限与聊天访问范围在同一页维护，不另设 PA 设置浮窗。来源勾选明确立即生效；创建与未完成创建的恢复仍使用原设置流程并保留创建时所选的协作权限档位。

#### Scenario: 创建与第一条消息分开
- **WHEN** 用户在首次设置或聊天入口创建 PA
- **THEN** 填写助手名字，头像按[角色头像约定](agents-nodes.md#requirement-创建助手时可选择统一且可辨认的角色头像)预选，协作权限默认选中「团队公开」并可直接切换为「私有」。创建成功后进入尚无消息的主人私聊，不收集或自动发送首个任务。
- **WHEN** 主人第一次进入已确认没有历史的 PA 聊天，且输入框为空
- **THEN** 先展示可尝试的小任务，背景介绍与长期职责入口按[首次建立合作约定](#首次建立合作约定)按需展开；点击提示仅填入并聚焦普通输入框，由用户编辑后发送。
- **AND** 发出第一条消息后隐藏整个引导，已有历史的聊天不再显示；已有草稿或附件时不覆盖，查看他人的 PA 时不显示主人职责引导。

#### Scenario: 刷新后恢复未完成的创建
- **WHEN** 电脑尚未确认 PA 创建，用户刷新首次设置页面或重新打开创建弹窗重试同一请求
- **THEN** 页面显示可重试的准备状态，恢复同一助手、原电脑与原选定的头像及协作权限档位（省略档位时沿用首次持久化的选择，使用同一 `request_key` 提交不一致档位时返回 409 拒绝），不打开尚未建立的聊天；只有确认创建完成才进入私人对话。

#### Scenario: 注册后创建并沿用同一个 PA
- **WHEN** 新用户注册并在首次设置中连接电脑、确认可用模型和创建助手
- **THEN** 创建的是该用户固定的 PA 与主人私聊，个人使用无需等待公司批准。
- **WHEN** 用户随后申请加入公司并获批
- **THEN** PA、绑定与主人私聊身份保持，既有消息、配置（含所选公开或私有档位）和工作上下文继续沿用；不再要求创建第二个 PA，也不把私人聊天与 Work 发布给公司。

### Requirement: 双向主人消息可用于协助

无论 PA 处于「团队公开」还是「私有」档位，只要会话仍在主人的聊天访问允许范围内，下列对主人已参与会话的新消息旁观与历史查询规则均保持有效；区别在于「私有」档位下 PA 不作为含外部成员会话的参与者、不接收外部成员直接发给 PA 的私聊，也不向含外部成员的会话发送自身消息或代表主人发言（仅向主人私聊或同主人内部专属会话汇报与提供草稿）。

#### Scenario: 主人先回复
- **WHEN** 主人亲自在原聊天回复
- **THEN** PA 能接收该消息并避免重复回复，读取不改变主人的已读状态。

#### Scenario: 观察主人与他人沟通
- **WHEN** 主人和他人在 PA 未参与的授权聊天里沟通（无论 PA 为「团队公开」或「私有」）
- **THEN** 双方原话可供 PA 理解背景，主人向对方交办或承诺、对方向主人请求均不自动变成 PA 的新任务；PA 可以按既有目标与授权继续协助（处于「私有」时仅向主人内部会话汇报或拟稿，不直接向该外部聊天外发或代发）。
- **AND** 普通观察消息不触发 PA 向该聊天自动发送拒绝警告。
