# Gateway Agent 能力增量

## ADDED Requirements

### Requirement: 可选的宿主浏览器与桌面控制

#### Scenario: 按需选择
- **WHEN** 用户关闭宿主操作工具
- **THEN** 普通会话与新委派不获得该入口；启用时仅加载简短入口，具体动作可按需发现。

#### Scenario: 两种浏览器身份
- **WHEN** 任务请求使用日常 Chrome 或明确选择隔离环境
- **THEN** 日常轨使用节点已配对的浏览器，每个任务有独立的后台标签页；连接不可用时告知恢复方式。隔离轨使用独立环境。任务结束后释放其资源并保留用户浏览器。

#### Scenario: 目标窗口失效
- **WHEN** 任务操作已授权的原生窗口且目标失效或权限不足
- **THEN** 返回原因，停止向该目标输入；用户能重新选择授权窗口。

#### Scenario: 复制和粘贴
- **WHEN** 用户交办读取刚复制的内容
- **THEN** 主会话或承接该交办的 Worker 可直接取一次系统剪贴板；其他任务与普通浏览器复制粘贴使用自己的会话内容。
