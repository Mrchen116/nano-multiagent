# Gateway 工具审批增量

## ADDED Requirements

### Requirement: 共享宿主操作按动作与目标进行一次权限判定

#### Scenario: 只读观察与纯导航
- **WHEN** 获授权的 Agent 或绑定 Worker 在自己的标签页或已绑定窗口中执行状态查询、只读观察、截图落盘、后台滚动，或短时复用同窗口已允准的纯导航快捷键
- **THEN** 宿主本地判定，通过后立即执行而不请求分类审核模型；调用身份或目标失效时停止。

#### Scenario: 修改页面或窗口与多轮语义延续
- **WHEN** 任务打开或导航地址、点击、输入或上传文件（含跨源重定向后对落地页面的写操作，以及在多轮对话中按同一会话上下文延续先前的网页或窗口操作）
- **THEN** 宿主采集当前页面或窗口的真实观察证据，结合会话历史与人类授权进行一次审批：未获自动放行或关闭自动审批时，`single_thread` 有人值守轮次发起 IM 人工审批卡，而 `global` 主会话与绑定外部 CLI Worker 将阻断原因交回调用方 Agent（不额外弹出 Worker 审批卡，也不借无人值守 fallback 放行 `computer_use`）；外部 CLI Worker 对其他原生工具仍走其既有审批路径。拒绝、撤销或执行前目标已改变时不投递原动作，且审批审计与工作视图不保留页面私有正文或剪贴板内容。
