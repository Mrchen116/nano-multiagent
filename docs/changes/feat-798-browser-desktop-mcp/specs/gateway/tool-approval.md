# Gateway 工具审批增量

## ADDED Requirements

### Requirement: 共享宿主操作按动作与目标进行一次权限判定

#### Scenario: 只读观察与纯导航
- **WHEN** 获授权的 Agent 或 Worker 在自己的标签页或已绑定窗口中执行只读观察、后台滚动、或短时复用同窗口已允准的纯导航快捷键
- **THEN** 宿主本地判定，通过后立即执行；调用身份或目标失效时停止。

#### Scenario: 修改页面或窗口
- **WHEN** 任务导航到新地址、点击、输入或上传文件
- **THEN** 宿主根据真实的目标与动作进行一次审批，CLI 保留对其他工具的审批；拒绝、撤销或目标改变时不执行原动作。
