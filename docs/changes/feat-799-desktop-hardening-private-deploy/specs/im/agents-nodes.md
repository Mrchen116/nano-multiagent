# IM - Agents and Nodes Specification (delta for feat-799)

## MODIFIED Requirements

### Requirement: 托管 IM 提供连续首次设置

新个人用户可从连接电脑、连接模型、定义首个助手一路进入真实聊天。连接电脑步骤在支持桌面客户端的平台上同时提供「下载完整 Desktop 客户端」与「仅安装轻量后台节点」两套并存入口；命令行/本地 Agent 安装指引与轻量后台安装器继续保留，所有安装材料均针对当前 IM 且不包含用户密码或模型凭据。进度由真实节点、模型和助手状态恢复；已有用户不被强制重新引导。

#### Scenario: 短窗口完整完成设置
- **GIVEN** 首次设置步骤的表单内容超过当前窗口高度
- **WHEN** 用户在桌面或手机上继续填写设置
- **THEN** 可纵向滚动到完整表单、保存与继续操作，不因屏幕高度被截断。

#### Scenario: 安装并恢复
- **WHEN** 用户运行页面提供的安装方式并确认设备绑定
- **THEN** 页面显示本人电脑并继续模型步骤；重复安装/刷新不重建身份或丢失数据。
- **AND** 首次连接确认展示当前账号和电脑，并以连接成功引导继续设置；只有整机交接使用设备转移文案，不将首次连接描述为转移。绑定页与首次设置使用聚焦的设置页头，分别呈现账号确认与电脑端连接进度，实际提交完成前不展示连接成功。

#### Scenario: 有指导的助手创建与冷启动检查恢复
- **WHEN** 用户完成电脑绑定与模型验证后选择用途、名称与协作范围并提交创建个人助手（包括 Windows 电脑首次冷启动能力检查耗时较长的场景）
- **THEN** 系统在电脑已配置模型上线与模型保存变更后后台预热并复用已确认的节点能力目录，避免创建时重复拉起冷检查子进程，在单次创建操作内落地独立助手与工作目录，进入真实聊天并可发送符合用途的起步任务；建议不冒充真实回复
- **AND** 首次设置用个人助手、电脑和模型等用户可理解的称呼；创建前的连接摘要优先展示模型显示名，不以内部服务标识代替模型名称
- **AND** 当提交创建遇到电脑离线、能力检查暂不可用/超时或节点正在确认应用结果时，保留已填写的名称、头像与协作范围草稿，并按实际状态分别给出离线恢复、能力准备中稍后重试或按同一创建请求核对结果的可行动提示

#### Scenario: Windows 用户从 IM 下载并连接工作电脑
- **GIVEN** 用户使用 Windows 10 或 Windows 11 x64，电脑上没有 Node.js 或 WSL。
- **WHEN** 用户从当前 IM 下载 Windows 安装包，双击安装并确认要连接的电脑和账号。
- **THEN** 用户无需终端或系统开发环境即可在同一 IM 看见电脑在线，连接模型、创建助手并收到真实回复。
- **AND** 当前服务尚未提供对应版本时，页面说明可稍后重试；下载或唤起电脑端后，仅实际连接的电脑可以进入下一步。

#### Scenario: 连接电脑并列提供完整 Desktop 客户端与轻量后台节点入口
- **WHEN** 用户在首次设置选择 macOS 或 Windows 10/11 x64 连接电脑
- **THEN** 页面同时提供「下载完整 Desktop 客户端」（macOS 标明支持 Apple Silicon 并引导 Intel Mac 选用轻量后台节点；支持下载安装包及通过桌面协议带入当前 IM 地址打开）和「仅装轻量后台节点」（保留终端/本地 Agent 脚本或 Windows 轻量后台安装器）两套可选路径，Linux/WSL 展示后台脚本路径
- **AND** 默认仅在 `https://`（及本机开发回环 `http://`）连接下开放桌面安装与唤起材料；独立 IM 私有化部署显式启用内网私网 HTTP 支持且服务地址属于 RFC1918/RFC4193 私网或 `.local` 范围时，开放自包含内置运行环境的完整 Desktop 客户端下载与桌面唤起入口，而依赖公网 HTTPS / 官方 GitHub 源的轻量后台安装入口在未满足其协议与发布源前提时如实标为暂不可用，不暴露必败链接或命令

### Requirement: IM 安装入口指定版本，程序包由独立发布源直接分发

#### Scenario: 安装当前服务选择的版本与受控自托管发布源
- **WHEN** 用户运行当前 IM 提供的安装方式或发起受管更新
- **THEN** 电脑按该 IM 提供的固定版本和校验信息，直接从默认官方 GitHub Release 或该部署与桌面安装包共同声明的受信自托管发布源下载程序包；不随发布源 latest 变化选取其他版本，程序包不经 IM 业务进程中转，安装完成后仍连接目标 IM
- **AND** 发布源基地址默认要求加密 `https://`（仅本机测试回环或私有化部署显式受控允许的内网私网自托管源例外，且明文私网源禁止跨源重定向），下载路径或哈希与受信发布清单不一致时一律拒绝

#### Scenario: 下载失败保留原安装
- **WHEN** 指定程序包不可下载或校验失败
- **THEN** 明确显示重试方法，保留原安装与数据；不跳过校验、不切换未知版本，也不悄悄改经 IM 转发程序包。

#### Scenario: 普通部署保持安装版本
- **WHEN** 用户只要求合并代码、构建或部署更新
- **THEN** 不发布新的安装包，安装入口保留当前已验证版本；服务源码更新不自动切换安装版本。

#### Scenario: 明确发布命名版本
- **WHEN** 用户明确要求发布安装包并确定 `X.Y.Z` 版本号
- **THEN** 发布对应 `vX.Y.Z` Release，源码提交仅作为追溯信息，安装包内容经校验后才可供安装入口选择；已有版本不覆盖。
- **AND** 缺少确定版本号时不猜测或自动递增；现有已发布的 SHA 版本在被替换前仍可安装。

#### Scenario: 同一 IM 为不同电脑提供各自的受管版本
- **WHEN** 用户安装或请求更新一台受支持的电脑
- **THEN** IM 提供已验证且适用于该电脑的指定版本。该平台未发布或下载校验失败时显示可重试的结果；已安装的版本和数据仍可使用。
