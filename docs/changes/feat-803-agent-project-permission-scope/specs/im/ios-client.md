# im/ios-client.md (delta for feat-803)

## MODIFIED Requirements

### Requirement: 原生日常页面优先呈现任务内容与下一步
#### Scenario: 创建与模型服务
- **WHEN** 用户在原生客户端新建或编辑普通/全局助手，或维护本人的模型服务
- **THEN** 创建与配置呈现名称、用途与「团队公开 / 项目级 / 私有（仅自己与名下助手）」三档权限选择（新建默认选中「团队公开」，支持直接选为「项目级」或「私有」；从「私有」放宽为「项目级」或「团队公开」保存前弹出历史私有内容暴露风险确认），技术设置按需展开；新建群聊勾选本人「私有」助手时自动锁定私密并禁止混入其他真人同事，勾选本人「项目级」助手时自动锁定私密但允许选择真人同事（群详情加人同样遵循该规则，且全局「项目级」助手跨非重叠私密群加入时弹出背景互通确认）；模型服务有常驻原生入口，保存、验证、失败与恢复遵循 [agents-nodes](agents-nodes.md) 契约；模型选择使用可辨认的服务与模型名称，底层选择值不改变。
#### Scenario: 工作与任务阅读
- **WHEN** 用户在 iPhone 阅读工作结果、任务焦点台与长线目标脉络
- **THEN** 先看到运行状态和可读内容，诊断信息按需展开；任务 Tab 默认呈现「与我有关」行动焦点台，支持「当前行动 / 长线目标」切换、顶部「待你拍板 ⇄ 先存着」并列切换（一键提上日程）、「进行中」主区、统一 9 状态词徽章、按阶段展示实质内容的任务详情 Sheet，以及切换「按负责人 / 团队全部」（顶栏双视角一致生效）、关键字搜索和选择归属会话快速创建单卡或多步目标，单手批准、「先存着」或关闭待拍板提议时浮层反馈不挤动相邻卡片；点入长线目标时顶部保留终局目标说明，以竖屏纵向阶段脉络呈现可展开的前序完成阶段、当前推进前沿、多层子脉络钻取、探索选型与待拍板新芽，保留新增与编辑子节点能力，不要求双指缩放二维画布
- **AND** 聊天内嵌顶层 `task_cards` 活卡片支持本机缓存离线展示与在线状态刷新，聊天卡片与任务页状态实时一致；原有会话权限不变。

#### Scenario: 表单与完整阅读
- **WHEN** 用户在原生页面阅读内容或编辑表单
- **THEN** 正文可完整换行，字段保留标签，每页有明确主保存动作，展开内容不修改所在页标题。

### Requirement: iPhone 可完成首次交办与个人助手专属管理

#### Scenario: 首次设置与恢复
- **WHEN** 已获准用户在手机上开始设置或回到进行中的创建
- **THEN** 能分清需在电脑完成的步骤，在手机验证模型连接、为助手命名、选择形象并选择「团队公开」（默认）或「私有（仅自己与名下助手）」两档协作权限（PA 不展示「项目级」选项），恢复同一次创建及原选定权限档位，确认就绪后进入对应私聊。开始提示可填入空草稿，正文由用户确认发送。

#### Scenario: 主人调整观察、联系人限制与主动筹划及历史私聊只读说明
- **WHEN** 主人打开 PA 的个人助手设置或运行配置页，或同事在手机打开对端助手已被设为「私有」（`write_blocked_reason == "agent_private"`）或失去共同私密群的项目级只读历史私聊（`write_blocked_reason == "agent_project_restricted"`）
- **THEN** 一级个人助手设置页展示当前主动筹划状态并可直达二级运行配置页；二级运行配置页保持「团队公开 / 私有」两档切换（从私有放宽时弹出确认），并在运行特性区提供单一「主动筹划」可编辑开关（与「任务图」特性同页依赖联动并共用主保存动作，避免跨页隐藏依赖阻断或同页重复开关）、修改排除会话、处理风险事件和解除联系人限制，结果与 Web 共享；节点离线时如实显示离线只读，未经确认的修改不会显示为已生效
- **AND** 同事在历史私聊中可正常阅读记录、在会话列表侧滑或长按菜单调整个人置顶与免打扰且隐藏输入框，底部按原因分别显示明确的私有助手或项目级助手未开放说明，不将其误标为“公开群 · 加入后可参与”。
