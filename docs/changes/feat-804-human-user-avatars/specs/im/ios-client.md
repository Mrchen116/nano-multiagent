# IM ios-client Specification (delta for feat-804)

## MODIFIED Requirements

### Requirement: iOS 独立客户端保持 IM 业务与权限契约
IM SHALL 提供原生 iPhone 客户端。聊天、任务、Agent 和我的及其管理页面 SHALL 保持现有 IM 业务契约，内部业务页面 SHALL NOT 委托网页容器完成。Intelligent UI 回复内容允许使用随包共享渲染组件，原生宿主 SHALL 保持业务权限与交付权威。公共可见性 SHALL NOT 推导出管理权限。

#### Scenario: 使用原生业务入口
- **WHEN** 用户从 iPhone 图标进入聊天、任务、Agent Work、配置、通道、节点、账号、公司和策略页面
- **THEN** 这些页面在原生客户端内可操作，并保持聊天、任务图、agents-nodes、external-channels、auth 与 settings 对应契约的权限、结果和失败语义。
- **AND** 外部网站链接可以打开系统浏览器，但不得附带 IM 凭据。

#### Scenario: 查看群聊与自己的空间
- **WHEN** 用户打开群聊详情
- **THEN** 先看到群名、成员与群任务，置顶与免打扰可以就地切换。邀请、改名、成员管理及解散遵循原会话权限；进入相应操作后才显示编辑或移除控件。
- **WHEN** 用户进入「我的」与「个人资料与语言」
- **THEN** 「我的」顶部展示当前账号最新圆形头像（已上传自定义头像或首字母圆章），点个人身份进入「个人资料与语言」后可从系统相册选择静态图片、经圆形取景裁剪确认后立即上传更换头像，或在已有自定义头像时移除恢复首字母圆章，且头像上传、取消或移除不覆盖未保存的显示名、默认入口设备或语言草稿；已有个人助手可直接打开私聊，未完成的创建可继续设置。电脑连接与绑定入口在一起，模型配置与退出登录从设置进入。

#### Scenario: 输入与辅助访问
- **WHEN** 用户使用中文组合输入、多行输入或 VoiceOver
- **THEN** 组合文字不会误发送，输入区和主操作保持可达，关键控件提供可读名称，长内容可选择和复制。
- **AND** 消息的复制正文和可用分支操作提供具名辅助操作，与长按菜单保持相同可用条件；创建分支仍需确认。

#### Scenario: 聊天输入和身份延续 Web 体验
- **WHEN** 用户在群聊输入 `@` 或在草稿开头输入 `/`
- **THEN** 输入框旁直接出现可筛选、可点击的成员或命令候选；选择保留其余正文和编辑焦点，仅预填不发送，附件菜单不承载提及和命令。
- **AND** 真人、群、PA 与专业 Agent 的身份在会话、消息、引用、成员、公司成员、Agent 与「我的」页面保持一致；已上传自定义头像的真人在各处统一显示圆形照片头像（加载中、离线或失败时稳定回退首字母圆章，外部未映射发送者不继承镜像拥有者头像），已选择的 Agent 形象跨端相同，未选择时由稳定身份确定。私聊改名或真人仅改显示名不丢失对方自定义头像，更换或移除头像后同步刷新，代发保留实际归属。已读回执、话题参与者和新增身份入口按同一 ID 显示头像，成员离群后历史回执仍保留其身份。Web 与 iOS 共享配色与跨端回归样例。

### Requirement: 本地聊天数据按服务与账号分区，并随访问变化清理

客户端 SHALL 以服务地址与账号共同限定本地聊天数据的范围，并在退出、切换账号或服务、账号或凭据失效、以及会话访问被撤销时停止展示对应内容；本地 SHALL NOT 保存受保护媒体（含受保护真人自定义头像）的字节。

#### Scenario: 换账号或切服务
- **WHEN** 用户退出登录后登录另一个账号，或把服务地址改到另一台服务并登录
- **THEN** 新会话语境里看不到上一账号或上一服务的会话、消息、草稿与未发出的内容
- **AND** 上一范围的迟到网络结果不会把内容重新写回界面。

#### Scenario: 两个账号在同一台设备上互不可见
- **GIVEN** 两个账号先后在同一台设备、同一服务上使用过
- **WHEN** 其中任一账号登录并离线打开 App
- **THEN** 只看到自己账号的会话与消息，另一个账号的内容既不可见也不会被当作自己的未读统计。

#### Scenario: 会话访问被撤销
- **GIVEN** 用户此前能访问某个群
- **WHEN** 用户被移出该群、群被解散或该会话的访问被撤销
- **THEN** 客户端在得知这次撤销后，使该会话从列表消失，本地已存的消息与预览不再展示，也不会在界面闪回
- **AND** 「得知」指在线收到该会话的事件、或一次成功同步的结果不再包含该会话；得知之后即使离线、重启或冷启动，同样不展示被撤销的内容
- **AND** 撤销发生在客户端离线期间时，不承诺离线期间不展示；从恢复联网后第一次成功同步起不再展示，收敛时间受客户端现有重试节奏限制。

#### Scenario: 受保护媒体不随本地内容留存
- **WHEN** 用户查看过受保护图片、文件或真人自定义头像之后退出登录、切换账号、切换服务，或该会话的访问被撤销后离线打开
- **THEN** 看不到这些受保护图片、文件与自定义头像图片字节（离线时真人头像稳定回退首字母圆章，聊天附件保留不含媒体的占位或说明）
- **AND** 本地持久层只保留元数据（如 `avatar_version` 与附件元数据），不将受保护媒体或自定义头像字节写入磁盘缓存，退出或切换时立即取消在途读取并清空内存图像缓存。
