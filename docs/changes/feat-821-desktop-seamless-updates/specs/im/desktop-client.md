# IM desktop-client Specification (delta for feat-821)

## MODIFIED Requirements

### Requirement: Desktop 客户端保持系统登录自启、菜单栏或系统托盘常驻与受管更新

Crewden Desktop（macOS Apple Silicon 与 Windows 10/11 x64）SHALL 支持系统登录自启与菜单栏/系统托盘常驻，并面向当前连接的官方 HTTPS IM 或配置了受信发布源的自部署 IM 提供独立于本机节点绑定状态的桌面端版本发现、默认开启的「自动保持最新」后台静默准备、低打扰一键热切换以及原生客户端安装包升级引导。所有面向用户的更新文案均使用自然易懂的产品语言，不暴露校验哈希值、内部协议字段或工程错误码。

#### Scenario: 默认登录自启与后台异常退出恢复
- **GIVEN** 用户已通过 Crewden Desktop 完成本机绑定并保持默认的开机登录自启设置
- **WHEN** 用户重启电脑并重新登录同一系统账号，或运行期间本机后台节点意外退出且故障已消除
- **THEN** 在网络与 IM 服务可用时，Crewden Desktop 自动驻留菜单栏（macOS）或系统托盘（Windows）并使原电脑恢复在线，原助手可继续正常回复

#### Scenario: 关闭主窗口保持后台在线并支持多入口唤起
- **GIVEN** Crewden Desktop 正在运行且本机节点在线
- **WHEN** 用户关闭主聊天窗口
- **THEN** 客户端继续驻留菜单栏或系统托盘，本机节点执行、消息接收与系统通知保持在线
- **AND** 点击 Dock / 任务栏图标、菜单栏/托盘打开项或系统原生通知时，主窗口恢复显示

#### Scenario: 手动启停本机节点与开关登录自启
- **WHEN** 用户在菜单栏/托盘或应用内本机管理页主动停止本机后台节点
- **THEN** 本机节点进入离线并保持停止，直至用户手动再次启动，或在仍启用登录自启时重新登录系统
- **WHEN** 用户关闭开机登录自启设置并重启电脑重新登录
- **THEN** 该电脑保持离线且不自动拉起后台运行；用户手动打开并启动后，原电脑身份与助手恢复可用；设置未能生效时界面如实展示实际状态与恢复提示

#### Scenario: 默认自动静默准备更新、空闲或重开平滑应用与纯聊天模式独立更新
- **GIVEN** 用户在 macOS 或 Windows 上使用 Crewden Desktop（无论本机节点处于已绑定在线、已手动停止、尚未绑定，还是归属于其他账号仅使用聊天功能）
- **WHEN** 当前连接的官方或受信自部署 IM 服务发布了较新的桌面热更新版本
- **THEN** 默认开启的「自动保持最新」在后台静默完成下载与完整性校验，不弹出阻塞遮罩、不打断正在输入的草稿或运行中的助手任务
- **AND** 主窗口打开可见时，准备完成后在导航区呈现不遮挡聊天输入区的轻量换新入口（含目标版本、按需展开的更新亮点与一键换新动作，切出窗口失焦但主窗口仍可见时不强行自动刷新页面）；仅当主窗口关闭隐藏至托盘（或后台常驻无窗口）且无未保存配置表单、无运行中本机任务，或下次启动客户端时，自动平滑切换至已就绪的新版本
- **AND** 无论「自动保持最新」处于开启或关闭状态，用户在个人菜单（含窄屏个人页）、系统托盘或「电脑」页发起手动「检查更新」时均实时反馈真实状态（已是最新版本、暂未提供桌面更新包、准备进度或一键换新）；关闭「自动保持最新」后该偏好跨重启持久化，后台不再自动下载或自动切换；切换连接的服务地址后更新状态与激活界面按服务独立隔离，且在非本人本机节点场景下绝不越权改写或重启他人节点

#### Scenario: 受管热切换保留当前路由、输入草稿、登录会话、电脑身份与工作区
- **GIVEN** 新版热更新包已在本地校验就绪，用户停留在具体会话或业务路由且聊天输入框内存在尚未发送的文字草稿、提及或回复引用
- **WHEN** 用户触发一键换新（存在在途本机任务时明确提示等待当前任务完成后自动换新，并在切换开始前支持取消）
- **THEN** 切换完成后自动回到换新前所在的同一页面路由，完整保留当前服务与账号会话下的未发送输入草稿与回复引用、登录会话、电脑节点身份、已有助手与本地工作区文件（退出登录或会话失效后清除会话草稿缓存）
- **AND** 检查、下载、完整性校验或切换启动失败时自动回退并保留原可用版本，以自然语言说明原因并提供一键重试入口

#### Scenario: 外层桌面客户端宿主升级无缝衔接为一键下载核验与安装引导
- **GIVEN** 当前连接的官方或受信自部署 IM 服务发布的新版本升级了外层桌面客户端宿主程序（无法仅靠内部热切换完成）
- **WHEN** 客户端检测到该版本并由用户点击下载升级客户端
- **THEN** 界面不显示「版本不兼容」或命令行提示，而是从当前受信发布源下载并完整校验对应平台安装包，实时展示准备进度
- **AND** 校验完成后，Windows 客户端支持一键拉起新版安装程序平滑停止旧实例并覆盖升级重开，macOS 客户端支持一键打开已校验的新版磁盘映像并给出拖入 `Applications` 替换及未公证版本首次打开的明确提示，升级后原登录会话、服务地址、节点身份与工作区完整保留
