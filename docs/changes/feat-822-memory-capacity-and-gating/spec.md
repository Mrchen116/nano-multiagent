## 用户场景

长期使用个人助手或全局数字员工的用户，在跨越数月乃至数年的日常高频或低频交互中期望获得稳定、精准且低成本的长期记忆体验：

1. **长周期使用后关键偏好依然在首屏可命中**：即便积累了数百轮工作流与业务规则，助手常驻首页中的主动介入偏好不会吞噬通用人物与事项索引；被动业务规则与回复排版习惯归入主题索引，详细的主动唤醒执行细则按需在主动巡检与夜间筹划轮次提供，不再把早期确认的生活/协作关键偏好挤出常驻视野。
2. **长期活跃项目页保持精炼“当前态”而非百 KB 流水账**：围绕同一重点项目持续讨论数月后，对应事项或实体页面始终聚焦当前有效结论、约束与关键决策指针，历史演变过程归入按日或按任务的历史记录；后台整理无需每晚反复整页重写超长历史，耗时与上下文开销保持受控。
3. **记忆正文干净利落，不刷无意义免责尾巴**：助手沉淀的记忆条目直接陈述有证据支撑的事实、条件与范围，对缺乏依据的猜测直接略去，不再在每条偏好后机械附加“这不代表付款/预订/发信授权”等系统元规则套话，释放宝贵的记忆容量（实际动作权限仍由宿主审批与角色规则严格把关）。
4. **低信息量轻交互日静默攒批，重要信号与超期兜底不漏记**：当用户某天只有简短日常寒暄或零星查询、尚未达到值得重开一轮后台整理的增量规模时，凌晨自动维护静默延后且不阻塞夜间主动筹划；一旦遇到首次建档、人类任务面板明确拍板反馈、累积增量达标或达到最长等待天数上限，后台自动合并完成整理，不丢失任何跨天对话。

## 验收标准

### Requirement: 常驻记忆首页实行独立分区配额并分层承载主动唤醒细则

#### Scenario: 主动偏好积累不挤占常驻主题索引空间
- **GIVEN** 个人助手或全局数字员工在长期交互中积累了多条主动介入边界、被动业务规范与回复格式偏好
- **WHEN** 后台记忆巩固更新常驻记忆首页与二级页面
- **THEN** 常驻首页的主动介入偏好专区严格保持在受控配额内，仅保留简短触发级边界与静默时段摘要，始终为主题与实体索引预留充足常驻空间
- **AND** 被动任务执行规范与回复排版偏好归入对应知识或人物主题页，详细的主动跟进与夜间筹划细则下沉至专用主动策略文档并在主动唤醒轮次自动提供，日常普通对话不额外膨胀系统提示

#### Scenario: 常驻主动专区超限或混入禁用文件引用时同轮自愈
- **WHEN** 整理草稿使常驻首页的主动介入专区超出分区配额，或违规暴露后台单次信号观察池
- **THEN** 宿主结构检查明确指出违规路径与配额原因，驱动同一整理轮次精简下沉修复后再提交正式记忆版本

### Requirement: 主题与实体页面受单页容量护栏约束并聚焦当前有效状态

#### Scenario: 长期演进事项保持当前态摘要并将过程归入历史页
- **GIVEN** 同一项目、事项或人物跨越多轮持续产生新进展与旧方案更替
- **WHEN** 后台记忆巩固整合最新进展
- **THEN** 对应实体、知识与事项/项目主题页仅保留当前有效状态、适用条件与合并后的关键决策指针，单页体积严格控制在容量上限以内，阶段性流水过程归入时间线或工作历史页面
- **AND** 若某主题页超出单页硬上限，宿主结构检查拒绝直接放行并提示拆分或将过程历史下沉后再完成提交（既有历史存档页面不会在空闲无增量时误触发后台重写）

### Requirement: 记忆正文仅陈述有依据事实，消除防御性元规则套话

#### Scenario: 巩固业务规则与个人偏好时不附带冗余免责尾巴
- **WHEN** 后台记忆巩固记录用户的审批阈值、差旅标准、排期习惯或沟通偏好
- **THEN** 记忆条目直接准确表述已确认的事实、例外与证据范围，未证实的推断直接略去，不在记忆正文中重复附加“不构成发送/预订/付款/部署授权”等通用系统权限免责声明
- **AND** 前台助手与外发工具审批的真实权限边界保持原有严格约束不变

### Requirement: 自动夜间巩固具备最小有效增量门禁与最长延后兜底

#### Scenario: 低信息量短对话日静默延后且不阻塞夜间主动筹划
- **GIVEN** 助手已有初始正式记忆、正式记忆仓干净无异常，且当日仅有少量低信息量普通对话、无人类任务面板拍板反馈或子任务复盘待整合
- **WHEN** 到达凌晨自动维护窗口且距上次完成巩固未满最长延后天数上限
- **THEN** 宿主判定本轮未达最小有效增量门槛，不启动整理模型调用，保留未整理对话游标供后续合并，并正常放行当夜的主动筹划唤醒

#### Scenario: 累积达标、达到兜底天数、首次建档或出现明确拍板信号时正常巩固
- **GIVEN** 此前因增量较小而延后整理的对话仍在待处理队列中
- **WHEN** 后续累积对话达到最小增量门槛、或距上次巩固达到最长延后天数上限、或当前尚处于初始空白记忆建档阶段、或收到人类任务面板拍板反馈、或用户显式请求立即整理
- **THEN** 后台记忆巩固正常启动，将此前延后期间的全部合格对话与新材料一次性合并整理入库，无遗漏推进处理进度

## 范围与非目标

- **在范围**：
  - 常驻 `MEMORY.md` 主动专区配额校验、专用主动策略细则文档支持及主动唤醒尾部按需附带；
  - 二级主题页（`entities/`、`knowledge/`、`workstreams/`、`projects/`）单页容量上限校验与“当前态 vs 历史流水”整理指引；
  - 记忆提炼与整合提示词去套话重构及随包 `nano-memory` / `nano-proactive-care` 技能同步；
  - 自动 `03:00` `Dreaming` 最小增量阈值 + 最长延后天数兜底调度门禁及配套单测、集成测试与 DolphinBench `1:753` 前缀同口径对比验证。
- **非目标**：
  - 不引入外部向量数据库或非 Markdown 存储引擎；
  - 不改变正式记忆“仅 `Dreaming` 单写者可修改”与外发/工具自动审批的安全边界。
