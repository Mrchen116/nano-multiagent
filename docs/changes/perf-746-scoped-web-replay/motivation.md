# Web 按可见范围恢复实时消息

## 用户要求

用户对五项审查发现逐项要求修复，并授权安排节奏：“都得解。怎么节奏做，你自己规划”。本单元对应“Web 按可见范围恢复实时消息”。

## 现状与动机

中心用全站事件差判定回放窗口，逐条取完整正文再判权。2,001 条与本人无关的私聊事件可触发全量恢复。

范围是浏览器事件回放与恢复，不改消息存储、实时发布协议或可访问范围。

## Requirement: Web 按可见范围恢复实时消息

### Scenario: 长历史下完成原有操作

- **WHEN** 用户短暂断线期间本人有少量未收到的事件，而别的会话产生大量流量
- **THEN** 浏览器按原顺序恢复本人可见事件并保持去重。无关流量不耗尽本用户的回放额度。真正的可见事件积压仍可安全降级，权限收回后不回放撤销的内容。
