## ADDED Requirements

### Requirement: 消费者能够观察完整模型轮的结束

#### Scenario: 多块正文与工具交错
- **WHEN** 一次模型调用输出多个正文块并启动工具
- **THEN** 消费者在该轮完整输出及工具结果处理后收到一次带相同group身份的完成事实，可以区分chunk结束和模型轮结束；事实本身不等待产品业务处理。

#### Scenario: 复核、空正文和异常
- **WHEN** 输出被原有新输入复核扣住、轮内没有正文，或者模型流异常/取消
- **THEN** 消费者不能将该事实解读成存在可公开的完整正文，原有运行终态与复核语义不变；未完成的流不得报告正常轮完成。

### Requirement: SDK 消费者可检查工具操作权限而不执行工具

#### Scenario: 真实会话下的产品操作
- **WHEN** SDK 消费者要求检查某项工具操作并提供真实session、workspace及来源操作身份
- **THEN** 检查复用同一工具权限策略和来源上下文，保留allow/deny/人工审批及取消语义，既不执行工具，也不生成伪造模型tool call。

#### Scenario: 会话隔离与已有执行权限
- **WHEN** 不同会话并发检查，或产品操作已通过真实工具执行权限链
- **THEN** 不串用会话权限或批准结果，SDK不会自行再为已执行工具追加一次审批；接口不包含图片、渠道或送达状态。
