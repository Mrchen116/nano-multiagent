# im Task Graphs delta — refactor-673

## MODIFIED Requirements

### Requirement: 任务不随聊天退出而删除

#### Scenario: 成员退出或会话解散
- **WHEN** 成员退群或群被解散
- **THEN** 任务及 ID 保留，访问按固定所属会话当前范围判断；解散群按冻结的成员与可见范围提供历史只读入口，未完成关闭、已完成保持，不再接受写入。
- **AND** 真人解散造成的节点关闭或当前选项清空，最近修改者和时间记录真实解散者及解散时刻，变更说明指明解散；被关闭节点不再携带旧等待或恢复推进信息，创建者、负责人和成果保留。未发生节点变更的已完成记录保持原修改信息。
