# im Task Graphs delta — refactor-673

## MODIFIED Requirements

### Requirement: 群任务视图记录本群创建及编辑的节点

#### Scenario: 从任意群聊天进入本群任务
- **WHEN** 成员在某个群聊天点击“任务”
- **THEN** 展示当前群新建或编辑过的任务节点，在同时有权读取任务所属会话时打开同一张任务图，并能返回原群；切换到另一群时采用新群上下文，不固定示例群。
- **AND** 全局 Tasks 沿用原列表/图/详情入口，按固定所属会话限制可见范围；本群活动不变成全局页的固定群筛选，回聊继续保留草稿和引用、不自动发送。

#### Scenario: 跨群分解与协作
- **WHEN** 公开 A 群创建总目标及分解，已加入 A 群的主体从 B 群更新其中子任务
- **THEN** A/B 各自保留相应图与节点的活动入口，打开同一持久图，不复制任务或用最后编辑群覆盖前群关联。
- **AND** 群过滤只对有权查看该群者开放；任务本身仍要求源会话访问资格；源群收紧范围后，B 群入口不能泄漏任务摘要、数量或内容。

#### Scenario: 独立生命周期与最后更新聊天
- **WHEN** 成员退群或群被解散
- **THEN** 任务及 ID 保留，访问按固定所属会话当前范围判断；解散群按冻结的成员与可见范围提供历史只读入口，未完成关闭、已完成保持，不再接受写入。
- **AND** 真人解散造成的节点关闭或当前选项清空，最近修改者和时间记录真实解散者及解散时刻，变更说明指明解散；被关闭节点不再携带旧等待或恢复推进信息，创建者、负责人和成果保留。未发生节点变更的已完成记录保持原修改信息。
- **WHEN** 节点从另一个聊天或无来源处被更新
- **THEN** 每节点的快捷回聊指向实际最后更新的有权访问聊天，无来源则留空；不覆盖其他节点的回聊位置，也不删除此前有效群活动关联。

#### Scenario: 保留原图浏览与讨论入口
- **WHEN** 成员打开任务深链或把节点交给另一 Agent 讨论
- **THEN** 既有层级图、面包屑、节点引用复制和回聊追加引用行为保持；保留聊天草稿，不自动发送；手机也可操作。
