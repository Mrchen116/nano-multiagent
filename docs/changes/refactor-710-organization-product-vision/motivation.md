# refactor-710: 组织级 Agent 平台产品愿景

## 原始诉求

> 我觉得得更新一下了，你可以看看当前的设计。我要做的是一个组织级的agent平台，im作为协作和工作的主体，每个人有自己的person agent，另外还有专业化的global agent做为数字员工，不是接受单个人的任务，而且承担独立的职能。

> 然后每个agent是承担长期的职责，意味着他不是收到一个任务就做一个事情，而是长期proactive的主动感知，在协作中主动完成任务。同时，需要有并行做多个任务的能力。
>
> personal agent我可以稍微介绍一下，他是辅助他的主人的，所以他能感知到主人所有的上下文，帮助主人更好完成主人的职责。

> 另外，更细的vision我在很多unit的spec原话中有

> 同时，proactive，长期职责，就意味着agent需要有辅助的长期记忆能力

## 澄清记录

用户已明确产品定位、IM 的主体地位、两类角色，以及所有 Agent 的长期职责、主动感知、多事项并行和辅助长期记忆。PA 要理解主人的整体上下文，帮助主人履行职责。

Agent 解读：本次更新产品总纲及入口摘要，表达用户确认的方向，并与当前设计对照。组织数字员工可以处理多人提出的请求，但其长期职责和工作连续性不依附于单个请求者；“独立职能”不自动意味着无限权限、任意派工或已实现新的组织管理系统。个人使用仍可作为入口，私人 PA 的关系与隐私不因加入组织而消失。本次不实施新产品功能。

Agent 解读（补充）：主动性覆盖全部长期 Agent，职责既支持对请求的响应，也支持在职责内持续观察、发现需要、主动采取有用行动和跟进结果。PA 的理解不能局限于与主人自己的私聊，要综合主人相关沟通、任务、关系、偏好和变化；接入与授权边界如实说明，不宣称已接通所有生活与工作来源。并行工作期间仍能交流，一项等待不阻塞其他事项。长期记忆为职责履行服务，支持背景与工作经验积累、相关消费和纠正，不把早期记忆方案恢复为当前契约。

## 目标状态

产品总纲明确：nano-multiagent 是以 IM 为协作与工作主体的组织级 Agent 平台。组织由真人、各自的 Personal Agent，以及承担专业职能的 Global Agent 数字员工共同工作。

需要读者理解的长期原则：

1. IM 承载沟通、协作、工作推进和结果交付，任务与 Work 服务于同一工作过程。
2. PA 围绕特定个人的目标、背景和授权协助，保护私人信息，能在授权内参与组织协作。
3. 专业数字员工围绕明确职能、职责范围与交付目标持续工作，整合多人、多聊天的相关输入；PA 围绕主人履职，两者都应持续主动感知并在职责与权限内采取行动，不以一轮请求定义全部工作。
4. 配置管理者、任务请求者和数字员工承担的组织职能是不同概念；本次不重定义运行资源及配置的 owner 权限。
5. 长期数字员工与任务内部 subagent 有不同产品身份；内部委派不转移对外职责。
6. 所有长期 Agent 能并行推进多个独立事项，持续交流和处理更正、等待与结果，避免一项等待占住全部工作。
7. 长期记忆支撑持续职责和主动判断：PA 逐步理解主人，专家积累领域、项目与协作经验；已有知识需要实际使用、可追溯和可修正。
8. 可观察、可干预、权限明确、知识与上下文连续是长期体验要求；方向描述不冒充完成验收。
