## MODIFIED Requirements

### Requirement: 前台提醒与后台限制明确
客户端 SHALL 在活跃时提供可关闭的新消息轻提示，并与 Web 及 Desktop 遵循一致的提醒资格与全局未读汇总语义；SHALL NOT 将免费个人签名描述成后台远程推送或持续运行保证。

#### Scenario: 实时消息与历史重放
- **WHEN** 活跃 App 收到其他未静音聊天的新消息（包括外部渠道镜像会话的入站对端消息），或在已静音聊天中被明确 `@提及`
- **THEN** 开启的轻提示可以定位聊天且默认不暴露正文；已静音聊天的普通消息与历史补齐不触发重复提醒。
- **AND** 底部聊天入口的总未读角标仅汇总未静音会话的未读数，已静音会话在会话列表行内仍保留自身的未读计数与静音图标。

#### Scenario: 后台及安装帮助
- **WHEN** 用户查看帮助，或从后台、锁屏或被终止状态回到 App
- **THEN** 可理解后台新消息不保证系统推送，返回后能补齐历史；不要求通知权限才能聊天。
