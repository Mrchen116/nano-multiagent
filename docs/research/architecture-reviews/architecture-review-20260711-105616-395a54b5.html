Candidate 01

深化 IM 持久化 module，封住 SQLite leakage

Strong local-substitutable

Candidate 02

把 AgentRuntime 的整轮事务深化为内部 module

Strong in-process

src/agent/core/agent/runtime.py · src/agent/core/session/* · src/agent/core/agent/prompt* · tests/unit/test_agent_runtime.py · tests/unit/agent/runtime/*

Problem

`_run_locked` 同时拥有 load、hooks、prompt、persistence、retry 与 recovery；测试只能穿透 private state。

Solution

不改 `agent.sdk` seam；在 core 内按共同生命周期收口一轮执行的事务语义，不做函数搬家。

Wins

  • locality: turn 原子语义
  • interface 替代 monkeypatch
  • retry / recovery 同测
  • SDK seam 保持不变
Evidence: runtime.py:146–170, 322–975, 1680+, 2141–2245+ · tests patch `_execute_loop`, `_memory_snapshots`, and use `AgentRuntime.__new__`

Candidate 03

深化 IM↔Gateway WS RPC correlation module

Strong ports & adapters

src/IM/ws/gateway_handler.py · src/IM/ws/gateway_protocol.py · src/IM/api/routes/agents.py · src/IM/api/routes/nodes.py · src/IM/api/routes/web_im.py

Problem

Solution

在 IM package 内收口 correlation lifecycle；各 domain RPC 仍拥有自己的 validation 与语义。

Wins

  • leverage: 一处服务 N 个 RPC
  • locality: timeout / cleanup
  • tests 不写 waiter dict
  • 新增 RPC 不复制状态机

Candidate 04
