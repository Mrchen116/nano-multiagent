Proactive execution deep module

Heartbeat 与 cron 只提供各自产品语义；共同状态转换留在内部。

Problem

一次 heartbeat admission 同时读取 binding、canonical dict、busy set 和 queue 私有状态；main 再私有回填依赖。

Solution

把主动执行的 session identity、busy 判断、排队和 delivery 状态收归一个 module。

Wins

  • locality: 并发状态单一 owner
  • leverage: heartbeat / cron 共用
  • tests 不读 private queue
  • main 只做 composition
约束：保留 feat-394 已定语义——heartbeat 复用 canonical direct session；cron 保持 isolated session + awareness。

Problem

Solution

  • leverage: run / fork / compact

Problem

transport constructor 注入大量领域 callbacks；listen loop 直接解释 config、heartbeat、cron、fork、capability。

Solution

保留 reconnect/ack 的 transport depth；把领域 frame 解释与本地文件/调度访问移到领域 module。

Wins

  • locality: transport lifecycle 集中
  • locality: RPC 语义集中
  • frame seam 独立测试
  • 新增 RPC 不扩 constructor
约束：保留真实网络 seam；不得让 IM 与 personal_assistant sibling package 互相 import。
