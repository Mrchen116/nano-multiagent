完成 Web relay 的 typed ingress

在 adapter 边界一次性形成 channel-neutral runtime facts，移除下游对 provider 名称和隐藏 metadata key 的了解。

PA / Gateway ingress

Files

channels/web_relay_adapter.py:145–282 gateway/runtime_protocol.py:13+ gateway/inbound_pipeline.py:197,310 gateway/runtime_delivery/*

Problem

把 session continuity 收进 GatewaySessionBinder

让 binder 成为 continuity 的唯一行为面，把 crash-safe SQLite 细节和并行内存实现留在 owner 内部。

PA / Gateway state

Files

gateway/session_binder.py:35–122 gateway/session_keys.py:102–1706

Problem

binder 的私有 repository protocol 已扩展到 16 个操作族；内存与 SQLite 两套实现被测试广泛直接调用。内存版本无法覆盖跨进程恢复，SQLite docstring 仍描述已移除的 HTTP kernel client。

Solution

让 session continuity 的状态机、持久化和恢复由 binder 整体拥有；调用方与测试只观察 binder 行为，生产 SQLite 可在临时目录中本地替代。

Decision change

2026-07-25 的审查仅将双实现记为观察项；当前私有 seam 已承载 boundary、control、outbox 与 supersession，证据强度已改变。
