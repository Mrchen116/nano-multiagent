# Thematic Studies

本目录保存围绕一个稳定研究问题形成的主体研究包。每个主题目录以 `<topic>-<YYYY-MM-DD>` 命名，日期表示该轮研究材料的截止日期；后续研究另建同级目录，旧包保持冻结。

每个研究包的 `README.md` 说明范围、状态和 current owner，`research.md` 保存来源、观察与推论，面向读者的结论文章及其必要图资产与之同目录保存。研究材料只提供证据与历史语境，不覆盖 current 文档。
