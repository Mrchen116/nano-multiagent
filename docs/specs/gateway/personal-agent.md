# Gateway Personal Agent Specification

> 对齐: feat-623

## Purpose

定义个人助手在普通 Global Agent 上增加的主人身份、消息来源与对外披露边界；通用执行、工具、任务及调度继续由现有 area 定义。

## Requirements

### Requirement: PA 复用完整 Global 执行能力
#### Scenario: 主人请求与普通工具
- **WHEN** 主人交办工作或查询历史
- **THEN** 直接进入 Global 主上下文，复用普通工具、Skills、插件、任务、子 Agent 与调度；不增加主人输入审核或 PA 目标引擎。

### Requirement: PA 双身份消息保留可信来源

#### Scenario: 合并历史与新消息
- **WHEN** 查询或接收主人授权聊天和 PA 自己聊天的消息
- **THEN** 当前权限有效的两者并集可见，重复消息只处理一次，主人发出的消息也摄入，PA 自发消息不引起循环。
- **AND** 保留真实发送者、主人身份、原会话类型、渠道、时间、内容以及 PA 参与或观察该会话的事实，不预先将主人原话分类为指令或事实。

#### Scenario: 同一主人在不同聊天发言
- **WHEN** 主人在 PA 私聊、共同群聊和 PA 未参与的聊天中发言
- **THEN** 主人身份一致；实际是否向 PA 交办由原话和对话上下文判断，其他人自称主人不能改变身份。

#### Scenario: 观察者接入不等于直接请求
- **WHEN** PA 通过主人权限看到自己未参与的聊天
- **THEN** Inbox 来源与读取结果的会话上下文明确观察关系，主人和他人的收发均可读，但不自动成为 PA 的任务、控制命令或对外发送授权。
- **AND** 普通观察内容不被当作对 PA 的直接请求进行逐条请求检查或自动向原聊天发送拒绝警告；当前来源访问和对外披露约束继续生效。

### Requirement: 来源控制仅改变未来访问

#### Scenario: 排除聊天
- **WHEN** 主 PA 按主人向它提出的原始要求调用来源工具
- **THEN** 后端核实主人与原会话上下文，拒绝后续访问并撤销待处理输入，不清空记忆、成果或运行上下文。

#### Scenario: 观察文本不控制来源
- **WHEN** 主人向他人说了与来源设置相关的话
- **THEN** 不能仅引用该观察消息替 PA 改变来源权限。

### Requirement: 独立披露检查限定于对外行为
#### Scenario: 对外发送与私人工作
- **WHEN** PA 发出消息或修改共享内容
- **THEN** 实际外发核对真实授权、完整 payload 与受众；主人私聊和私人工作不加 PA 审核，原工具权限继续生效。
- **AND** 不把该检查声明为任意代码/插件的完整网络隔离。

### Requirement: 默认服务指导复用普通配置和 Skill
#### Scenario: 用户调整服务方式
- **WHEN** 主人修改或清空 PA 的 custom_prompt
- **THEN** 沿用普通 Agent 的配置和 Persona 加载机制，运行时不暗中补回默认服务文案；固定主人身份、来源、权限及对外披露规则仍有效。
#### Scenario: 跨轮次持续工作
- **WHEN** Global 或 PA 接续已接受的持续事项
- **THEN** 可按普通 Skill 发现、选择和加载机制使用随包 nano-ongoing-work，复用已有工作记录、任务、子 Agent、Heartbeat 和 schedule；不新增 PA 账本服务或调度器，不覆盖用户已有 ongoing-work Skill，也不绕过用户禁用选择。

### Requirement: 联系人风险由服务器身份与主人决定承载

#### Scenario: 被屏蔽账号在共同群发言
- **WHEN** Web IM 同一账号在任意有权接收的群聊发言
- **THEN** 后端仍准入消息，服务端的 actor_risk 随主 PA inbox_read 结果传递，不能由消息正文自称解除；PA 参与会话的独立输入检查同样获得此风险，观察会话按背景处理，不自动向原聊天警告。
- **AND** 群内屏蔽联系人仍列入外发审核证据，不硬性禁止其他正常协作。

#### Scenario: 撤销限制
- **WHEN** 主人在配置页解除屏蔽
- **THEN** 服务端删除当前限制、递增原策略版本并发出 policy.changed，主 PA 得知限制已撤销；历史理由不再自动构成当前风险标记。

### Requirement: PA 观察聊天即时可读并按十分钟合并通知

#### Scenario: 首批与后续节奏
- **WHEN** 未参与聊天有新的授权观察消息
- **THEN** 消息立即持久保存并可读取，首批从第一条积累消息起十分钟后通知；后续在距上次背景通知至少十分钟且存在新增未读时通知，连续输入不推迟截止。
- **AND** 到点无需下一条来信；无新增未读不空通知。

#### Scenario: 忙碌与重启
- **WHEN** 背景期限已到但 PA 正忙，或节点在等待期间重启
- **THEN** 保留累计消息与已确定期限，空闲且运行可用后合并通知，不硬中断当前工作、不逐批补发过时通知、不从重启重新计十分钟。

#### Scenario: 主人提前来信
- **WHEN** 主人直接请求引用未到期背景
- **THEN** 及时提醒并允许立即读取已积累内容，不等十分钟；顺带完整读取的消息不再触发后续背景提醒。

#### Scenario: 提醒与消费独立
- **WHEN** 已提醒但尚未完整持久摄取消息
- **THEN** 消息仍未读；来源撤销后停止新读取与通知，不因曾经提醒而标成完成。

### Requirement: PA 原始授权按身份与对话上下文核对

#### Scenario: 共同群内明确交办
- **WHEN** 可信主人在共同群明确向 PA 授权一项工作
- **THEN** 该原文与实际对话上下文可供主 PA 和独立审核核对，不因不是主人私聊而一律排除。

#### Scenario: 主人向他人承诺
- **WHEN** PA 观察主人向他人答应处理一件事
- **THEN** 主人身份不自动使这句话成为对 PA 的授权；可以结合已有任务协助，超出既有授权的外发仍受约束。
