# gateway - Task Graphs Specification

> 对齐: feat-584、feat-587
> 上级: [gateway Specification](spec.md)

## Purpose

约束 Agent 在任意输入渠道下通过工具维护同一份持久任务记录的行为。

## Requirements

### Requirement: Agent 可按讨论结果维护持久任务图

#### Scenario: 创建、查询和增量修改
- **WHEN** 用户要求已配置任务工具的 Agent 保存或调整讨论好的计划或探索结构
- **THEN** Agent 能建立、读取并修改对应任务图，返回同一图的稳定入口。
- **AND** 保存不按图结构调度执行；分配和结果等协作系统消息遵循既有群接收策略。
- **AND** 节点以图内稳定短编号（如 `n1`、`n2`）读取和更新；改名、排序或状态变化不改变编号，不要求 Agent 反复传递节点 UUID。
- **AND** 图本身也使用短且稳定的引用（如 `tg_a1b2c3d4`）；不同图不会因短 ID 重名而覆盖彼此，工具与 Web 链接使用同一个图 ID。


#### Scenario: 配置任务图特性
- **WHEN** 用户在 Agent 配置中开启或关闭默认开启的“任务图”特性并保存
- **THEN** 该 Agent 下一轮回复按最新配置采用任务图能力，当前正在回复的一轮不切换，已有聊天历史和任务图记录保留。
- **AND** 开启开关通过既有界面联动选中 `task_graph` 工具；有效能力同时要求特性开启和工具白名单包含该工具。关闭后即使白名单保留该工具，也不向后续模型提供或允许调用，预览采用同一有效配置。
- **AND** 关闭某个 Agent 的特性不撤销用户按所属会话读取既有任务图的 Web/iOS 访问权，也不改变其他 Agent 或输入渠道的权限。

### Requirement: 图操作使用真实会话与账号归属

资源空间资格是前提，任务访问由固定所属会话决定；私人 Agent 仅访问本人私人空间，公司 Agent 须保持 owner 的公司资格。账号归属核实真实主体，不替代会话权限。加入公司不发布私人会话或其任务。

#### Scenario: 真实身份与公司能力
- **WHEN** 有效成员交办已启用任务工具的真实注册 PA Agent 维护任务
- **THEN** 可跨 owner/Gateway 在所属会话范围内读取同一持久图，写入要求会话成员资格；不接受模型指定身份、未核实内核 child、停用 owner 或过期机器连接。
- **AND** 工具开关和 allowlist 继续同时生效；工具不按任务依赖调度执行；协作系统消息按原群策略处理。

#### Scenario: 外部渠道复用现有主人与 Agent 资格
- **WHEN** 飞书等外部渠道的 Agent 调用任务工具
- **THEN** 复用既有 ownerOpenId 及交办规则；IM 校验 Agent/Gateway 的有效身份、目标空间资格与任务能力，不要求外部发言人另行关联 IM 登录账号。
- **AND** 私人 Agent 不要求公司资格但只能读写自身私人任务；公司 Agent 的管理者未加入公司、待批准或停用时无权读写公司任务；ownerOpenId 不替代这些检查，也不自动转换成外部发言人的 IM user_id。
- **AND** 飞书私聊/群的正常沟通、背景与回复去向保持，无全群核验、关联页面或仅发链接限制。

#### Scenario: IM 不可达时任务调用如实失败
- **WHEN** 飞书 Agent 正常对话期间无法连接 IM 任务服务
- **THEN** 普通渠道继续既有本地自治；任务工具明确返回不可用或结果未知，不宣称任务已保存、不创建本地替代图。

#### Scenario: 来源与无来源操作
- **WHEN** Agent 创建或更新节点
- **THEN** 普通绑定会话采用真实聊天，全局会话只记录可核实来源；显式来源未映射时明确失败，不猜测聊天或创建本地影子图。
- **AND** 创建必须解析所属会话，无绑定来源时显式指定已有会话；编辑可不指定讨论来源，但仍需所属会话写入资格，不伪造用户；每次仅更新实际受影响节点的来源和群活动关联，重试保持原记录。

#### Scenario: 返回稳定入口
- **WHEN** Agent 返回任务图及更新结果
- **THEN** 图与节点短 ID 稳定，外部链接指向既有 IM 公开入口；打开后仍验证资源空间资格、所属会话及受保护来源。

### Requirement: 工具确认、失败与结果未知按真实情况返回

#### Scenario: 过时修改或无效图
- **WHEN** Agent 提交与新版本冲突或破坏图结构的修改
- **THEN** 得到可操作的错误，旧请求不会覆盖新图或落下部分修改。

#### Scenario: 写入结果未知后重试
- **WHEN** 一次写入未取得确认，Agent 以同一请求身份核实或重试
- **THEN** 不重复创建图或节点；无法核实时不声称已保存。

### Requirement: 图查询与记录不改变既有执行语义

#### Scenario: 查询或标记完成
- **WHEN** Agent 查询图或按用户要求更新一个节点的待确认、完成、暂缓、关闭或选定记录
- **THEN** 不消费聊天Inbox，不以此自动执行依赖任务、开子Agent或宣布目标验收通过。

### Requirement: 删除任务遵守真实用户明确要求与既有图一致性

#### Scenario: 删除或自主工作
- **WHEN** 成员明确要求删除已指定范围或确认 Agent 说明的范围
- **THEN** Agent 按会话上下文和统一工具权限流程判断授权，工具授权且实际 Agent 为目标创建者（或真人调用主体为有写资格的公司管理员）时删除该范围并报告真实结果；笼统整理、解散群或主动调度不等于删除授权。
- **AND** 用户无需重复任务标题、ID 或固定确认口令；工具获准后，不要求本轮重新读取真人消息或重新收集删除授权。统一权限拒绝时不执行删除。
- **AND** stale revision、非法结构与结果未知继续按既有冲突/回执契约处理，不能无条件覆盖或重复删除。

### Requirement: Agent 使用真实身份分工并遵循协作状态引导

#### Scenario: 创建、分配与领取
- **WHEN** 真实 Agent 创建、分配或领取任务
- **THEN** 创建者固定为实际 Agent；新子任务默认未分配，负责人可为所属会话成员中的人或 Agent；分配不改状态、不自动入群，领取只允许无负责人或自己负责的任务并表示开始推进。
- **AND** 改派不改创建者，负责人不独占修改权限，工具不能伪造真人或继承其管理者的管理员角色。

#### Scenario: 结果提交与逐层反馈
- **WHEN** Agent 完成任务或收到父任务暂缓、关闭通知
- **THEN** 引导完成工作先标待确认供人核对，但允许直接完成；父子状态不自动联动，通知不强停其他任务、不自动遍历子树执行。
- **AND** 系统消息的事件与有效 @ 对象遵循 [IM 任务协作契约](../im/task-graphs.md)，无独立任务线程、私信或回执审批。

### Requirement: Agent 可发现、创建与自行加入内置群

#### Scenario: 真实主体创建或加入
- **WHEN** 具有既有产品会话工具资格的真实 Agent 列出公开群、创建群或自行加入
- **THEN** 公司内公开群可读；新建群默认公开且可选私密；加入仅作用于 Agent 自己，私密群不允许自行加入。
- **AND** 此能力不授权模型指定其他 Agent 身份，不绕过内部 child 的既有工具限制，不把 Agent owner 身份转换为群管理员。
