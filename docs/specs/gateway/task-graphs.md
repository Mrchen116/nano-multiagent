# gateway - Task Graphs Specification

> 对齐: feat-569
> 上级: [gateway Specification](spec.md)

## Purpose

约束 Agent 在任意输入渠道下通过工具维护同一份持久任务记录的行为。

## Requirements

### Requirement: Agent 可按讨论结果维护持久任务图

#### Scenario: 创建、查询和增量修改
- **WHEN** 用户要求可访问目标聊天且已配置任务工具的 Agent 保存或调整讨论好的计划或探索结构
- **THEN** Agent 能建立、读取并修改对应任务图，返回同一图的稳定入口。
- **AND** 保存行为本身不启动或调度执行工作。

### Requirement: 图操作使用真实会话与成员权限

#### Scenario: 身份不匹配或未注册
- **WHEN** 请求中的会话不属于对应注册 PA Agent（包括无法核实为 PA 身份的内核 child），或 Agent 无权访问图所关联的聊天
- **THEN** 操作被拒绝且说明原因，不接受模型传入的身份或借 Work 可见性扩大权限。

#### Scenario: 输入渠道与工具能力解耦
- **WHEN** 持有任务工具的 Agent 会话处理来自 Web IM 或外部聊天的用户指令
- **THEN** 使用相同的创建、查询和更新契约，不按输入渠道另建任务工具权限。
- **AND** 显式工具配置未授予该工具时不绕过配置；工具操作本身不创建或唤醒会话。

#### Scenario: 目标聊天映射尚不可用
- **WHEN** 创建或按聊天查询使用的目标引用尚无既有 IM 会话映射
- **THEN** 明确返回来源暂不可用，不猜测另一聊天、不创建本地影子图；已知 graph_id 的查询或更新仍只按该图的目标成员关系判定。

#### Scenario: 返回可查看的同一张图
- **WHEN** Agent 向用户说明任务图及更新结果
- **THEN** 返回稳定图引用，可用的外部回复链接指向既有 Web IM 公开入口；打开后仍登录并检查成员关系。

### Requirement: 工具确认、失败与结果未知按真实情况返回

#### Scenario: 过时修改或无效图
- **WHEN** Agent 提交与新版本冲突或破坏图结构的修改
- **THEN** 得到可操作的错误，旧请求不会覆盖新图或落下部分修改。

#### Scenario: 写入结果未知后重试
- **WHEN** 一次写入未取得确认，Agent 以同一请求身份核实或重试
- **THEN** 不重复创建图或节点；无法核实时不声称已保存。

### Requirement: 图查询与记录不改变既有执行语义

#### Scenario: 查询或标记完成
- **WHEN** Agent 查询图或按用户要求更新一个节点的完成、暂缓、放弃或选定记录
- **THEN** 不消费聊天Inbox，不以此自动执行依赖任务、开子Agent或宣布目标验收通过。
