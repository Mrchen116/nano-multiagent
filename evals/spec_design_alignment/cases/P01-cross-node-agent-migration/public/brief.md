# 把一个长期 Agent 从 MacBook 迁到 Mac mini

我有一个已经长期使用的 Agent，现在运行在 MacBook 上。我希望把它迁到 Mac mini，之后由 Mac mini 持续运行。

迁移后它仍然应该是同一个 Agent：已有聊天和上下文、记忆、skills、cron、workspace，以及已经配置的外部通道都不能悄悄丢失或变成另一份互不相干的数据。

迁移过程中不能出现两个节点同时接管这个 Agent。任一步失败都要把真实状态告诉我，并能安全回到迁移前仍可使用的状态；不能留下半迁移、双活或需要我手工猜哪份数据才是真的局面。

请基于仓库当前行为完成需求与技术设计。代码、测试和 current specs 能回答的事情自行查证；只有会真正改变产品体验、数据安全或取舍方向的未决问题才需要问我。
