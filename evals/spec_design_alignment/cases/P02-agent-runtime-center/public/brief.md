# 在 Agent 详情里看懂它最近在做什么

我希望 Agent 详情页不再只有配置项，而是真正能看见这个 Agent 最近在做什么。

普通对话、heartbeat、cron 和后台任务应该能在一个可理解的视图里呈现。我需要区分仍在进行、等待、已经完成和失败的工作，并看到有用的结果或原因；如果工作卡住或失败，也应该有安全、明确的处理方式。

这不是工程日志查看器。信息应该让我快速理解 Agent 的活动和结果，同时在桌面和移动端都能使用。离线、数据暂时不完整、加载、错误和空状态也不能互相伪装。

请基于仓库当前行为完成需求与技术设计。代码、测试和 current specs 能回答的事情自行查证；只有会真正改变产品体验、权限或数据安全的未决问题才需要问我。
