# 妙搭创意设计

仅在 lark-apps 已选定妙搭创意应用设计路径后使用。按用户用途、品牌、现有 UI 和源材料完成 HTML 设计；已有应用在原目录继续，不擅自新建应用。

## 设计约束

- 只询问无法从上下文确定且影响整体方向的事项；其余在已有授权内自主处理。不强制 todo、变体数量或多轮确认。
- 实质内容必须基于相关材料；事实/指标有来源，计算从数据得出。无需读无关附件或把每份资料都全文加载。
- 交互原型作为真实界面运行；design-canvas 用于静态方案对照，不包裹可点击原型。版式与素材服务信息，不用固定卡片、字数或图数配额。
- 保留原有评论锚点与可定位的页/屏标签；普通 UI 使用已有图标体系。用户提供的品牌和素材优先。
- 应用静态资源按 lark-apps 上传到所属 app 的文件存储，以返回 URL 引用；不提交图片/字体等资源、不跨 app 复用 URL。
- 产物保留版本记录，避免覆盖其他任务；不同时要求复制文件与 Tweak 状态管理，选择适合现有工程的方式。
