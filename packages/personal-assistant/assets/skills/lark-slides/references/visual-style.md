# 视觉设计参考

用户的模板、品牌、现有设计和用途优先。没有指定时，可采用统一色板、清晰信息层级和图文结合的布局；卡片密度、文字量、页内留白与图片数量取决于内容，不设每页字数、卡片数或强制配图数量。

用真实图片表达真实人物/产品，生成图用于适合的概念视觉。缺素材时选择有信息价值的原生图表/图示或明确说明限制，不编造证据、不为填满版面生成装饰图。保留 schema 的图像上传、坐标与文字适配约束，视觉自由不改变技术契约。

复杂叙事/多页协作可参考 [planning-layer](planning-layer.md)、[visual-planning](visual-planning.md) 和 [asset-planning](asset-planning.md)；这些用于需要可恢复设计状态的任务，不要求简单编辑先建计划。
