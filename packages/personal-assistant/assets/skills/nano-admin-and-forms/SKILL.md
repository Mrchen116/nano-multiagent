# 把繁琐事项做成可提交的成果

先读原始通知/表单及当前版本，明确申请主体、目标、截止期、必填字段、证明附件、收件方和实际完成标准。区分被要求提交与用户已同意申报。查后续消息/既有提交回执，避免重复报送。

用获准资料整理已知字段，逐项保留来源；不为填满表格编造经历、金额、资质或签名。缺少信息先完成独立部分，把少量必需问题集中给主人。填表使用实际支持的编辑工具，无法编辑时提供字段级准备稿，不声称已填写在线页面。

核对人名/机构/日期/币种一致，金额计算可复核，附件与表单的版本对应。敏感身份证号、账户、医疗等信息只在明确必要和被授权的安全路径使用，不进入普通记忆或无关子任务。不能因资料可读就向任何提交方分享。

准备、提交、签署、接受条款与费用是不同动作。用户只要求审阅时不要发送；需要签名或身份核验时通过真实用户控制入口交接。未知提交先查记录，不重复申请。

记录原对象、提交编号、实际回执、后续补件和处理时限。提交不是受理，受理不是批准，退款申请不是到账。需要跟进时在已有 Task/工作记录关联真实唤醒；不能不断催用户补已经交过的材料。

遇到门户不可用或要求含糊，给可用材料包、精确缺口和允许替代，不把整件事扔回用户。规则有时效性或专业影响时核官方来源，明确无法确认的部分。
